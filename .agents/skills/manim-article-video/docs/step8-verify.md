# Step 8 验证 + 归档（构建后，QA subagent 检查）

构建完成后派 `manim-qa-reviewer` 对**成片**做最终检查（渲染后的检查在 step6-render.md）。成片六查 + 字幕验证：

```bash
# 六查：
# 1) 字幕：抽首/中/尾帧，品牌条上方 y∈[1610,1690]（距底 230-310px）有黄色像素（r>180,g>150,b<120）
# 2) 内容不越界：对 build_S*.mp4（无字幕）抽每页最后一帧，距底 200-441px 区域（y∈[1479,1720]）
#    无非背景像素（品牌条带 y∈[1706,1734] 除外）
# 3) 内容占屏：每页内容最低点距底 ≤800px（跨度 ≥40% 屏高），且 ≥399px（两行字幕上方）
# 4) 音画：silencedetect 最长静音段应 ≈ tail（0.1s 级），句子间停顿 <1s 正常
# 5) 品牌尾卡：最后一场景抽帧，品牌图 + 黄色关注引导 + 当期文章标题可见
# 6) 时长 ≈ Σ(配音)+N×tail；封面 <标题>-封面.png 为 yairouter 1080×1920（不是 Manim Cover）
```

**字幕验证（2026-08-15 新增）**：成片抽帧检查字幕折行（≤2 行）、无英文拆断、无左右截断、音画同步。
- **字幕折行**：每条字幕 ≤2 行（75 号字一行约 13 字），长句在逗号处拆成语义片段
- **英文不拆断**：中英文混杂时在空格/单词边界断行（InstructGPT、sigmoid 等完整保留）
- **无左右截断**：字幕不超出画面左右边界（libass 对中文不自动折行，需手动 \N 换行）
- **音画同步**：`scripts/check_sync.py` 检查字幕时间戳无重叠/无过短，与画面切换对齐
- **无长静音**：silencedetect 最长静音段 <1.5s（段内长静音需裁剪）

- **SRT 必须改名**（不能与 mp4 同名，VLC 会叠加显示同名 .srt）
- 产物归档 `content/<日期>-<主题>/shipinhao/`：`<标题>-成品.mp4`、`<标题>-封面.png`、`<标题>-字幕备份.srt/.ass`、`storyboard.md`、`scenes.py`、`tts.txt`、`full.txt`、`tts/`、品牌圆角图
