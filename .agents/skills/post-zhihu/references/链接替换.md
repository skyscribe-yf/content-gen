# 链接替换 — 微信 URL → 知乎 URL

## 核心规则

知乎文章中的内文引用、系列导航、文末链接不能出现微信公众号 URL（`mp.weixin.qq.com`），需要替换为知乎专栏 URL（`zhuanlan.zhihu.com/p/...`）。

## 替换时机

| 阶段 | 动作 |
|------|------|
| 写作 `promote/zhihu-{slug}.md` | 写映射占位，或等发布后回填 |
| 发布知乎拿到 URL后 | 更新 `templates/zhihu-urls.yaml` + `draft-status.yaml` |
| 写新 zhihu.md 内文引用 | 查映射表，如果有已发布知乎 URL 就替换，否则保留微信 URL 标注 `（原文发于公众号數解AI）` |

## 替换策略（优先级）

1. **先查映射表** (`templates/zhihu-urls.yaml`)
2. **有映射** → 直接替换为知乎 URL
3. **无映射但已发布** → 从 `draft-status.yaml` 的 `zhihu_url` 字段查找
4. **未发布** → 保留微信 URL + 文字标注

## 系列导航链接

原文系列导航（尾部合集链接 + 逐篇导航）必须全部用知乎 URL：

```markdown
# 替换前（微信 URL）
📖 **[训练回路合集](https://mp.weixin.qq.com/...)：梯度下降 → ...**

# 替换后（知乎 URL）
📖 **[训练回路合集](https://zhuanlan.zhihu.com/p/XXXX)：梯度下降 → ...**
```

## 引流钩子（保留微信元素）

文末引流钩子不能删除但需要合规转化：

```markdown
# 合规版
完整版（含 7 张原创技术图解 + DeepSeek-V4 Muon 时间线）发在公众号「數解AI」。
数学拆 AI，不堆公式不讲废话。

# ❌ 违规版
关注公众号「數解AI」回复"Adam"直接收到这篇  ← 可能被折叠
```

**原则**：提及公众号名称和回复关键词是 OK 的，但不能有可点击的微信公众号链接。

## 脚本使用

```bash
# 提取文件中的所有外链（用于构建映射表）
python3 scripts/zhihu-links.py promote/zhihu-adam.md --mapping templates/zhihu-urls.yaml --extract

# 替换链接
python3 scripts/zhihu-links.py promote/zhihu-adam.md --mapping templates/zhihu-urls.yaml

# 仅预览
python3 scripts/zhihu-links.py promote/zhihu-adam.md --mapping templates/zhihu-urls.yaml --dry-run
```
