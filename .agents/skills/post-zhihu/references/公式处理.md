# 知乎公式处理

## 核心决策：知乎公式用 LaTeX，不转 Unicode

知乎编辑器 **原生支持 MathJax**，`$$...$$` 直接渲染为矢量公式。因此知乎版内容应保留 LaTeX 格式，不需要转换为 Unicode。

## 为什么 Unicode → LaTeX？

当前 `promote/zhihu-*.md` 中公式已被转为 Unicode（`θₜ₊₁ = θₜ − η · gₜ`），这在知乎上是**次优选择**：

| 方案 | 效果 | 编辑性 |
|------|------|--------|
| Unicode `θₜ₊₁` | 显示正确，但非矢量 | 不可二次编辑 |
| LaTeX `$$\theta_{t+1} = \theta_t - \eta \cdot g_t$$` | 矢量渲染，最佳效果 | 可二次编辑 |

## 转换规则速查

| 符号 | Unicode | LaTeX |
|------|---------|-------|
| 下标数字 | ₀₁₂₃₄₅₆₇₈₉ | _{0}_{1}... |
| 下标字母 | ₜₙᵢⱼₖₗₛᵣ | _{t}_{n}... |
| 上标数字 | ⁰¹²³⁴⁵⁶⁷⁸⁹ | ^{0}^{1}... |
| 上标字母 | ⁿⁱʲᵏᵗ | ^{n}^{i}... |
| α-ω | αβγδεζηθικλμνξπρστυφχψω | \alpha \beta ... |
| 运算符 | ·×÷≤≥≠≈∞∂→⇒∑∫√⋯ | \cdot \times ... |
| 帽子 | m̂ₜ | \hat{m}_{t} |
| 分数 | ½ ¼ | \frac{1}{2} |

## 脚本使用

```bash
# 检查公式格式
python3 scripts/zhihu-formula.py promote/zhihu-adam.md --check

# 转换 Unicode → LaTeX
python3 scripts/zhihu-formula.py promote/zhihu-adam.md --direction unicode-to-latex
```

输出：`promote/zhihu-adam.zhihu.md`（全部公式已转回 LaTeX）

## HTML 中的处理

生成知乎粘贴用 HTML 时，公式需要以 `$$...$$` 或 `$...$` 形式出现在 HTML 中。知乎富文本编辑器在粘贴时会自动识别并渲染。

**注意**：不要用 KaTeX 或 MathJax 预渲染成 HTML，直接保留 `$$...$$` 源码即可。

```html
<!-- ✅ 正确 -->
<p>更新公式：$$\theta_{t+1} = \theta_t - \eta \cdot g_t$$</p>

<!-- ❌ 错误（KaTeX 渲染后无法在知乎编辑器中二次编辑） -->
<p>更新公式：<span class="katex">...</span></p>
```

## 多行公式

```latex
$$
\begin{aligned}
m_t &= \beta_1 \cdot m_{t-1} + (1-\beta_1) \cdot g_t \\
v_t &= \beta_2 \cdot v_{t-1} + (1-\beta_2) \cdot g_t^2
\end{aligned}
$$
```

知乎支持 `aligned`、`cases`、`matrix` 等常见 AMS-LaTeX 环境。
