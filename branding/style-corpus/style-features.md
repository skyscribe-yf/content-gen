## 两个体裁，两种腔，不要串

账号有两条声音，成稿跟当篇体裁走，禁止用贴图短打去「优化」数学长文，也禁止用长文书面腔去改手敲贴图。

### A. 贴图（手敲 digest）

第一人称行业观察 + 个人使用经验。写的是「我用过/我看到/我担心」，不是转述新闻。

- 短段落，一句一段，极少超过 3 句
- 开头直接抛观察、结论或情绪，不做铺垫
- 中间按「先说结论 → 补细节/实测 → 吐槽或类比」松散推进
- 结尾几乎必有开放式问题：「你选谁」「你怎么看」「评论区交流交流呗」
- 口语：说实话、话说回来、呗、嘛、真的、居然、简直、爽翻了、杀疯了、撸一个、搞一个
- 技术黑话混生活类比：「agent 领域的 gentoo 或者 archlinux」「机械爱好者自己组装一台发动机安装在自己的爱车上」
- 情绪直给：天壤之别、腐朽的味道、大吃一惊、太激动人心了、恶心人
- 数字 + 亲测：「一度 90% 的 token 都交给它」「200tps（我个人体验过，是真的！）」
- 偶尔 ［呲牙］、「。。。」

标题：口语、情绪、问句或悬念。「opencode 这波真要杀疯了」「突飞猛进的 pi agent 和友善的 openai，你选谁」。

### B. 长文 / 数学篇（raw.md 主腔）

不是咖啡厅短打，是毕业多年重新学通之后，带着读者把一条思路推完。

- **结构**：先讲自己怎么学、怎么卡、怎么通 → 换一个朴素视角推概念 → 落到 AI → 主动划边界（「测度论不管」「这里就不展开了」）
- **句子**：从句多、一口气推一个想法。不要为了「手机好读」把原声拆成「这是真的，不是段子。」那种新闻短打
- **口头禅（保留，不是 AI 腔）**：然而、其实、本质上、事实上、某种程度上、不过、当然、嘛、非常自然吧、这里就不赘述了、先说一下
- **教学人称**：讲推导时用「我们」，点读者时用「你」。禁止为去 AI 味把「我们」一律改成「你」
- **类比**：典故/书/经历（鸠摩智硬学七十二绝技、买椟还珠、洞穴寓言、盲人摸象、看山不是山、山高月小水落石出）。禁止编造具名角色连续剧（学徒、实习生、30 层楼便利贴）
- **自我定位**：毕业 20 年重学、不甘心、刷新操作系统内核；承认「专业学数学的人可能嗤之以鼻，我也无可辩驳」
- **说人话**：把抽象概念用自己的话摊开（「用一句通俗的话说，这个变换其实是有很大水分的」），**不要**打上「说人话就是：」这种标签
- **结尾**：功德圆满 / 下一篇再详细说说 / 有兴趣的可以进一步讨论——不是每段一个小结

## 原声句识别清单

以下句子类型**必须逐字保留**，AI 不得改写（只修明显错别字）：

1. 个人使用经验句（含「我」和具体时长/数量/场景）
2. 学习过程句（怎么卡、怎么通、恨不得给当年自己一拳）
3. 类比句（「就像/就是/这方面它就是」、典故、武侠、寓言）
4. 情绪与吐槽句（爱憎分明的评价）
5. 数字实测句（tps、token、价格、百分比等）
6. 划边界句（「不管它」「不展开」「专业人士可能嗤之以鼻」）
7. 结尾互动问句

### 可贴图节奏（只模仿节奏，不编事实）

- 「你想干的事情，都可以交给 pi，没有的插件自己写」
- 「那种感觉就像是机械爱好者自己组装一台发动机安装在自己的爱车上」
- 「骂归骂，openai 还是对开发者很友善的……和恶心人的 anthropic 简直天壤之别啊！」

### 可长文节奏（来自金标准 raw.md）

- 「这个过程不能说全无收获，但是得到的东西却不伦不类，有点像天龙八部中的硬学少林寺七十二绝技的鸠摩智」
- 「后来很多年后我打算认认真真，不为功利地学会人工智能的底层第一性原理的时候，才发现原来自己自我感觉良好的数学基础是多么地不堪一击」
- 「当初我第一次看到这个结论的时候，是极为震惊的！」
- 「我们就假装不存在这档子事儿，也丝毫不妨碍我们去解决工程问题，学习 AI」

## 真 AI 腔（改）vs 作者口头禅（留）

### 一律改掉（真 AI / 教材 / 公文）

值得注意的是、让我们来、总而言之、综上所述、不难发现、不难看出、需要指出的是、深入探讨、全面分析、起着至关重要的作用、由上可知、显然（装懂时）、易得、易证、首先…其次…最后…、表现优异、具有显著优势、综合来看、今天我们来聊聊、随着 AI 的发展

### 作者长文口头禅——禁止当 AI 腔删

然而、其实、本质上、事实上、实际上、某种程度上、不过、当然、话说回来、嘛、呗

这些词出现在原声或作者同款推演里，留下。只有写成套话时才改，例如「本质上来说，我们可以发现……」。

## 红线

- 原声句逐字保留；允许的唯一改动是明显错别字
- 禁止把口语改成书面语，禁止补专家口吻，禁止每段加总结句
- 禁止改成总分总或排比段
- 禁止为凑「人味」编造作者没写过的第一人称发现戏（「我盯着公式看了十分钟」「我差点把键盘摔了」）。raw.md / 原声槽里没有，就不要编
- 禁止用「人味儿八法」配额（埋我×3、闲笔×2）当验收——那是工艺参考，不是作者习惯
- 禁止把作者长句拆成贴图短打或「这是真的，不是段子」新闻腔
- 禁止用「说人话就是」当正文标签；人话直接说
- 话题标签保留 `#数解AI` 及作者原有标签风格

## 不像作者的鉴别信号

- 总分总、排比、每段小结、客观中立转述腔
- 真 AI 连接词套装（值得注意 / 综上所述 / 不难发现 / 让我们来）
- 贴图里没有第一人称使用经验；长文里没有「我怎么学通的」
- 编造的具名角色故事、配额式「我第一次」
- 一句一段的短打新闻腔（昨今混稿贴图的特征）
- 正文里出现「说人话就是：」
