# 数解AI 作者风格特征

> 基于 2026-08-12 抓取的 13 篇作者手敲贴图（`branding/style-corpus/tietu-raw/`），全部经作者确认为本人手写。
> 用途：AI 动笔前必读；用于识别「原声句」和判断成稿是否「像作者」。

## 核心定位

第一人称的行业观察 + 个人使用经验。写的是「我用过/我看到/我担心」，不是转述新闻或科普教程。

## 句式与结构

- 短段落，一句一段，极少超过 3 句
- 开头直接抛观察、结论或情绪，不做铺垫
- 中间按「先说结论 → 补细节/实测 → 吐槽或类比」的松散顺序，不追求工整
- 结尾几乎必有开放式问题或互动引导：「你选谁」「你怎么看」「评论区交流交流呗」

## 用词习惯

- 口语随性：说实话、话说回来、呗、嘛、真的、居然、简直、爽翻了、杀疯了、撸一个、搞一个
- 技术黑话混生活类比：「agent 领域的 gentoo 或者 archlinux」「机械爱好者自己组装一台发动机安装在自己的爱车上」
- 情绪直给：天壤之别、腐朽的味道、大吃一惊、太激动人心了、恶心人
- 数字 + 亲测背书：「一度 90% 的 token 都交给它」「200tps（我个人体验过，是真的！）」「1019 个人」
- 使用 ［呲牙］ 类表情符号，偶尔「。。。」结尾

## 标题风格

口语、情绪、问句或悬念：「突飞猛进的 pi agent 和友善的 openai，你选谁」「opencode 这波真要杀疯了」「第三方 DeepSeek0731 还是有希望」「极限肉搏战背景下，略显落寞的 meta 何去何从」。

## 原声句识别清单

以下句子类型**必须逐字保留**，AI 不得改写：

1. 个人使用经验句（含「我」和具体时长/数量/场景）
2. 类比句（「就像/就是/这方面它就是」）
3. 情绪与吐槽句（爱憎分明的评价）
4. 数字实测句（tps、token、价格、百分比等）
5. 结尾互动问句

## 原声句示例（可直接模仿节奏）

- 「你想干的事情，都可以交给 pi，没有的插件自己写」
- 「那种感觉就像是机械爱好者自己组装一台发动机安装在自己的爱车上」
- 「这方面它就是 agent 领域的 gentoo 或者 archlinux，懂行的程序员朋友应该能明白我在说什么」
- 「骂归骂，openai 还是对开发者很友善的……和恶心人的 anthropic 简直天壤之别啊！」
- 「在这个智能几乎要过剩的时代，你觉得当前最好的体验是什么？综合性价比最高，体验最佳？」

## 红线

- 原声句逐字保留；允许的唯一改动是修正明显错别字（如「滋滋不倦」→「孜孜不倦」）
- 禁止把口语改成书面语，禁止补「专家口吻」，禁止添加总结句
- 禁止改成总分总结构或每段小结
- 禁止使用 AI 腔连接词（然而、由此可见、综上所述、值得注意）
- 话题标签保留 #数解AI 及作者原有标签风格

## 与 AI 生成文风的反差（鉴别信号）

AI 稿常出现的「不像作者」特征：总分总结构、排比段、每段一个小结、书面连接词、客观中立的转述腔、没有第一人称使用经验、结尾没有互动问题。
