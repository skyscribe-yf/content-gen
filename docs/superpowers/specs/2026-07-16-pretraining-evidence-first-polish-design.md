# 预训练文章：证据优先的润色设计

## 目标

将 `content/2026-07-27-预训练/weixin.md` 从“低 loss 必然意味着能力阶梯／理解”的叙事，改为一篇以受控实验证据为中心的预训练解释文章。读者应能区分三件事：更好的 next-token 预测、可迁移的能力表现、以及理解或主观体验；后两者不能由前一者直接推出。

## 已确认的写作决定

- 核心结论：预训练可以产生看似理解的行为，但本实验不构成理解或意识的证据。
- 4090 实验是受控反例：验证 PPL 下降、局部语言模式更像故事；长程叙事依然模板化且容易复读。
- “涌现”仅保留为受限术语：本文观察到的是局部、渐进的表现改善，没有 PPL 或生成质量的突变式相变。
- 《西部世界》仅作 300–450 字的轻微剧透思想实验；它追问行为复现是否带来第一人称体验，不充当科学证据。
- 诚实限制直接放在实验正文：33,739,776 参数、单一中文故事分布、约 790.1M 训练 token，不能外推到前沿模型，更不能检验意识。
- 图像和封面不在本次改稿范围；只替换既有图片附近的说明与 alt 文案，如其含有不成立的能力阶梯。

## 正文结构

### 1. 开头与标题

- 标题改为关键词前置且不超过 22 字。推荐：`预训练：猜下一个 token，为什么会写文章？`。
- 保留 GPT-2 的历史钩子，但删除“训练方法从头到尾没有变化”这种过强说法；改为“自回归 next-token 预测仍是核心目标之一”。
- 开头的问题从“凭什么能理解世界”收束为“为什么一个预测目标会产生可迁移的语言能力”。

### 2. 交叉熵：修正数学对象与推论

- 保留 one-hot 训练标签下的 **H(p,q) = −log q(观测到的下一个 token)**，并用 Unicode 公式。
- 将 **H(p,q) = H(p) + DKL(p‖q)** 说明为总体／条件分布层面的关系；单个 one-hot 样本的熵为零，不能同时把它说成“语言天然的不确定性”。
- 将“互联网文本真实分布编码知识，所以模型必然懂得知识”替换为：低交叉熵奖励对数据中规律的可预测压缩；这种压缩可支持泛化，但不保证事实性、因果模型、推理或理解。
- PPL 旁加可比性边界：只能在相同语料、切分与分词器下横向比较；它不是跨模型的智力分数，也不是意识量表。

### 3. 正式实验：用真实证据取代射雕 toy demo

- 删除旧的 82 万参数／2.4 万字《射雕》训练、其虚构的阶段样例以及“loss 归零后仍变好”的结论。
- 用正式实验的可核验信息替换：50 万篇中文故事，按故事划分训练 490,011 篇／验证 9,989 篇；8 层、512 hidden、8 头、8,192 BPE、256 token 上下文、33,739,776 参数；RTX 4090 D；两段共 90 分钟训练、24,112 步、约 790,102,016 token；最佳固定验证 PPL 50.7278（step 24,100）。
- 使用合并训练时间轴曲线，不使用续训重置后的原始 `elapsed_seconds`；把 0–60 分钟和 60–90 分钟明确为纯训练时间。
- 选用可复查的固定验证前缀生成：展示由随机碎片转向局部故事模板，同时保留复读、人物／事件衔接不足的反例。每条样例标出里程碑、解码方式与“固定验证前缀”。
- 增加“实验能说明／不能说明”小节：独立验证集优于训练 loss 作为泛化证据；但单语料、小模型、单次运行和定性生成均限制结论。

### 4. 从能力表现到“理解”的边界

- 删除固定的 `PPL 500→100→20→5→2` 能力阶梯，以及“不同尺度必然突然涌现”的表述。
- 改为三层区分：预测损失、任务／生成表现、理解与主观体验。指出测评中可能出现非线性或阈值形态，但阈值依赖任务、指标与尺度，本文没有观察到突变。
- 将 scaling law 写成经验规律而非“尚未撞墙”的保证；所有模型版本、参数、训练 token、日期及能力比较必须在改稿当天以官方技术报告或 Hugging Face `config.json` 复核并贴出来源。
- 以当日可核验的国产模型实例作延伸，不把未证实的 DeepSeek V4 参数、训练数据或“所有开源最强”写入正文。

### 5. 《西部世界》思想实验与结尾

- 放在能力边界之后、RLHF 过渡之前。只使用准确且可轻微剧透的 Forge 行为档案与 James Delos 不稳定复制实验；不混同为“Dolores 翻某人的记忆书就完美复刻某人”。
- 将核心问题落在：若一个系统能根据行为记录预测、模仿、对话，它是否因此拥有那个主体的第一人称体验？本文不回答这一哲学问题。
- 过渡句明确：RLHF 改善可用性、对话和约束，不是意识的解决方案。
- 结尾互动问题改为开放的经验问题，例如“什么证据会让你把‘像理解’与‘理解’区分开？”；保留系列合集链接与关注引导。

## 验收标准

- 不再出现“低 loss 证明真正理解”“PPL 固定区间对应固定能力”或“本实验观察到突然涌现”。
- 每个实验数字均可回链到本地导出证据；续训时间轴不重复计时。
- 交叉熵、KL 与 one-hot 标签没有混用“单样本标签分布”和“语言总体条件分布”。
- 西部世界段不超过全文的 10%，不当作实证，不暗示 RLHF 解决意识。
- 标题关键词前置、≤22 字；数学完全为 Unicode；微信链接、尾部合集、互动问题和系列回引均符合项目规范。
- 草稿完成后执行文章质量清单、事实来源检查和 Markdown 公式／图片路径检查。
