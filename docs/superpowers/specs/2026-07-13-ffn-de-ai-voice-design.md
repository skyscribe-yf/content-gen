# FFN 文章去 AI 味语言修订

## 目标

让 `2026-07-21-FFN/draft.md` 更像作者在推进一个技术判断，而不是在逐条讲授答案。

## 保留

- 技术结论、Unicode 公式、完整可运行实验与实际输出。
- 5 张配图、DeepSeek 配置旁注、MoE / 残差系列回引。
- 开头的反直觉问题与结尾的开放式提问。

## 修订规则

1. 删除替读者复述结论的解释腔，例如“这也澄清一个容易混淆的点”。
2. 把整齐排比和模板化段首（如“第一步、第二步、最后”）改为随推理自然推进的叙述。
3. 用具体主语与动作替换泛化判断（如“这意味着”“需要注意的是”）。
4. 只做措辞和句序调整；不以满足 API 长度为理由删减论证、实验或叙事节奏。

## 验收

- 读者仍能顺着“注意力写入上下文 → FFN 独立加工 → MoE 延伸”的主线读完。
- 不改变实验结果、引用链接、标题、摘要和图文位置。
- 全文不新增 LaTeX 定界符。
