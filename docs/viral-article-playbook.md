# 爆款经验手册（>300 阅读文章复盘）

数据基础：2026-08-20 审计，56 篇文章中 7 篇阅读 >300（已排除贴图），另有低阅读对照组。
关键前提：**账号推荐流量占比 84~86%**（2026-08），爆款 = 被「看一看」算法选中，粉丝阅读贡献极小。
因此决定因素排序：**选题+标题（点击率）→ 开头前两段（完读率）→ 结构闭环（分享/二次分发）**。

> ⚠️ **2026-08-22 修正**：流量主力是**贴图**（图片消息，item_show_type=8），不是文章！
> 30 天阅读 >1,000 的 8 篇中 6 篇是贴图（opencode 5,433 / opencode go 1,759 / pi agent 1,373 / 严重过拟合 1,312 / QWen3.8 1,152 / 第三方DeepSeek 1,072），文章仅 2 篇（KV缓存 2,604、高维空间 1,356）。
> **双轨道爆款密码不同**：贴图 = 当期热点 + 情绪词/强立场标题 + 3~6 图 + 200~1000 字手敲文本；文章 = 反直觉疑问句 + 场景钩子开头 + 悬念链结构。
> **2026-08-18 起推荐断崖教训**：连续 6 天纯理论连载文（矩阵秩→Q-learning→策略梯度→随机变量→多维高斯→协方差→高斯二阶），新文推荐几乎归零（单篇 33~248 阅读），每日推荐量 1,450→451。**系列续集标题/开头 + 内容与账号画像偏离热点 = 被推荐池降权。**

## 二、标题公式

**反直觉疑问句 = 反常陈述 + 「为什么/怎么」**。7 篇爆款 6 篇命中：

- 数字反差：「慢 50 倍的硬盘，为什么反而更快」「56 层比 20 层还差」「1 万条数据就能听话」
- 否定常识：「为什么不直接取最大值？」「为何不用 MLA？」
- 痛点提问 + 动作承诺：「学习率怎么自动调？……拆给你看」
- 关键词前置：DeepSeek-V4 / KV缓存 / SSD / MLA / Adam / Softmax（搜一搜 SEO）
- 唯一的非疑问句用比喻补悬念：「内积才是那把尺子」

反例：「打分标准决定学习方向」——陈述句、无反差、无悬念。

## 三、开头规则（前两段定生死）

TOP 4 爆款开头零导航，三选一钩子：

1. **场景对比**：「你丢了 100 万字文档等十几秒；同事问同一问题，秒回」（KV缓存）
2. **个人故事+情绪**：「恨不得给当年的自己一拳，这东西将来是 AI 的基石」（高维空间）
3. **行业冲突/直接抛问题**：「每个参数都要走同样大的步子吗？不行。」（Adam）

**禁止**系列导航/「上一篇我们……」开头——推荐流量里 99% 是陌生人，开头放导航 = 劝退。
系列承接内容移到驱动问题之后或文末。

## 四、结构规则

**A 类（叙事弧线，全部 ≥990 阅读）**：
- 小标题连起来就是完整故事链。KV缓存 8 节：为什么慢 → 为什么划算 → 怎么对齐 → 什么能存 → 取舍 → 对手方案 → **为什么秒回**（回应开头场景）。
- 链路：场景钩子 → 机制拆解 → 论文数字验证 → 回扣开头。**开头的问题最后一节必须被回答**。

**B 类（固定模板，上限 300~1100）**：🎯驱动问题 → 💡直觉 → 📐数学 → 🔧实现 → 🔄回扣。
模板保下限，但「数学原理」「算法实现」这类功能标签不构成悬念链。**小标题要写成悬念链**，少用功能标签。

## 五、分享钩子

实用工程结论（省钱/提速类）分享率最高：Adam 24.4、KV缓存 10.4。高维空间分享率实测达 **19.8%**（267 次分享 / 1,349 阅读，08-22 数据）——「认知颠覆型」同样高分享，但需要故事/比喻铺垫。
纯概念解释分享率低：Softmax 2.5、SFT 2.7。
选题优先级：痛点（慢/贵/反直觉）+ 绑当期国产热点模型（DeepSeek 解密系列期间产出 3 篇爆款）。

## 六、贴图轨道（图片消息，真正流量主力）

30 天阅读 >1,000 有 6 篇贴图，标题公式与文章不同：

- **当期热点 + 情绪/强立场**：「杀疯了」「即将反转」「还是有希望」「评分接近（Kimi）」
- **利益相关 + 悬念**：「第三方 DeepSeek 0731 还是有希望」（涨价受害者视角）
- **内容形态**：3~6 张图 + 200~1000 字手敲 digest，原声句保留，AI 只整理图表
- ⚠️ **必须开启群发通知**：08-18 后贴图「未开启群发通知」且内容单薄，阅读跌到 18~64（opencode 背刺 18 / Jspace 64），对比 08-16 前的 1,000+
- 贴图不做「反直觉疑问句」——那是文章轨道的公式，别混用

## 七、掉量反例（2026-08-18 起，推荐断崖）

连续 6 天纯理论连载文期间（08-18~08-22），单篇阅读全部落进 33~248：

| 日期 | 标题 | 阅读 | 问题 |
|---|---|---|---|
| 08-20 | 多维高斯：为什么同一步长差1万倍？ | 36 | 开头即「上一篇……那把尺子今天拿出来」= 系列导航开头顶格违规 |
| 08-21 | 协方差矩阵：1个方差怎么变9个数？ | 60 | 标题同系列续集感 + 开头「上篇……拆开看」 |
| 08-21 | 高斯为什么二阶就够？ | 216 | 开头 2 句内两次提及「上篇/捆绑同日推送」 |
| 08-19 | 策略梯度是什么？ | 33 | 同上，系列承接开头 |
| 08-18 | Q-learning是什么？ | 42 | 拐点日，推荐量 1,450→451 同日落 |

**红线复核**：① 标题/开头禁止「篇N」「上篇」「拆给你看（续集口吻）」；② 禁止连续 >2 天纯理论连载，每篇须绑热点或工程痛点；③ 系列衔接信息全部后置到驱动问题之后或文末。

**2026-08-22 二次复核（同天双发对照，作者质疑后）**：数学直觉篇 vs 强化学习原理篇差别极大，开关在开头类型：

- 数学篇 08-18~08-21：矩阵秩 196（个人故事开头）、随机变量 248（直接抛问题开头）、高斯二阶 216（反直觉提问开头）、协方差 60（**数学篇唯一「上篇」系列开头**——系列开头连数学篇都救不了）
- RL 篇 08-16~08-20：MDP 50、Bellman 81、Q-learning 42、策略梯度 33、多维高斯 36——5 篇里 4 篇开头第一句就是「在上一篇/上一篇结尾说过」。
- **对照组结论**：同一天、同群发、同粉丝基数，「独立钩子开头」≈ 200 级阅读，「系列导航开头」≈ 30-80 级。标题公式只加分不救命（多维高斯标题是合格反直觉型，仍 36 读）。「XX是什么」式标题（Q-learning是什么/策略梯度是什么）信息缺口弱，改反直觉冲突式。
- MDP 是唯一独立开头但 50 读的 RL 篇：系列首篇无存量 + 当天贴图（严重过拟合 1304）抢走推荐，属例外；TRPO（08-22 场景开头）为下一个验证点。

**RL 系列改造规则（2026-08-22，DeepSeek 系列已结束，RL 原理是当前主线）**：

1. **标题**：禁「XX是什么」解释型（Q-learning是什么/策略梯度是什么 = 无信息缺口）；用反直觉冲突 + 场景数字（范例：TRPO「梯度一步踩爆50倍预算」、KL散度「为什么整个AI共用一把尺子」）。
2. **开头**：三选一独立钩子（场景对比/个人故事/反直觉提问），禁「在上一篇/上一篇结尾说过」。**系列连续性靠「同一个故事主角」维持**（coding agent 修 bug 连续剧），不靠篇名引用——读者从中间篇进入也应能独立看懂。
3. **术语门槛**：每篇 ≤2 个新术语，其余用比喻（账本/转盘/步子大小）；新术语首次出现给一句话人话版。
4. **锚点**：钩读者已有知识（KL 散度篇开头勾 VAE/扩散/TRPO「名字都不换」是范例）；数学铺垫篇（高斯/概率论/矩阵）穿插在 RL 篇之间，既是系列必要铺垫也是读者更爱吃的菜（数据：数学篇 196-248 vs RL 篇 33-81）。
5. **预期管理**：RL 题材受众天然窄（大模型原理期 RLHF 26/PPO 58/GRPO 77/RLVR 65 同样从未起量），目标设为稳定 150-300 阅读 + 涨粉 + 搜一搜长尾，不做千读预期；推荐恢复需连续 3-5 篇独立开头高质量文。
6. **机动轨道**：行业热点出现时（DeepSeek 涨价类）顺手发贴图抢推荐，与 RL 主线互不干扰，但不再依赖热点做主线。
