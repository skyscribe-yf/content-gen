# 文章标题：痛点 + 搜一搜关键词双驱动

**规则**：标题必须同时满足两个目标——**人想点**（点击率）+ **算法能搜到**（搜一搜 SEO）。AI 生成初稿标题后，必须按本规则改写。

**原因**：
- **点击率维度**：学术标题（如「损失函数：打分标准决定学习方向」）只有已入门的人会点，而这类人早已关注大号。冷启动阶段，标题要抓住「想学但还不会」的人。
- **搜一搜维度**：微信搜一搜日活超 5 亿，搜索结果前三名点击率 60%。标题中的关键词是搜一搜排名的第一信号，但算法已从「标题精准匹配」转向「语义理解 + 全文意图匹配」，所以关键词要自然嵌入，不能堆砌。

## 搜一搜排名机制（标题相关）

微信搜一搜采用 **Peoplerank 算法**（以人为中心的信任排序），标题影响排名的三个层面：

| 因素 | 权重 | 说明 |
|------|------|------|
| 关键词匹配 | ⭐⭐⭐ | 标题前半段的关键词权重最高；语义近义词也能被识别（如「减脂」≈「瘦身」） |
| 标题热度/价值性 | ⭐⭐⭐ | 公众号推流评估标题的「热度」和「价值性」结构，如「为什么 + 原因1、原因2」比纯名词堆砌得分高 |
| 用户点击行为 | ⭐⭐ | 搜一搜结果中，标题决定点击率；点击率影响后续排名，形成正/负循环 |

**关键认知**：搜一搜排名不再只看标题关键词，而是看**全文是否真正解决用户搜索意图**。标题引流进来，内容留不住人（低完读率、3秒跳出），排名反而会降。所以标题不能标题党，必须与内容高度一致。

## 标题公式：点击力 × 搜索力

每个公式标注「搜索力」——即对搜一搜排名的贡献度：

| 公式 | 结构 | 搜索力 | 示例 |
|------|------|--------|------|
| 痛点问答型 | 用户问题 + 悬念答案 | ⭐⭐⭐ | 模型不收敛怎么办？90% 是学习率设错了 |
| 类比型 | 日常比喻 + 术语锚点 | ⭐⭐ | 训练 AI 就像教小孩：为什么骂太多反而学不会？ |
| 反常识型 | 认知反转 + 关键词 | ⭐⭐⭐ | Softmax 不是取最大值——它为什么更温柔？ |
| 场景数字型 | 具体场景 + 量化对比 + 关键词 | ⭐⭐⭐ | 学习率 0.1 vs 0.001：训练效果差了 10 倍 |
| 教程攻略型 | 「如何/怎么」+ 动词 + 目标 | ⭐⭐⭐⭐ | 如何选择损失函数？3 种场景 3 种答案 |
| 对比评测型 | A vs B + 结论悬念 + 关键词 | ⭐⭐⭐ | MSE vs 交叉熵：谁让模型学得更快？ |

**搜索力说明**：
- ⭐⭐⭐⭐ = 包含用户高频搜索句式（「如何」「怎么」「XX vs XX」），搜一搜直接命中
- ⭐⭐⭐ = 包含核心关键词 + 信息缺口，兼顾点击和匹配
- ⭐⭐ = 依赖语义理解匹配，搜一搜能识别但不够直接

## 关键词布局规则

标题中必须包含 **1 个核心关键词**（搜一搜精准匹配用），位置尽量靠前：

```
✅ 损失函数怎么选？3 种场景 3 种答案       ← 「损失函数」在第1位
✅ 学习率调不好？试试这 3 个实用技巧         ← 「学习率」在第1位
❌ 为什么你的 AI 越训练越笨？               ← 没有任何专业关键词，搜一搜难以匹配
❌ 深度学习 损失函数 优化技巧 全面解析        ← 关键词堆砌，被算法降权
```

**挖词方法**：在微信搜一搜输入核心词（如「学习率」），观察下拉推荐词——这些是用户真实搜索词，直接用作标题关键词。

## 标题自检清单（6 条）

写完标题后逐条检查，任一条不通过就重写：

1. **有关键词吗？** 标题中包含至少 1 个用户会搜的专业关键词，且位置在前半段
2. **小白能懂吗？** 不懂术语的人看到标题，是否知道这篇文章跟自己有关？
3. **有点击冲动吗？** 标题是否制造了信息缺口（「想知道答案」）？
4. **没有术语堆砌？** 标题中出现 ≥2 个专业术语 → 删到只剩 1 个，或换成比喻
5. **不超过 22 个字？** 微信信息流只显示前 22 字，核心信息必须在前半段
6. **不是章节标题？** 「损失函数：打分标准决定学习方向」是目录/章节风格，不是文章标题

### 验证结论

1. **不要将账号日新增关注归因给单篇标题**：推广、互助群和发布时点同时影响新增关注。此前“某篇文章带来多少粉”的表述只能视为同日相关性，不是单篇转化率。
2. **文艺比喻标题的累计阅读仍最低**：「蒙着眼下山」现为 37 读，且缺乏专业关键词；但文章年龄与分发不同，需在同等分发条件下继续验证因果。
3. **教程攻略型升为首选公式之一**：Adam「怎么自动调」109 读、全站第 3，与痛点提问、反常识提问并列推荐。后续 BPE / 词嵌入 / 位置编码优先「怎么/为什么 + 关键词前置」。
4. **「反常识提问 + 具体数字」仍是有效候选公式**：残差连接 93 读、留言高。高阅读信号 ≠ 已证实吸粉因果。
5. **推广与发布节奏会掩盖标题差异**：损失函数 152 含推广；MoE 14 含连发+无推，**不能**据此否定场景数字型标题。
6. **文章会持续累积阅读**：老文仍在涨；标题评估分「首日曝光」与「长期搜索入口」两维。
7. **推荐 31.5%、搜一搜 1.5%**：推荐飞轮在转；SEO 仍严重不足，摘要 2–3 关键词必须执行。
8. **低阅读 + 高分享率优先补分发**：MoE 14 读但分享约 8、留言 6——先二次推广，再改标题。

## 标题生成流程

1. **先定关键词**：从文章核心概念中提取 1 个用户最可能搜索的词（用搜一搜下拉词验证）
2. **再套公式**：围绕关键词，用 2-3 个不同公式产出候选标题
3. **按自检清单打分**：6 条全过才算合格
4. **最终标题写入 frontmatter 的 `title` 字段**
5. **同时将关键词写入 frontmatter 的 `keywords` 字段**（数组），方便后续搜一搜数据分析
