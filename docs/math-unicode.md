# 数学公式：使用 LaTeX（推荐）或 Unicode

**规则**：公众号文章的 Markdown 源文件中，优先使用 LaTeX 语法（`$...$` 和 `$$...$$`），由 `baoyu-markdown-to-html` 通过 KaTeX + CSS 内联方案渲染为微信兼容的 HTML。

**原理**：渲染流程为 LaTeX → KaTeX HTML → 样式内联 → 微信兼容的 `style` 属性（mdnice 同款方案）。无需外部 CSS，微信不会清洗。

**备选**：简单公式可用 Unicode 手写，但复杂公式（矩阵、积分、多行）必须用 LaTeX。

**Unicode 替换对照表**：

| LaTeX | Unicode | 示例 |
|-------|---------|------|
| `\frac{a}{b}` | a/b | ∂L/∂ŷ |
| `\sum` | Σ | Σ(yᵢ − ŷᵢ)² |
| `\partial` | ∂ | ∂L/∂x |
| `\nabla` | ∇ | ∇f(θ) |
| `\theta` | θ | θₜ₊₁ |
| `\alpha` | α | α·∇f |
| `\hat{y}` | ŷ | y − ŷ |
| `\log` | log | log(p) |
| `\times` | × | 2 × 0.99 |
| `\approx` | ≈ | 1/0.49 ≈ 2.04 |
| `\in` | ∈ | y ∈ {0,1} |
| `_{i}` | ᵢ | yᵢ, ŷᵢ |
| `_{t+1}` | ₜ₊₁ | θₜ₊₁ |
| `^{2}` | ² | (y−ŷ)² |
| `-` (减/负) | − (U+2212) | −1/ŷ |
| `\cdot` | · | y·log(ŷ) |

**独立公式写法**：不用 `$$...$$`，直接用普通文本段落，居中效果由 HTML/CSS 处理。

```
❌ $$ L_{MSE} = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2 $$
✅ L_MSE = (1/n) Σ(yᵢ − ŷᵢ)²
```

**内联公式写法**：不用 `$...$`，直接写 Unicode。

```
❌ 梯度被 $p(1-p)$ 因子压扁
✅ 梯度被 p(1−p) 因子压扁
```

**自检**：无需特别检查——KaTeX 渲染引擎会自动处理所有 `$...$` 和 `$$...$$` 语法。

### 公式样式（仅 Unicode 备选方案适用）

使用 LaTeX 方案时，公式样式由 KaTeX 自动渲染，无需手动包裹引用块或加粗。

**仅在使用 Unicode 手写公式时才需要**以下手动样式：

独立公式（独占一行的）用**引用块**包裹，让渲染后带背景色和蓝色左边框，与正文区分：

```
> **L_MSE = (1/n) Σ(yᵢ − ŷᵢ)²**
```

渲染效果：浅灰背景 + 蓝色左边框 + 加粗蓝色字体，视觉上明显突出。

内联公式（嵌在句子中的）用**加粗**标记：

```
MSE的梯度被 **p(1−p)** 因子压扁了
```

渲染效果：蓝色加粗字体（grace 主题的 strong 标签样式为 `color: #0F4C81; font-weight: bold`）。

**公式样式三原则**：
1. 独立公式 → 引用块 + 加粗（背景 + 蓝字）
2. 内联公式 → 加粗（蓝字）
3. 公式绝不能和正文用相同样式——读者一眼就要能区分
