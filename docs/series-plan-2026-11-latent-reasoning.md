# Latent 思维链 · 四篇系列写作计划

> 2026-11-17 建立，pre-grill。作者拍板「分 4 篇」后立项，系列计划先行，逐篇 grill 收敛后才写大纲。

## 0. 一句话结论

**AI 不写字的思维链（latent reasoning）已从论文技巧变成架构范式：四条机制路线里只有一条悄悄进了旗舰产品，而它最大的问题——思维链消失之后，没人能监控 AI 在想什么——恰好是 2026 下半年最受关注的理论问题。**

## 1. 先分层，防张冠李戴

写任何一篇之前必须先分清这三个经常被混为一谈的东西（笔记 §10）：

- **隐藏思维链**：思维链照常逐 token 生成、占上下文、按输出计费，只是 API 不返回。是**显示策略**。
- **Latent reasoning**：根本没有思维链 token，计算发生在隐状态 / 循环里。是**计算机制**。
- **两者正在收敛**：invisible reasoning（arXiv:2607.22925）证明 13 个前沿模型上 filler token 显著涨点——「隐藏思维链」里本来就有 latent 计算成分，只是没人训练过它。

完整光谱（笔记 §10.2，行文可直接引用）：

```
① 显式可见 CoT ──────── DeepSeek V4 thinking（全量流式可见，四家唯一）
② 摘要式 CoT ────────── GPT-5.6 Sol / Claude 默认（abridged summary）
③ 完全隐藏 CoT ──────── token 存在，用户不可见，厂商可读
④ 哑 token 推理 ──────── pause / filler tokens（token 无语义，计算不可见）
⑤ 抽象 token 语言 ────── Abstract-CoT（离散端压缩，过渡带）
⑥ 连续 latent thought ── Coconut / CODI（无 token，向量）
⑦ 循环/隐藏计算 ─────── Ouro、Astra recurrent depth、Hidden Decoding
⑧ neuralese（极限概念）── 模型完全在私有稠密表示里思考与交流
```

③ 是隐藏思维链；④–⑦ 是 latent reasoning；⑧ 是安全学界想象的下限状态。

## 3. 每篇细案

### 3.1 L1 机制：AI 不写字也能做题

**核心问题**：不往上下文里写任何一个推理 token，计算往哪放？四条路线各自把思考塞进了哪个维度？

**主落点**（全部经 article-researcher 2026-11-17 开原文核到版本/日期/口径，brief 见 `.grill/2026-11-22-latent-reasoning-four-routes-research.md`）

- **2607.22925**（*Not All LLM Reasoning is Visible in the CoT*，v1 2026-07-24 / v2 2026-09-03，NYU+UMD+TogetherAI）：13 个前沿模型 × 3 个合成任务（4 位乘法、多步算术、代码变量计数），10-shot，filler = 计数 token「1–100」，Δ 相对无 filler 基线。**Gemini 3 Flash 算术 51.0→61.7（+10.7pp）**为最稳主数字；乘法 +1.0 不显著；Opus 4.6\* 算术 +30.0 有选择效应（API 不支持 assistant prefilling），禁当主数字；摘要「up to 13pp」与表 1 口径不一致。
- **同论文负面结果（必须进稿）**：RL 让 Qwen3-235B 形成 filler 偏好，但「neither RL nor SFT produces a filler token benefit that persists at test time」；Qwen3-235B 计数 filler 零涨点。**「隐藏里本来有 latent 成分」成立，「训练能放大」不成立。**
- 隐藏约束实验：Claude Opus 4.5 可不牺牲主任务暗中满足模运算约束（安全叙事承重证据，留给 L3）。
- **四路线编号（已核）**：A = 2310.02226（Goyal，ICLR 2024）/ 2404.15758（Pfau，filler '......' 两道算法任务，需密集监督）；B = 2412.06769（Coconut，COLM 2025，BFS 涌现）/ 2502.21074（CODI，GPT-2 规模 GSM8k 追平显式 CoT、3.1× 压缩）；C = 2607.08186（WeLM，47 作者，n=4，80B/617B）；D = 2502.05171 / 2510.25741（Ouro，Geiping 等 33 作者，7.7T token）。
- **WeLM 官方博客已通读**（welm.weixin.qq.com，2026-07-14）：九基准全涨（SciCode 45.8→50.0、PHYBench 69.8→73.8、GPQA 87.6→88.8）；「所有数字均为自测结果」；n=4 单 batch 5.1×（80B）/ 4.4×（617B）；探针显示各流隐状态余弦 0.987→0.637→0.783、最终流读取中间流（峰值 0.52）。**定位研究博客，未确认上线微信产品线。**

选型一句话：A = 零风险试水但天花板低；B = 最纯 latent 但训练最重；C = 工程最干净、唯一验证到前沿规模；D = 参数效率最高但工程代价最大。

**反常识**

- 「让 AI 多想一会」不等于「让 AI 多写点」——A/D 把思考放进 prefill / 深度循环，不占输出 token、不按输出计费。
- Ouro 的关键实证：looping 扩展的是「知识操纵/组合」能力，**不是**「知识存储」——Capo 合成任务上 bits/parameter 与标准模型无差异，但多跳推理显著增强（此条留给 L4，L1 只埋一句）。
- 四条路线不是竞争关系，是按「你能付多少重训成本」分档的选型表。

** grill 已定（2026-11-17）**：

1. **叙事结构 = 概念辨析切入**：不平铺四条路线。光谱 ①–⑧ 逐档走一遍 → ③ 是显示策略、④–⑦ 是计算机制 → invisible reasoning 收敛点 → 收口「两个东西正在合流」。四条路线在光谱里各就各位，不当主菜。

3. 结构示意：钩子（filler 涨点）→ 光谱 ①–⑧ → ③/④–⑦ 分层 → 收敛（隐藏里本来就有 latent 成分）→ 收口（合流）。

### 3.2 L2 生产：唯一敢给你看思维链全文的

**核心问题**：2026 年 11 月，到底谁真的把 latent reasoning 上线了？为什么其他厂商不上？

**主落点**（笔记 §9，三度追加，2026-11-16）

- **Route D 唯一进旗舰**：GPT-6 Astra = 短 CoT + 有限程度 recurrent depth。⚠️「媒体报道加部分承认」，行文必须带这个限定，禁写成官方确认。
- **Route C 最大规模验证**：腾讯 WeLM（HD4-80B / HD4-617B）研究阶段，未确认上线。
- **Route A 第三方意外生效**：filler token 在生产模型上显著涨点（Gemini 3 某任务超 10%）。
- **厂商栈对比表**（§9.6）：DeepSeek V4 thinking mode **全量流式可见，四家唯一**；GPT-5.6 Sol / Claude / Gemini 3.x 均走隐藏 token 或摘要。
- **为什么其他厂商不上**：§9.7 五个真实障碍（与流水线并行不兼容、推理栈重写、训练成本、监控压力、商业动机）。
- **商业账**（§10.1）：输出 token 单价是输入的 3–5 倍；难 query 烧 1 万以上 hidden reasoning token，总成本 3–6 倍。**隐藏思维链在商业上是加价项，不是省钱项。**

**反常识**

- 「隐藏思维链更便宜」是错觉：token 照常生成、照常计费，只是不给你看。
- 最该害怕 latent reasoning 的不是竞品，是依赖 CoT 做监控的安全团队（留给 L3 收口）。
- DeepSeek V4 的「全量可见」在四家里是异类——这是品牌词钩子，也是本文与账号 DeepSeek 线合流的挂载点。

**标题候选（草标题）**

- 「唯一敢给你看思维链全文的旗舰模型，凭什么」
- 「烧掉 1 万个 token 的思考，为什么收 5 倍的钱」

**边界**

- Astra 的上线程度以媒体报道 + 部分承认为限，不写成官方规格。
- 价格数字（GPT-5.6 输入 15/输出 75 每 M、o4-mini 4.4、o1-pro 600 每 M、Sonnet 5 输出 10 每 M）写前必须实时现核，笔记口径截至 2026-11-16。

### 3.3 L3 监控：思维链消失之后

**核心问题**：CoT 监控是 2024–2026 安全界依赖度最高的工具；latent reasoning 把这条监控通道关掉了，剩下什么？

**主落点**（笔记 §3.3 + §10）

- 光谱 ③→⑧ 逐档走一遍：用户可读性、厂商可读性、faithfulness 概念是否成立，逐档关闭。
- 四个本质差异表（§10.3）：token 是否存在 / 成本结构 / 可监控性 / faithfulness——**latent reasoning 下「CoT 不忠实」这个概念本身消失，因为没有 CoT 可供不符**。
- invisible reasoning（arXiv:2607.22925）：13 个前沿模型 filler token 涨点 → 「隐藏」里本来就有 latent 成分 → 监控界以为在读思维链，读到的可能本来就不是完整计算。
- 三条桥梁（§10.4）：边界模糊、动机一致（都是测试时计算的答案，一个往贵的方向一个往便宜的方向）、Astra 是融合点。
- 邻域佐证：diffusion LLM 真正商业化（另一家族，Inception Mercury）——并行生成的推理同样不可读。

**反常识**

- 「模型把想法复现到答案里」是厂商的补偿机制，不是等价替代（OpenAI o1 发布原话可引）。
- 监控器本身正在成为被优化对象：latent reasoning 让「读思维链找 reward hacking」这条最常用的检查线失效。
- 接账号既有线：intent-formalization（11-04）已写「意图变规格没人能验」，本文是同一问题的模型层版本。

**标题候选（草标题）**

- 「AI 不写字思考之后，我们还怎么知道它在想什么」
- 「监控窗口正在关闭：思维链消失意味着什么」

**边界**

- neuralese（⑧）是概念下限，不是已有技术，行文必须标注。
- 不贩卖恐慌：给出可操作的替代（行为级评测、激活监控、probe），不停在「完了」。

### 3.4 L4 深挖：循环扩展的不是存储

**核心问题**：同一组权重反复应用 T 次（$h_{t+1}=f_\theta(h_t)$），多出来的能力到底是哪来的？

**主落点**

- Ouro 报告核心实证：Capo 合成任务上，**存储原始知识的 bits/parameter 与标准模型无差异，但多跳推理显著增强**——循环扩展的是「知识操纵/组合」，不是「知识存储」。
- 7.7T token 预训练 + 熵正则深度分配的训练细节。
- 架构合流：LoopMTP 把 latent MTP 接进循环 transformer；与 2026 混合线性注意力浪潮（KDA、Gated DeltaNet，见 MiniMax 架构演进笔记）天然合拍。
- **国产落点（待补，见 §5 缺口①）**：DeepSeek V4 的 mHC / CSA 与循环/潜变量计算的关系；GLM-5.2 / Kimi K2.6 / Qwen3 是否有同构设计。按账号硬规则，理论须挂最新国产模型并引 HF config.json。

**反常识**

- 「循环 = 重复利用权重换深度」听起来像免费午餐；Capo 结论给出了免费的部分（操纵）和不免费的部分（存储）。
- 1.4B ≈ Qwen3-4B 是特定任务口径，不是全面替代——这正是 L4 要拆穿的误读。

**标题候选（草标题）**

- 「不加参数，循环四次：多出来的推理能力从哪来」
- 「循环扩展的是「操纵知识」的能力，不是「存知识」的能力」

**边界**

- Capo 是合成任务结论，外推到真实任务需谨慎。
- 国产落点在 researcher 补核前不得预写。
