# 微信话题标签

## 规则

每篇 `weixin.md` 末尾**必须**添加微信话题标签（`#标签`），这是公众号搜一搜 SEO 和话题聚合的关键入口。

## 格式

```
#标签1 #标签2 #标签3 #数解AI
```

- 放在全文最末尾（系列导航 + CTA 之后），独占一行
- 标签之间用空格分隔
- 3-5 个标签，含品牌标签 `#数解AI`

## 标签选取

| 分类 | 说明 | 示例 |
|---|---|---|
| 系列标签 | 所属系列名，便于话题页聚合 | `#深度学习基础` `#大模型原理` `#DeepSeek技术解密` |
| 主题标签 | 文章核心概念 2-3 个，用于长尾搜索 | `#梯度下降` `#注意力机制` `#MoE` |
| 品牌标签 | 固定 `#数解AI` | `#数解AI` |

## 示例

```markdown
#梯度下降 #优化器 #深度学习基础 #数解AI
```

⚠️ 2026-11-07 起尾部不再有 `📖 合集导航` 行（上一篇示例里的旧写法已废止），标签行直接接在参考资料之后。

## 核查

发布前检查清单（`docs/article-quality-check.md`）中包含话题标签项。
