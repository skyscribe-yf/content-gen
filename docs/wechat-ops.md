# 公众号运营规则

## 发布节奏

**规则**：每天最多发布 **1 篇**文章，日更节奏。

**当前策略**（2026-07-25 起）：文章总数不足 100 篇，先冲量。日更优先，运营数据优化后置。等文章基数上来后再根据数据回调节奏。

**历史数据**（供日后回调参考）：
- 间隔 ≥2 天时，推荐位不互相稀释，每篇曝光更充分
- 连发三天 + 无推广时首日阅读显著偏弱（MoE 仅 14 读）
- 推荐来源占比 57.5%，是当前主驱动
- 日更可能稀释单篇推荐曝光，但总量不足时曝光池本身有限，日更的增量覆盖 > 稀释损失

**执行**：
1. 规划好发布日历，标记每篇的预计发布日期
2. 即使文章已写好，也不要同日发多篇
3. 固定节奏：每天 1 篇，于 20:00 发布；具体日期以 `draft-status.yaml` 为准
4. 文章总数达到 100 篇后，重新评估是否回调为隔天发布

### 🆕 推荐权重恢复期规则（2026-08-22 起，临时 1–2 周，**优先于上方日更节奏**）

**背景**：08-18 起推荐绝对量断崖（1,450→451，-69%），此后在 480–680 低位徘徊未恢复；账号级降权（8-18 后文章和贴图同时全崩，非单篇问题）。推荐配额是近 7-14 天滚动平均，需连续合格文重建，不可用单篇爆款救回。

**A. 止损清单（立即执行）**

1. **宁缺毋滥，允许断更**：内容不合格（标题不过 6 条自检 / 开头 100 字含「上篇 / 在上一篇」/ 文末无可回答问题）宁可当天不发。「合格才发」优先于日更，恢复期豁免日更考核。
2. **禁止同日双发同题材**：双发共享同日小流量池且互相稀释（8-18、8-21 双发日均垫底）。
3. **发布后不改标题/摘要**：修改可能中断/重置该文推荐分发（8-14 以来 6 次「已修改」皆发生在表现差的内容上，恢复期零容忍）；正文小修可，标题/摘要/封面不动。
4. **取消机动加发**：仅走 20:00 固定班次；8-19~8-21 加发贴图（06:46/07:30/16:25）全部失败。

**B. 质量门禁（恢复期加严条款，任何一条不过 → 不发，重写或缓发）**

在既有 `docs/article-quality-check.md` 13 项核查之上，恢复期额外执行 6 条：

1. **独立可读**：删掉全文所有系列回引（「上篇/下一篇预告/篇N」）后，文章是否仍然成立？删完就散架 = 不合格。测试法：把自己当「第一次刷到这篇的陌生人」从头读一遍，不懂的地方漏出。
2. **认知交付**：一篇必须交付至少一个「反直觉答案」或「能拿去用的工程结论」。术语搬运、课堂笔记式（「XX是什么→特性→总结」）判定不合格，即使是系列必需篇也要包裹在反直觉问题里。
3. **篇幅管控**：正文区间 3.5–5k（重数学篇可顶 5k；GAE 类最短 3k），**超 5k 必砍**；篇幅可以宽，但「开头 100 字内进入实质内容」是硬红线，加长部分只允许是推导/例子/细节，禁止铺垫与元话语（7.8k 元话语长文为反面教材）；「是否每个小标题都有不可删的推进」作为减字判据。
4. **术语人话**：每个新术语首次出现必须紧跟一句「说人话就是……」；「说人话」句缺失率 >0 即视为术语轰炸，逐处补。
5. **开头 100 字白盒检查**：开头 100 字里出现「上篇/上一篇/篇N/在上一篇」→ 直接不合格（高斯篇 216 读的引用块放在钩子之后才允许，且必须是对目标读者有信息量的内容而非导航）。
6. **文末问题 30 秒测试**：问题读者 30 秒内答不出（「你怎么看」「欢迎讨论」类）→ 不合格；合格模板：「你调学习率时踩过最狠的坑？报模型名和数值」。

**C. 修复动作（接下来 5–7 篇，滚动窗口重建）**

- 连续 5–7 篇全合规（TRPO、KL 散度已合规，为前两个合格样本），每篇目标：阅读 150–300、留言 ≥5、分享率 ≥10%；窗口内 ≥4 篇达标权重才回升，无捷径。
- **质量红线**：B 节质量门禁 6 条任何一条不过 **不发**——恢复期「质量断供」优于「凑合日更」，空窗期权重由历史文章长尾兜底。
- 互动强化（详见「互动引导」恢复期增量）：文末问题可回答性设计 + 发文后 1 小时内作者回复前 3 条留言 + 文末「一句话总结卡」给分享借口。
- **题材配比 RL : 数学 ≈ 1 : 1**：数学铺垫篇（KL 散度/概率论/矩阵/高斯）既是系列必需又是高天花板题材（对照：数学 196–248 vs RL 33–81），恢复期由数学篇当拉权重主力，RL 篇当系列推进。
- **锚点用账号内已爆词汇**：钩子优先钩「内积 / 高维空间的壳 / 注意力 / KV 缓存 / KL」，不用新术语当唯一锚点；强化账号标签一致性。

**C. 监控判据（只盯每日推荐绝对量）**

| 情况 | 判读 | 动作 |
|---|---|---|
| 连续 3 天 >800 | 权重修复成功 | 退出恢复期，恢复日更+正常选题 |
| 700–800 | 修复中 | 继续执行 B |
| 2 周后仍 <600 | 写法问题之外另有题材×画像错配 | 题材层调整：数学篇占主流，RL 篇挂现实中模型（DeepSeek/GLM 训练）重讲 |

**退出条件**：每日推荐绝对量连续 3 天 >800，本规则自动失效，恢复到「每天最多 1 篇、固定 20:00」日更节奏。

## 文章末尾关注引导

**规则**：每篇文章末尾必须包含**关注引导**，放在系列导航之后。

**引导内容**：
1. **价值承诺**（不是「求关注」）：告诉读者关注后能得到什么
2. **系列结构**：列出系列全部篇目，标明当前是第几篇，让读者知道后续还有什么

**模板**：

```
---
📖 **当前系列名**
① 第一篇 → ② 第二篇 → ③ 第三篇（本篇）→ ...

每天更新一篇，把大模型的底层原理讲到不用回头查。关注「数解AI」，下一篇第一时间推给你。

---
📖 **其他系列名**（已完结）
① [篇名](微信URL) → ② [篇名](微信URL) → ...

🔥 **DeepSeek 技术解密系列**（对应原理讲完后发布）
① 篇名（发布日期 / 微信URL）

---
*如果这篇帮到了你，点个「在看」让更多朋友看到。*[开放式问题]？评论区聊聊。
```

**要点**：
- 当前系列放在最上面，用 `📖` 图标 + roadmap（①→②→...）
- 已完结系列放在中间，只列有微信 URL 的
- DeepSeek 系列用 `🔥` 图标，标注其对应的原理篇与发布状态
- 结尾三段式：在看引导 → 开放问题 → 系列导航
- 系列用箭头 `→` 连接，不要用换行列表

## 互动引导

**规则**：每篇文章结尾（关注引导之前）必须包含 **1 个开放式问题**，引导读者留言。

**原因**：0 留言 = 算法认为内容无互动价值。1 条种子评论就能显著提升互动率。

**写法**：问题要具体、有争议性、读者能凭直觉回答：
```
✅ 你觉得 ReLU 和 Sigmoid 哪个更适合图像分类？评论区聊聊
✅ 学习率 0.1 和 0.001，你会先试哪个？
❌ 欢迎留言讨论（太泛，没人接得住）
```

**数据验证**（2026-07-08 统计）：5 篇文章共 234 阅读，**0 条留言**。

**更新**（2026-07-09 统计）：**26 条留言**（07/08 单日爆发）。从 0 → 26 的突变说明：(1) 读者基数跨过临界点（56 → 105）；(2) 具体争议性问题比泛泛提问有效得多；(3) 推广带来的新读者中可能有更多活跃互动者。**验证结论**：互动引导的方向正确，关键是问题要具体、有争议性、读者能凭直觉回答。基数达到 100+ 后留言概率自然提升。

**再更新**（2026-07-10 统计）：**24 条留言**（07/09 单日），连续两天 20+。留言率约 19%（24/126），远高于公众号平均 1-3%。验证结论：互动已形成习惯而非偶发。基数 126 人后互动已达稳态。**关键因素**：问题要有可争论性（「为什么不直接取最大值」「为什么56层比20层还差」比「欢迎留言」有效 100x）。

## 摘要关键词

**规则**：文章摘要（digest）必须包含 **2-3 个搜索关键词**，不能纯文学化。

**原因**：搜一搜不只看标题，也索引摘要。摘要里没有关键词 = 丢失搜索流量。

**示例**：
```
❌ 3分钟搞懂梯度下降——从生活直觉到数学公式，一个闭环讲透AI最核心的优化算法。
✅ 梯度下降是什么？用生活直觉讲清学习率、步长和梯度方向，3分钟看懂AI最核心的优化算法。
```

**自检**：写完 digest 后 grep 一下，确认至少包含 2 个专业术语关键词。
