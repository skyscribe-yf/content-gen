# 小红书文案输出格式

**规则**：小红书文案必须写入独立的 `copy.txt` 文件，**禁止**将文案内容嵌入 `cards.json` 或在回复中内联输出。

**原因**：小红书发布时需要直接复制粘贴正文，`cards.json` 中的文案需要手动提取，内联输出含多余空格和换行会虚增字数。`copy.txt` 无格式标记，复制粘贴即用。

**输出结构**：
```
content/<article-dir>/xiaohongshu/
├── cards.json    # 图片 prompt 配置（无文案）
├── copy.txt      # 发布正文（≤1000字，无多余空行）
└── *.png         # 生成的卡片图
```

**copy.txt 格式要求**：
- 纯文本，无 Markdown 标记
- 段落间单换行，无空行（空行算字数）
- 末尾带话题标签 `#标签1 #标签2`
- ≤1000字（小红书正文上限）
- 含互动钩子（引导评论）

**迁移说明**：旧文章可能还在用 `copy.md`，需迁移为 `copy.txt`（删除 Markdown 标记、去掉标题行和分隔线）。
