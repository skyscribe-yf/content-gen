### 2.7 G6：扩散 / 流匹配模型的 RL 对齐（reward 从哪里来，**2026-10-10 作者指定收录**）

> **定位**：视觉生成组的进阶题，也是**扩散数学系列（09-19~09-22 四篇）的第五块拼图**——前四篇讲「模型怎么学出图」，这篇讲「出完了怎么按人类偏好调」。⚠️ 与 `2026-09-19-diffusion-steps`（步数）**标题撞车风险高**（都带「50 步」），起题时避开。
> **核心反常识**：文本 RL 是「一条回答 → 一个奖励」；扩散 RL 是「**一条几十步的去噪轨迹 → 只有终点一个奖励**」——分怎么往回发（信用分配）就是整个领域在卷的事，2026 年 ICLR/CVPR 上相关论文扎堆。第二个反常识：**图像奖励模型是新的 reward hacking 温床**（过度饱和、伪影、审美塌缩）——与本号 `2026-09-14-reward-hacking` 篇同源。
> **国产落点**（吃 `docs/theory-practice.md` 要求，写稿前核验版本）：Flow-GRPO 是**快手可灵**团队（`arXiv:2505.05470`，第一个把在线 RL 搬到 flow matching，关键技巧 = denoising reduction，把 T 步压成 1 步算 likelihood ratio）；Flow-DPPO 是**腾讯混元**（`arXiv:2606.11025`）；TempFlow-GRPO 是**浙大 + 腾讯微信视觉**（ICLR 2026）。
