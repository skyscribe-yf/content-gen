**关键教训（数据都证明）**：
- 同一系列，题材量级定天花板、标题公式决定同题材内能不能打满：微软 Go（圈外大事件）583 vs 圈内技术文 47~64；KV 反常识 2,867 vs MTP/CP「名词+机制」27-35
- 「XX是什么」解释型标题 = 无信息缺口，陌生人不点（策略梯度/Q-learning/GAE 全死在这）
- 合集归属不影响推荐池（推荐看标题正文），只为粉丝回读导航
- **爆款的软肋是分享率**：微软 Go 篇 1.2%（纯推荐灌入），恢复期 KPI 的「分享率 ≥10%」反而是数学篇在供

### 2.6 L 组：后训练整合范式（OPD / 多教师蒸馏，**2026-10-10 作者指定收录**）

> **渊源**：`2026-08-26-knowledge-distillation` 篇的否决清单里明写「**不展开 OPD/MOPD**」——那是**故意留的口子**，本篇是它的正式续篇。分工：08-26 篇讲 **off-policy 软标签**（学老师写下的整张把握表）；本篇讲 **on-policy**（在 **student 自己生成的轨迹上**让老师逐 token 打分）。
> **品牌落点**（写稿前实时核验）：**DeepSeek-V4** 用 OPD 替掉 V3.2 的混合 RL 阶段（10+ 领域专家）；**Kimi K3** 把 **9 个专家**（3 领域 × 3 推理档位）折进一个模型；**MiMo-V2-Flash**（309B/15B）也用 MOPD。术语约束：每篇 ≤2 个新术语。

| # | 选题 | 反常识点（数字已核） | 状态 |
|---|---|---|---|
| L1 | 「一锅大 RL」为什么要拆开再合并 | 三种整合范式对撞（数据/权重/策略空间）；同源对照 OPD 归一化分 **0.9373** > Mix-RL 0.8818 > 朴素权重平均 **0.3280**；动机是一锅 RL 互相踩（跷跷板问题） | ✅ **已兑现 2026-11-16**（与 L2 合并为一篇发布） |
| L2 | **换掉一个更强的老师，合并出来的模型反而崩了** | 换更强老师（Qwen3-235B）归一化分 0.9373→**0.6003**，AIME25 掉到 **0.94%**；选老师看同不同源、不看单体分；附带 top-k 截断修正项的坑 | ✅ **已兑现 2026-11-16**（`2026-11-14-opd-multi-teacher-distillation`，标题即本候选句） |
