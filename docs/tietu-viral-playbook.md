## 二、第一层规律：题材事件量级定档（天花板）

1. **S 档全是出圈事件**：价格战（opencode 涨价、ollama 峰谷价）人人看得懂；费马大定理是全网猎奇新闻。出圈题材不需要读者懂 AI。
2. **钱包/利益题材最容易出圈**：10 篇爆款里 6 篇价格/优惠/缩量相关。
3. **圈内小事件就是百级**：评测分数、榜单对齐、小优惠，标题再花也到不了 A 档。
4. ⚠️ **三件套齐 ≠ 起量**：「330tps，疾如闪电的DeepSeek v4.1 flash」品牌词+情绪+数字全有，仍 160 读——题材定档是天花板，标题决定同题材内能不能打满，两层别混。

## 三、第二层规律：标题三件套 + 时机（同日对照铁证）

**标题三件套**（10 篇爆款 10/10 命中①，②③ 8/10）：

1. **具体品牌词/事件词进标题且靠前**（10/10）：opencode、ollama、DeepSeek、QWen、Kimi、pi agent、费马大定理、c++之父、deepSWE——必须具体到人/产品/事件，「大模型」「网络」这类泛指不算。
2. **情绪/强立场**（8/10）：杀疯了、即将反转、突飞猛进、友善、严重过拟合、魔幻、好家伙、沦陷、锐评、膨胀、还是有希望、还可以的、扎心、越权最狠、离谱。
3. **利益钩子**：钱包（价格/优惠/缩量）6/10、站队（你选谁/评分接近/还是有希望）3/10、猎奇（358 年/被 AI 证明）1/10。

**数字钩子加分**：358 年、1/3、4 个月、0731、5 折、2.39 倍——数字比形容词可信，也是可转发的弹药。

**同日对照是铁证**（同一天、同一批推荐，量级差全在贴图自身）：

- 09-05 双发：费马大定理 4,683 vs 《Harness 前沿大重构》未单列（百级以下）
- 09-03 三发：deepSWE 沦陷 927 vs 《前沿harness评测集》《线性注意力机制全是弯路吗？》均未单列
- 08-07 三发：opencode 5,435 / QWen 1,470 / 第三方DeepSeek 1,073，三篇全 1,000+

**时机**：S 档全部热点当天/次日发。费马 09-05 发，T+1 已 4,683。热点窗口一过，同一篇掉一档。

## 四、头号杀手：谜语化标题

**反例（全部垫底）**：

- 「强悍的大模型之间最强烈的厮杀进行中」148——无品牌词、无事件、纯抽象概括
- 「五分之一只对得上牌价」「少想四成这一刀并不均匀」「77.9这分公开榜没有」「模型没换账单却被砍掉一半」——要靠猜才知道讲什么

**判据**：把标题缩到信息流卡片大小，陌生人 3 秒说不出这篇讲什么 → 重写。无品牌词、主题靠猜、泛指（「网络」「大模型」）一律打回。

## 五、封面规律（2026-10-04 确立）

1. **封面大字 = 定稿标题核心句**（`compose.py` 改字重渲即可）——信息流里标题和封面同帧出现，两套说法互相打架、浪费一帧。
2. **热点词必须进大字**，禁止埋进小字——缩略图里小字不可读，品牌名/人名在小字等于没有。
3. 封面小字只做补充，不放「只在这里出现」的关键信息；每张图一个主信息。
4. 数字/结构由脚本画，AI 图不写字（既有规则，见 `docs/tietu-infographic-flow.md`）。

## 六、执行清单（新建贴图必过）

- [ ] **选题定档自评**：出圈事件 / 圈内大事件 / 圈内小事件？第三档预期放百级，不按爆款做预期
- [ ] **标题三件套**：品牌词/事件词前置（必中）+ 情绪/强立场 + 利益/站队钩子，至少中两个
- [ ] **反谜语检查**：陌生人 3 秒能说出主题吗？
- [ ] **数字钩子**：有没有一个能单独转发的具体数字？
- [ ] **前 22 字窗口**：品牌词 + 反差/情绪落在信息流截断窗口内
- [ ] **封面大字 = 标题核心句**，热点词在大字里
- [ ] **热点当天/次日发**
- [ ] **开启群发通知**（`viral-article-playbook.md` 第六节：不开群发阅读掉到 18~64）
- [ ] 结尾开放式问题 + 话题标签（含 `#数解AI`）

## 七、与文章轨的区分

- **贴图不做「反直觉疑问句」**——那是文章轨公式，别混用（`viral-article-playbook.md` 第六节）
- 贴图标题：口语、情绪、悬念或站队；`article-title-seo.md` 九条自检里的疑问句/教程攻略型要求不适用于贴图
- 贴图量级不作文章策略判读依据；双轨推荐相互独立（见 `docs/wechat-ops.md` 双轨框架）
- 手敲文本风格对照 [`branding/style-corpus/style-features.md`](../branding/style-corpus/style-features.md) A 节
