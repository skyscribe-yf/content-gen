### 0y.4 执行规则（写入文章质量核查参考）

1. **每篇文章自检「三种利他钩子」至少命中 2 个**：
   - 可复用钩子：给可抄的结论/参数/对照表（如 PPO 的 clip/KL 实验数据表、KV 的带宽对比表）→ 促收藏；
   - 可传递钩子：给读者「转给谁有用」的理由（点名应用场景：做 agent 的同学、调 RL 的、搞推理优化的）→ 促转发；
   - 可表态钩子：给一个鲜明立场（「凭什么」「其实是假的」「我反对」）→ 促点赞。
2. **纯认知解释文（高斯型）慎发或补钩子**：完读率 22% 不低但收藏/点赞垫底——读者「看懂了但没有行动理由」。要么结尾给「可用清单」，要么给争议立场。
3. **数据驱动选题优先级**：实操参数文（PPO 型）> 新情报文（智谱阿里型）> 反常识直觉文（高维型）> 纯认知解释文（高斯/信息熵型）。
4. **互动率指标替代绝对数**：恢复期（推荐池枯竭）文章轨判据改用互动率——赞率 ≥8%、藏率 ≥5%、享率 ≥12% 即达标，不再用 150 读硬线（粉丝盘 60 人上下，150 线在无推荐时不可达）。

- 推荐占阅读来源 **86.0%**；「opencode这波真要杀疯了」5,422 读，占全部文章阅读量（11,908）的 **45.5%**、近 30 天阅读人数（14,003）的 38.7%。

- 结论：08/11 的 1,613 读是脉冲高位，不是新基线；下次复盘以脉冲退潮后 7 日均值判断真实水位。

### 0k.2 两种内容经济：热点拉流量，原创技术文赚钱 + 沉淀

| 类型 | 篇数 | 平均阅读 | 千读广告收入（代表篇） |
|---|---:|---:|---:|
| 热点/情绪文 | 13 | 636 | opencode 1.06 元、第三方DeepSeek 0.64 元 |
| 原创技术文 | 27 | 135 | Muon 16.72 元、K=V 16.60 元、FP8 6.86 元 |

结构性原因：**原创文才有底部 + 文中广告位**（底部 eCPM 7.41 元、文中曝光率 48.54%）；非原创热点贴图只拿留言区 + 贴图底部广告位（eCPM 约 3 元）。执行规则：热点文负责引流，尾部必须导向合集与技术文，不单独背 KPI。

### 0k.3 搜一搜是转化率最高的渠道

- 搜一搜阅读占比 1.0%（约 140 人）→ 关注 25 人（8.93%），估算关注转化 **≈18%**。
- 整体转化 280 / 14,003 = **2.0%**；文章页关注 214 / 11,908 文章阅读 ≈ 1.8%。
- 搜索读者转化约为整体/文章页的 **9–10 倍**；SEO 投入直接作用在转化率最高的流量上，是当前 ROI 最高的吸粉渠道。

### 0k.4 推荐流量宽而浅，关注转化只有 2%

- 整体 14,003 阅读 → 280 关注（2.0%）；脉冲当天 08/11 为 1,613 读 → 28 关注（1.7%）。
- opencode 5,422 读未带来成比例关注；历史峰值 48/49（07/06、07/08）出现在阅读量小得多的时期，大概率由推广驱动。
- 结论：算法流量是过客流量，不主动收割不会变粉丝；热点文末尾关注引导、合集入口、下期预告是漏斗最值得强化的环节。

### 0k.5 粉丝资产尚未形成回读闭环

- 公众号主页（3.6%）+ 公众号消息（4.4%）合计约 **8%**（约 1,120 人）来自已有关系，**92% 阅读来自陌生推荐**。
- 主页绝对量约 451 → 504 人（占比被脉冲稀释）；419 粉丝尚未产生自我维持的阅读循环。
- 账号目前是「推荐货架」而非「关注资产」，系列化回读仍需文末合集与跨系列入口强化。

### 0k.6 广告瓶颈已从曝光转移到阅读

- 各广告位曝光率均健康：文中 48.54%、留言区 20.13%、底部 19.75%；收入跳升完全来自拉取量放大（留言区拉取 160 → 2,543/日）。
- eCPM 高低是广告位类型差异（底部 7.41 vs 文中 1.26），不是内容质量信号；脉冲期底部 eCPM 23–25 元属竞价噪音。
- 结论：当前卡收入的是「阅读量 → 拉取量」，不是广告位配置；保留底部、文中、留言区、贴图广告位即可。

### 0k.7 数据口径提醒

- JSON 中单篇文章的 `share` 字段实为「阅读人数占比」（如 opencode 38.72 = 5,422 / 14,003），**不是分享次数**，不可用于分享行为分析；分享只看日/30 天卡（08/11 分享 91、30 天 836）。
