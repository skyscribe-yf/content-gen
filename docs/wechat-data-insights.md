| 收入/阅读 | **0.00038 元/读** | 每 1000 阅读收入约 0.38 元 |
| 收入/曝光 | **0.0056 元/次** | 每次广告曝光 0.56 分 |
| 收入/日 | **~0.06 元/日** | 4 日均值；当前不可作为收入预期 |
| 曝光/阅读 | **6.9%** | 100 人阅读，仅 ~7 人看到广告 |

**结论**：当前收入可忽略不计。核心瓶颈不是 eCPM（8.24 元属正常），而是**曝光量太低**（45 次/4 天）。提升路径：增加阅读 → 提高拉取量 → 优化广告位位置（文中广告比底部广告曝光率高）→ 曝光量才能放大。

#### 0.7.5 eCPM 优化建议

| 优先级 | 动作 | 依据 |
|--------|------|------|
| P0 | **持续扩大阅读基数**——收入 = 曝光量 × eCPM / 1000，曝光量由阅读量驱动 | 目前曝光量仅 45 次，任何 eCPM 波动都无意义 |
| P1 | **启用文中广告**（当前仅留言区广告有数据） | 文中广告曝光率通常 2–3× 底部广告 |
| P2 | **关注曝光率而非 eCPM**——曝光率从 66.67%→6.79% 说明广告位可见性差 | 读者不愿滚到文章底部 |
| P3 | 暂时不用关注 eCPM 绝对值——50 次曝光以下无统计意义 | 等日曝光量稳定 200+ 后再评估 eCPM 水位 |

**下轮复盘触发条件**：日曝光量稳定超过 200 次时，单独拉 eCPM 趋势与广告位对比分析。

### 2026-07-12 流量主/eCPM 规则（新增）

1. **收入 = 阅读量 × 曝光率 × eCPM / 1000**，当前阶段（<1000 阅读/日）**不要关注 eCPM 绝对值**——45 次曝光下的 eCPM 无统计意义。
2. **拉取量 ≠ 曝光量**：07/10 拉取量 324 但曝光仅 22（曝光率 6.79%），说明读者滚不到广告位。优先启用**文中广告**（比底部广告曝光率高 2–3×）。
3. **零点击（CTR 0%）是曝光量问题，不是内容问题**：预计 500+ 曝光/日后会出现首次点击。
4. **eCPM 看趋势不看绝对值**：等日曝光量稳定 >200 次后，对比周/月 eCPM 趋势，单日波动忽略。
5. **概览页「昨日收入」可能≠日报表合计**：概览含多广告位汇总，日报表默认单一广告位（留言区广告）。运营决策以**概览页累计收入**为准，分析用**日报表分日数据**。
