# 口播视频制作复盘（2026-08-15 RLHF 视频）

> 本 session 制作《RLHF怎么让模型选出好回答？》视频号视频（口播模式）的完整复盘。
> 目标：把踩过的坑沉淀为 skill 规则、通用脚本、流程改进，避免下次人工重复提醒。

## 一、可沉淀为 skill 一部分的（manim-article-video 口播分支）

### 1. 录音流程（Step 4B 补充）
- **用 ffmpeg 录音**（用户提醒"可以用ffmpeg录的"）：ffmpeg -f alsa -i hw:<card>,0 -t <秒> -ar 48000 -ac 2 -y recordings/sN.wav
- **麦克风选择**：先 arecord -l 列出设备，用 volumedetect 探测哪个有信号（CM40 USB 麦 vs 内置麦）。CM40 需 48kHz 立体声；内置麦 44.1kHz 单声道
- **录音窗口要足够长**：预估时长 + 10-15s 余量，避免最后一句被截断（S2 曾因 35s 窗口不够，最后一句被硬截断）
- **逐段核对**：录完一段用 silencedetect 检查时长/吞字/静音，再进下一段
- **开头准备静音**：用户常在我启动后 5-7s 才开口，开头静音正常，裁剪时去掉

### 2. 录音后处理（裁剪静音）
- **裁剪头尾静音**：用 silencedetect 找语音起止，-ss start -to end -c copy 裁剪
- **开头微弱声音误判**：S6 开头 0.19~3.05s 有微弱环境声被误判为语音起点，导致 2.86s 静音残留。裁剪时用第一个明显语音段（不是第一个非静音点）
- **尾部静音残留**：S2 裁剪终点用了"最后一个静音开始"，但录音末尾有长静音，导致 6.3s 尾部静音。裁剪终点用最后一个语音结束点

### 3. 字幕规则（大量返工的核心）
- **字幕按完整句子出现**（句号/问号/感叹号/分号切分），不拆半句
- **长句在逗号处拆成语义片段**（用户认可"可以用逗号分割"）
- **每条字幕 ≤26 字**（最多折 2 行，用户明确"不要三行"）
- **英文单词不拆断**（中英文混杂时，在空格/单词边界断行）
- **整条一次出现**（不用逐字打字机，用户明确"不要一个字一个字滚动"）
- **fad 淡入淡出要小**（fad(60,40)，避免短字幕字被吞）
- **字幕时间戳和画面切换时间对齐**（用 pauses 停顿点作为句子边界，避免字幕比画面早 2-3s）

### 4. 音画同步
- **字幕时间戳按字数比例分配会导致和画面切换不同步**（字幕比画面早 2-3s）
- **用 pauses.json 停顿点作为句子边界**，从停顿点均匀采样 n_blk+1 个边界，确保单调递增且覆盖整段

### 5. 静音验证
- **段内长静音要删**（S6 开头 2.86s）
- **成片验证最长静音段**（应 <1.5s）

## 二、可成为通用脚本的（scripts/ 目录）

### 1. 录音脚本（新增 scripts/record_voice.py）
封装 ffmpeg 录音 + 麦克风探测 + 逐段核对，避免每次手敲 ffmpeg 命令。

### 2. 裁剪静音脚本（新增 scripts/trim_silence.py）
封装头尾静音裁剪 + 语音起止检测（处理开头微弱声音误判、尾部静音残留），输出 VOICE_DUR。

### 3. 字幕折行（已固化到 manim_video_build.py）
- wrap_line()：手动按 13 字折行，断行优先级 中文标点 > 英文空格 > 字符，不拆断英文单词，最多 2 行
- split_sent()：按完整句子切分，长句在逗号处拆成语义片段
- pauses 分支：用停顿点作为句子边界对齐音画

### 4. 音画同步验证（新增 scripts/check_sync.py）
抽帧对比画面切换时间和字幕时间戳，自动检测不同步。

## 三、可改进现有流程避免人工重复提醒的

### 1. 录音前自动探测麦克风
skill 的 Step 4B 应加一步：录音前自动 arecord -l + volumedetect 探测可用麦克风，选有信号的设备，避免用户提醒"应该使用CM40"。

### 2. 录音窗口自动计算
skill 的 Step 4B 应加：录音窗口 = 预估时长 + 10-15s 余量，避免最后一句被截断（S2 教训）。

### 3. 裁剪静音自动处理
skill 的 Step 4B 应加：录音后自动裁剪头尾静音（处理开头微弱声音误判、尾部静音残留），避免人工发现 2:22 静音。

### 4. 字幕规则固化到 build 脚本
skill 的生效决策表应加字幕规则（完整句子、逗号分割、≤26字、2行、英文不拆断、整条出现、fad 小、音画同步），避免用户反复提醒。

### 5. 成片自动验证
skill 的 Step 8 应加：自动验证字幕折行（≤2行）、无英文拆断、无左右截断、音画同步、无长静音，避免用户看样片才发现问题。
