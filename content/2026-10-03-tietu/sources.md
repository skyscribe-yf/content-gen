# DeepSeek 开源昇腾全套组件 —— 事实核查表

> 采集日：2026-10-03。**所有数字均已一手核实**，写稿时以本表为准，勿凭记忆改数。
> 未核实项一律标注，不得进稿。

## 一、事件

- **2026-09-30 上午**，DeepSeek 通过**官方公众号**宣布：正式开源面向**华为昇腾**算力平台的全套基础设施组件。
- 涵盖三类：**高级语言编译工具（TileLang）/ 计算库 / 分布式通信库**。
- 官方明确：**所有昇腾组件与此前面向英伟达平台的开源组件一一对应**。

来源：DeepSeek 官方公众号 2026-09-30；《科创板日报》2026-09-30（记者 黄心怡）；七牛云技术拆解 2026-09-30。

## 二、六个 GitHub 项目

| 项目 | 仓库 | 性质 | 说明 |
|---|---|---|---|
| **TileLang** | `github.com/tile-ai/tilelang` | 原有项目**新增昇腾后端** | 面向 GPU/CPU/加速器的高性能内核 DSL；此前已在英伟达平台被 DeepSeek 广泛使用，**GitHub 7500+ Star**。官方原话：「沿用 NVIDIA 路径，内核现在提供第二个后端，**运行时自动选择**」——同一套 Python API 直接跑在 NVIDIA GPU 与华为 NPU，不需重写代码 |
| **DeepGEMM-Ascend** | `github.com/deepseek-ai/DeepGEMM-Ascend` | **为昇腾新建**的独立仓库 | API 与英伟达版本对齐；标注为「**昇腾 950 系列设备的首次发布**」；2026-09 新创建 |
| **DeepEP-Ascend** | `github.com/deepseek-ai/DeepEP-Ascend` | **为昇腾新建**的独立仓库 | 专家并行通信；⚠️ Bucket 集合通信、专家负载均衡等**部分能力仍在持续开发中** |
| **TileKernels** | `github.com/deepseek-ai/TileKernels` | 原有项目**新增昇腾后端** | — |
| **FlashMLA** | `github.com/deepseek-ai/FlashMLA` | 原有项目**新增昇腾后端** | 即本号已写过的 MLA 那套 |
| **DeepSelect** | `github.com/deepseek-ai/DeepSelect` | 原有项目**新增昇腾后端** | TopK 算子 |

覆盖链路：**底层编程语言 → 矩阵计算 → 专家并行通信 → TopK 算子**。

## 三、昇腾 950 超节点

- DeepSeek 官方公告提到：面向昇腾平台的研发中**华为团队给予了大力支持**，双方**已共同推进基于昇腾 950 的 128 卡超节点方案**。
- 这六个基础组件（尤其 DeepEP-Ascend 的专家并行通信）是支撑这类超节点**规模化训练与推理**的底层基础之一。

## 四、生态背景（写稿可用，须标注为背景而非本事件）

- 英伟达软件体系核心是 **CUDA 编程平台**，推出近 20 年，全球数百万开发者在其上积累算子程序，主流大模型训练代码多基于它编写；企业换芯片需**逐一重写并重新调优**。
- **TileLang 由北京大学计算机学院团队主导开发**，2025 年 1 月开源，定位是连接大模型算法与底层硬件芯片的「桥梁」。
- DeepSeek 方面表示：**相对英伟达 CUDA 语言，TileLang 编程更简单**，能显著提高开发效率、简化代码逻辑，同时不损失硬件性能。

来源：封面新闻 2026-10-02（记者 温彦博）；红星资本局 2026-10-02；《科创板日报》2026-09-30。
