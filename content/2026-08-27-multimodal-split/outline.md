## 结构（叙事弧线：小标题连起来就是故事链）

1. **看不见的旗舰**——场景钩子 + 现象：DeepSeek/GLM 旗舰纯文本，传图失败是日常；8-21 才补上嫁接眼，实测连梁文锋照片都认不出
2. **国产头部在视觉上分两派**——表格：DeepSeek V4 / GLM-5.2 纯文本 vs Kimi K3 / Qwen3.8 原生多模态（K3 2.8T 参数 104B 激活 / MoonViT 从头训练）
3. **三位创始人，三个说法**——梁文锋「多模态对智能上限是组件不是主线」；唐杰「对提升 AGI 智能上界帮助有限」+ 评论区清一色要视觉；杨植麟「多模态不损伤脑子已经很好了」——嘴最保守的人事做得最激进
4. **为什么装眼睛会伤脑子**——视觉和文本抢同一个大脑：训练目标干扰、数据动力学不同；DeepSeek-VL 消融实测：100% 图文数据 MMLU 掉 10.3 分，70/30 配比才不掉点；Kimi K2.5 报告：训练中后期才加视觉，文本能力先降后恢复
5. **反转：练看能练强想**——Kimi K2.5 早期融合（视觉+文本从头混训 15T）：只训数数/识图/视觉问答，没加数学编程，文本推理变强；零视觉 SFT 方案——直接反驳「装眼睛伤脑子」
6. **嫁接眼 vs 原生眼**——DeepSeek V4 Vision Exp：图像折算 384 token、跑分全放 Agent 基准（TerminalBench/ApexBench 而非 MMMU）、认不出老板照片 = 视觉前端拼到文本引擎；Kimi MoonViT：从零训视觉编码器，视觉直接进下一 token 预测
7. **回扣：多模态不是要不要，是怎么做**——DeepSeek/GLM 的克制是「算力 + 现金 + 战略排序」的账本（V4 昇腾迁移、训练失败、现金掣肘），Kimi 的全脑是 2.8T 参数烧出来的；但 K3 证明「全都要」可行，行业会往哪边摆

## 认知交付（读者带走什么）

1. 反直觉答案：多模态伤文本是「后期拼接」的锅，早期融合反而反哺文本推理——融合时机比做不做更关键
2. 工程结论：鉴别国产视觉模型真伪的标尺——嫁接眼（跑分全是 Agent 基准）vs 原生眼（看图答题基准 + 技术报告）
