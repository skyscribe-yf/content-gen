2019 年，OpenAI 让两个 agent 在同一个场地里玩躲猫猫。

跑到大约 2,500 万局，躲的那一方才学会搬起箱子，挡住对方的视线。

再过 7,500 万局，追的那一方才学会把斜坡搭到墙上，翻进去。

这两步加起来，大约 1 亿局。

七年之后，2026 年 10 月 8 日，一个叫 MirroS 的团队把同一个游戏重跑了一遍。

**躲的一方在第 4 轮就搭好了掩体，追的一方在第 10 轮就翻过了墙。**

差别不在模型。

差别在它换了一块练习场。

## 一、agent 学不到东西，可能不是模型的问题，是它没地方练

### 论文的第一句话，就是全篇的题眼

“agent 能学到什么，被它练习的环境所限制。”

这不是修辞，是个工程约束。

一个 agent 靠“动作 → 观察 → 再决策”的轨迹学习，环境必须同时满足两个互相打架的要求。

一个是忠实（faithful）：状态一致、规则确定、动态可复现。转个弯，视野就该变；推了箱子，后果就该留着。

另一个是拟真（realistic）：视觉观察要贴近真实世界的分布，否则学到的感知能力迁移不出去。

“迁移不出去”有个专门说法叫 sim-to-real——仿真里学会的，拿到真世界里还能用。

### 两条老路，各占一半

第一条是模拟器和游戏引擎：世界由代码定义。

好处是状态和规则都由程序保证，绝对忠实。

坏处是程序化出来的场景，视觉极其贫乏。

想要好看，就得给每个环境单独做美术资产、单独调渲染管线。这个成本，决定了环境库永远扩不起来。

第二条是视频世界模型：让生成模型直接“想”出下一帧。

这条路视觉上是真的。NVIDIA Cosmos 这一类模型，能把画面做得像实拍。

但它是生成式的。

长程交互里，物理会漂移，状态对不上。

agent 在一个会漂移的世界里学因果，学不到。

![两条老路各占一半：左边像素贫乏但忠实，右边好看但物理会漂](01-两条老路.png)

![忠实与拟真是一对矛盾：两条老路各占一半（据论文 Figure 1 与作者梳理）](05-两难对照.png)

### 于是环境本身，成了瓶颈

合成数据快被采干之后，行业里真正焦虑的就是这件事：**可扩展的环境从哪来？**

这篇论文是冲着这个问题去的。

## 二、一个世界，两种真相：代码管事实，渲染器管皮

### 拆成两层，中间用几何当接口

AgentGarten 的做法是这样一条回路：

agent 发出动作 → 代码世界维护持久的世界状态、执行程序定义的交互规则。

代码世界导出几何条件 → 神经渲染器把它变成下一帧画面 → 画面回到 agent。

代码世界那层，负责“事实”：物体的位置、规则、动态。

渲染器那层，负责“皮”：这一帧长什么样。

![动作到下一帧的回路（据论文 Figure 1 与 §2 整理）](06-动作到下一帧.png)

### 关键不在分层，在于导出的不是像素

这一层接口里，代码世界送给渲染器的**不是像素，是几何**——深度图，或者表面法线，从 agent 摄像机看出去的形状。

这一点很要紧。

![一层线框几何从代码世界导出，被照片级画面穿上“皮”](02-事实归代码皮归生成.png)

事实由确定性程序保证，真实感由生成模型补足，两边各干一件事，谁也不用假装自己能干对方的活。

### 新环境 = 一段代码

布局、物体、动态、规则、目标，都可以系统性地生成和修改。

环境库的扩展成本，从“每个世界一套视觉工程”，降到“每个世界一段代码”。

论文的演示里，同一套渲染器覆盖了导航、物体操控、场景重拍（re-shot）和多 agent 交互。

还有三个纯代码规则的浏览器小游戏：保龄球、点球大战、推箱解谜。

## 三、为什么偏偏是深度图和法线

### 因为这个条件，训练和推理两头都好拿

训练侧：模拟器直接从几何导出深度和法线。

真实视频用估计模型反推。

深度用 ViPE（后端是 Depth Anything 3），法线用 NormalCrafter。

推理侧：任何有 3D 场景的代码世界，都能廉价渲染出这两张图，不需要精细资产，也不需要材质。

两头都拿得到，意味着**同一批训练数据里可以混进真实视频**。

几何条件，就成了弥合 sim-to-real 那条缝的桥。

### 论文自己承认的那个坑

这里有个值得记下来的工程细节。

论文用的是自蒸馏那一路的做法：让一个学生模型去追老师的分布。

他们发现，只用 score distillation 训出来的渲染器会崩。

崩在长 rollout、大场景变化的时候——生成帧开始出现棋盘格纹理，同时跟条件视频漂移、对不上。

照 DMD2 的做法，在真实视频上加了一个 GAN loss，才把纹理和条件一致性都稳住。

这套组合拳论文起了个名字，叫 Adversarial Forcing。

### 先埋一根线

那个“真实视频上的 GAN loss”，是整条技术栈里跟现实接触的**唯一一条缝**。

记住它。第八节会回来咬它。

## 四、OpenAI 花 1 亿局换来的东西，它几轮就有了

### 换掉的不是渲染器，是整个 agent 范式

hide-and-seek 那个场地没换，换的是 agent 的整套配置。

| | OpenAI 2019 经典做法 | AgentGarten 做法 |
|---|---|---|
| 观察 | 对象状态向量（位置、速度、尺寸、雷达读数） | 神经渲染的**第一人称画面** |
| 动作 | 每步一个连续控制信号 | **短 Python 程序**（`step(turn=-1, steps=2)`） |
| 记忆 | policy 网络权重 | **playbook 技能文件** |
| 学习信号 | self-play RL + 奖励 | 每轮复盘，教训写进 playbook |

![两套范式对照（据论文 Figure 9 与 Table 3 整理）](07-范式对照.png)

### 把“记忆”从权重里搬出来

先看记忆这一栏，因为它是整件事里最像当下的部分。

每个角色自己带一本 playbook，里面是一堆短的 skill file。

那是 Markdown 笔记，可以包含代码，一个文件一条经验。

记录下来的那一轮跑法是这样的：两本 playbook 从空白开始。

每轮打 5 局，用的布局和随机种子都是采样出来的。

一轮打完，双方各自复盘自己的行动程序，以及自己被允许看到的那部分视觉证据。

找出失败，补一条 skill file 进 playbook。

下一轮，agent 拿着累积起来的技能，重新理解当前场景，判断哪段旧经验还管用。

**成功和失败的尝试，都进下一轮的修订。**

顺带一提：agent 全程拿不到物体坐标、拿不到隐藏的世界状态、也拿不到对手的私有观察。它只看得见渲染器给它的画面。

### 三条涌现行为

论文点名了三条：

躲的一方搬动屏障板，堵住入口。

追的一方把斜坡运到内墙边，翻了过去。

还有第三条——第一次跳跃没跳上去，**追的一方把斜坡往墙边挪近了一点，再试一次**。

第三条最重要。

那是一段带反馈的多步规划：它得先意识到“这次不够高”，再判断“把斜坡挪近能解决”，然后重试。

### 论文自己的数字

论文 Table 3 给得很干脆：

建造掩体，自博弈强化学习用了大约 **2,500 万**局；预训练 agent 在第 **4** 轮做到了。

用斜坡进入掩体，自博弈 RL 大约 **1 亿**局；预训练 agent 在第 **10** 轮做到了。

同一个团队还把这套流程搬到另外四个世界，每个跑四轮：陪狗玩、单车道桥、牧羊、采石场装载机。

四个世界全部只用第一人称的渲染画面，拿不到仿真内部状态，也拿不到引擎的原始几何缓冲。

### 从这件事上退一步看

这套东西的结构其实很眼熟：Python 程序当 action space，Markdown playbook 当持久记忆。

本质上，这是把“RL agent”换成了“harness 形态的 LLM agent”。

也就是说，**环境侧已经准备好迎接 harness 范式的 agent 了**，缺的只是把两边接上。

从这个角度来思考，其实 AGI 并不是普通公众想象的那样，真的可以从底层逻辑上，能代替人类去探索未知的世界。

## 五、它没做错任何事，除了“一致”不等于“真”

### 论文把 faithful 定义成了“内部一致”

回头看第一节那个词。

论文原文对 faithful 的定义是 `consistent state, rules, and dynamics`。

注意：是**一致**，不是**与真实相符**。

这是两个不同的量。

一个本体论就是错的代码世界，可以完美地一致、确定、可复现：它是一个运行良好的错误宇宙。

### 追问一环：代码世界的本体从哪来

如果只是做个演示，这一问可以放过。

但要规模化地建环境库，代码只有两个来源。

一是人手写——扩展性当场就死了。

二是 LLM 生成。

后者意味着这样一条链：

真实世界（模糊）→ LLM 生成代码世界（声称可验证）→ 神经渲染器（从真实视频学）

上下两层看上去异质，其实上层的公理，是下层同一种分布的冻结快照。

可验证性没有被“获得”，只是被“转移”，且转移过程中丢失了原图。

### 论文自己就承认了这条缝

这一点上，论文比很多同类工作诚实。

它在相关工作里写得非常直白，大意是：

> 在我们的系统里，动作先推进一个可执行的环境，渲染器只负责外观。
>
> 但视觉连续性仍然是学出来的，生成出来的帧**不必完美实现所给的状态**。

“不必完美实现所给的状态。”

世界状态是忠实的，可 agent 看到的画面是生成的。

渲染器画错一个物体，agent 拿到错误观察，这个错误观察就成了训练数据里的一味毒。

于是系统层面的问题，从“世界会不会说谎”，变成了“传感器会不会说谎”。

![一个自洽、可复现，但物理规则明显不对的世界](03-错误宇宙.png)

### 这个坑，本号上周刚讲过一遍

durable execution 那边有完全同构的教训。

这与 durable execution 的教训同构：replay 一万次一致，不能证明第一次记录的语义解读是对的。

（详见 [Pi Durable：工具调用中途崩溃，重发还是放弃？](https://mp.weixin.qq.com/s/_gnfMHGfYW5yxtm6UJkfxg)）

崩溃重放能挡住的，是“同样的东西跑了两遍”。

它挡不住的是“第一次的解读本来就想错了”——而后面那一万次，会把这个想错的解读执行一万次。

代码世界是同一个道理。

虚妄不是一个明确的错误，而是生成时无人审视的建模选择，被确定性执行放大成了物理定律。

## 六、损失不是“优化失败了”，是被默认设计出来的

### 先看一条五层的链

把这条从真实世界到训练数据的路拆开，一共五层有损压缩。

1. **感知层**：人类观测是为适应度优化的，不是为真理优化的。你能看见的“多样性”，已经被生存压力过滤过一遍。
2. **数据层**：训练数据是这些观测的不精确采样。
3. **衍生层**：LLM 从数据里学出的分布，拿去生成代码世界——虚妄被冻结成了公理。
4. **优化层**：梯度下降再收窄一次。
5. **递归层**：生成产物又回到训练集里，循环累积。

![从真实世界到训练数据的五层有损压缩](08-五层压缩链.png)

### 第四层要说清楚，因为这里最容易被讲错

常见的说法是“陷进了非凸局部最优”。

不是。

真正的机制是三件事叠在一起：

**典型性偏置**——高维样本几乎必然落在典型集里，这是高维几何的结果，不是优化器的失误。

**隐式正则**——优化过程本身在按某个方向丢东西。

**RLHF 对齐税**——对齐又收窄一次。

损失是范式级的默认行为，不是优化失败的副产品。

这句话值得停一下。它意味着你没法靠“换个更好的优化器”解决这件事，因为丢东西不是意外，是设计的一部分。

> 这里要和 9 月那篇 [损失面上全是坑，为什么梯度下降还能走到谷底？](https://mp.weixin.qq.com/s/AYlFPXsMJJ0esCa_7_amrw) 分开看。
>
> 那篇论证的是“损失面上的坑不阻止下降”；这里讲的是“下降本身在按默认方向丢东西”。
>
> 一个说能走通，一个说走通的同时在丢，两件事不冲突。

### 第五层：尾部最先死

生成产物再进训练集，一轮一轮滚下去，分布会塌缩——就是常说的 model collapse。

塌缩的顺序不是均匀的。

最先死的是尾部。

### 一段历史维度的补充

把尺度再拉大一点，这件事其实不是 AI 带来的新问题。

人类历史本身就是一部群体观察被高度浓缩的历史。

文字、传播、政治、灾害，层层过滤。而且过滤器之间还互相强化——这叫关联灭绝，不是独立乘法。

再叠加一层表演性偏差：被记录下来的，往往是“想被看见的那个自我”。

所以最深的一刀在这里：

最深层的损失是那些从未成为记录候选物的 mundane 具身经验——而那恰恰是物理直觉和可供性的基座。

这些经验从来没被写下来过，不是因为不重要，是因为它们太日常了，日常到不构成一个“值得记录的事件”。

而物理直觉，恰好全部长在这层日常上面。

（压缩这件事，本号在 [信息熵：压缩1000倍，为什么信息反而少？](https://mp.weixin.qq.com/s/BkGWzKxiJE2mlPMlZgb7ag) 里讲过一遍。那次讲的是一次编码，这次是五层串联。）

## 七、多样性可以用算力买，真理性不能

### 两件东西，只有一件可以再注入

这条链上丢了两样东西：多样性，和真理性。

多样性是可以补的。

温度、噪声、domain randomization、novelty search——代价只是算力。

多样性可以被再注入：温度、噪声、domain randomization、novelty search——代价只是算力。

但这些方法只能在数据支撑集内部重新排列，支撑集之外一点也补不了。

真理性不行。

真理性没有再注入机制。它不能靠采样恢复，唯一来源是与真实世界的接触。

于是整条技术栈里，现实接触的通道只剩一条窄缝——第三节埋的那根线，那个真实视频上的 GAN 信号。

整个技术栈里现实接触通道只有一条窄缝（AgentGarten 里就是渲染器的训练视频）——“真”的总量由最窄的通道决定。

这句话可以直接当判据用：一个系统的“真”有多少，不看它最宽的那条管道，看它最窄的那条。

### 科学为什么既要做实验，也要读档案

还有一层结构上的对称。

档案通道是**反向过采样**的：mundane 的部分被系统性丢弃，异常的部分被系统性保留。翻遍史料，你看到的全是当年觉得值得记的事。

实验通道正好相反：它能随时补 mundane 的东西——随便做一次测量的手感、一次失败的触觉。

但它探测不到预料之外的东西。实验只能回答你问得出的问题。

两条通道的偏差方向相反。

这就是科学既要做实验、也要读档案的结构性原因。

绝望只属于主观体验区（永久丢失、无法重测）；物理世界有活的实验通道，没那么绝望。

（“支撑集”这个词，[流形假设：15 万像素的图片，AI 凭什么只用 43 个数就认得？](https://mp.weixin.qq.com/s/z5OT4caCjpMsMKxLd7Zp7A) 里讲过它的几何版本。）

## 八、要打破支撑集，你需要两个组件——其中一个至今没有算法

### 组件一：贝叶斯只在支撑集内生效

先看第一件工具，贝叶斯更新。

它有个常被忽略的前提：后验只能在先验的支撑集内部重新分配权重。

证据如果落在“所有现有假设的似然都约等于零”的区域，后验纹丝不动。

也就是说——

模型自己的采样永远落在自己分布的支撑集里——探索半径被生成器本身锁死。

### 所以纯随机是陷阱

有人会说：那就随机采样呗，乱撞总能撞出点新东西。

高维空间里，这个直觉是错的。

随机样本几乎必然落在典型集里，信息增益约等于零。

随机性必须带方向。

论文之外的三条路：

- curiosity，拿不确定性当奖励；
- novelty search，直接奖励“不一样”；
- 仪器，把感官够不到的区域强行搬进可观测范围。

它们的共同点是**结构化的越界**——随机只是它们的零件，不是策略本身。

（为什么高维空间里“乱撞”没用，[高维空间为什么全是壳？内积才是那把尺子](https://mp.weixin.qq.com/s/Nrfr-90Fpu3mFDML9s0d1Q) 里有一整套几何解释。）

### 组件二：溯因，而它没有算法

第二件工具，比第一件麻烦得多。

新数据来了，还得有新假设去装它。

贝叶斯只能在**给定的假设菜单上做乘除**——它没有加菜的能力。菜单上没有的假设，哪怕它才是真相，后验也永远分不到一点权重。

皮尔士管这个能力叫溯因（abduction），“猜测的天赋”。

它在现有框架内，没有算法。

### 一个公式，和一句历史的旁注

把两件事写在一起：

**贝叶斯生效 = 尾部数据（采样器）× 新假设（溯因器）。**

任一为零，整体为零。

科学史上，采样器这件事靠工程解决——造仪器，把够不到的地方搬进可观测范围。溯因这件事，一直靠直觉，靠人。

顺带一句生物学旁注：进化早就为尾部采样付过预算。游戏、梦、艺术，这三样都没有直接适应度，却都需要专门的机制养着。

## 九、如果真要采“活的经验”，该采什么

### 黑客帝国采的是状态，西部世界采的是行动

黑客帝国采集的是状态（人当传感器，输出脑波）——溯因不住在状态里，住在行动里；

西部世界采集的是正在运转的溯因器（客人在追自己的目标，每个行动都是一次活的猜测）——不是数据库，是溯因器的原位观测站。

这个对照把问题问反了：

不要问“怎么把人身上的经验采下来”，要问“怎么让人正在进行的推理跑起来”。

### 但这条路有内伤

园区这个形态，有一个绕不过去的问题。

客人知道这里没有后果。

于是采到的不是这个人，是这个人**度假时的样子**——一种幻想态。

而这恰好毁灭了最稀缺的那层 mundane 经验。

一句话：**娱乐优化的环境，和数据优化的环境，目标函数是冲突的。**

### 两个必须承认的坑

第一个叫代表性修正的递归陷阱。

“谁来定义代表性？”这个问题没有干净的答案——你用来分层的那套框架，本身就来自现有档案。

而现有档案，就是第六节那条五层压缩链的产物。**采样框是理论负载的。**

第二个叫霍桑效应。

溯因器只有在自然状态下才输出真数据，而“自然状态”要求它不知道自己是样本。

务实的解法不是假装自己拿到了原始经验（拿不到），而是把“人在被观察时的系统性扭曲”当作**已知参数**，校准进模型。

![带宽、真实性、伦理性，现有原型最多占二](04-游乐场与窗口.png)

### 三角约束

带宽、真实性、伦理性——现有原型最多占二。

Ego4D 和 Aria 这类穿戴设备真实但窄；游戏遥测量大，可后果轻，还带自选择偏置；园区带宽最高，却有伦理和娱乐偏置。

### 所以，根本性的倒转在这里

活体经验的价值**不在“更真”**——未折射的原始经验，原理上就不可采集。

价值在**持续在线、持续生成新尾**。

园区的正确设计目标不是“采集代表性的人类”，而是引导人们去做没做过的事、体验没经历过的体验——把采集问题变成体验课程设计问题，最大化溯因器的运转密度。

采集问题，到此变成了课程设计问题。

## 十、回到论文：它造的是游乐场，不是窗口

### 全系统没有一个组件扮演实验员

把第九节那套判据拿回来，逐层检查 AgentGarten。

代码层是**封闭演绎**：公理给定，剩下全是推演，推不出菜单以外的东西。

渲染器是**离线传感器**：它学的是过去的真实，不产生新的真实。

agent 的探索是**封闭回路里的主动学习**：它在世界内部试错，但世界本身不变。

（顺手回收一下“溯因”这个词：溯因就是从结果反推出“能解释它的新假设”。它是唯一能跳出支撑集的动作——而这个系统里，没有组件在做这件事。）

结论是：它能恢复轨迹多样性，永远无法恢复本体论多样性。

### 不过它值得肯定的三件事

第一，它给出了一个稳定的训练基底，程序性技能在这个基底上真的涌现了——错误但一致的宇宙里，可学的部分照样可学。

第二，它把 sim-to-real 的桥，压在了“渲染器用真实视频训练”这条唯一的现实缝隙上。作者知道纯合成会塌缩，这一点从那个 GAN loss 就能看出来。

第三，它给了一条环境规模化的工程路径：世界库的数量本身，就是一种 domain randomization。

用多样性代偿真理性。

顺带说一句工程数字：480×832 的画面，单张 H100 上跑到 36.5 帧每秒。

这个数字包含条件编码、四步去噪、解码和主机传输。

一个 16 帧的服务块，稳态墙钟 438.8 毫秒，其中 Transformer 那部分占 414.4 毫秒。

这是可以真的跟 agent 交互的速度。

### 四项缺失实验

这是我读完这篇笔记之后，自己推出来的清单。

1. 训练之后迁移到真实世界的任务，看哪些能力塌、哪些幸存；
2. 渲染器的幻觉率对 agent 的行为错误率，画一条剂量曲线；
3. 世界库数量加到多少就饱和，也就是多样性代偿真理性的有效期；
4. 往这个回路里接一条在线现实反馈通道——哪怕极窄。

![如果这篇论文要补实验，我会先补这四项](09-缺失实验表.png)

**前三项是诊断，第四项是干预。**

标题里那个“还没人做的实验”，就是第四行：往这个封闭回路里，接一条哪怕极窄的**在线现实反馈通道**。

前三项只能告诉你这个系统丢了多少东西。

只有第四项，能改变它丢不丢。

### 收束

回到开头那两组数字：2,500 万局和第 4 轮之间，差的不只是效率，是练习场换了。

而练习场换掉的东西里，也包括“真”。

AgentGarten 是给“压缩后的世界”造游乐场；打破压缩需要的是给“活着的世界”造窗口。

它造的是前者，而且没有假装造后者。

这是它诚实的部分，也是它盲区的部分来源。
