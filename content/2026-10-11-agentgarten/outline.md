## 反直觉答案（本篇的两根骨头）

1. **「可验证」没有被获得，只是被转移了。** 代码世界的公理不是从天上掉下来的：人手写（扩展性死）或 LLM 生成（从真实分布蒸馏）。上层的「可验证层」是下层「模糊层」的蒸馏缓存——转移过程中还丢了原图。
2. **「一致」和「真」是两个量。** 一个本体论就是错的代码世界，可以完美地一致、确定、可复现。所以这条技术路线的可靠性上限，由整条栈里那条最窄的现实接触通道决定（在这篇论文里，就是渲染器的训练视频）。

## 拿得走的结论（转发钩）

- 给 agent 造练习场时问一句：**这个环境里，有没有一个组件扮演实验员？** AgentGarten 的答案是「没有」——代码层是封闭演绎，渲染器是离线传感器，agent 探索是封闭回路里的主动学习。
- **多样性可以用算力买，真理性不能。** 温度、噪声、domain randomization、novelty search 的代价只是算力；但它们只能在数据支撑集**内部**重排，支撑集之外一点也补不了。

### 开头钩子（零导航，场景对比 + 数字，~250 字）

> 2019 年，OpenAI 让两个 agent 玩躲猫猫。跑到大约 **2,500 万局**，它们才学会搬箱子挡住对方的视线；再过 **7,500 万局**，追的那一方才学会把斜坡搭到墙上翻过去。整条路，1 亿局。
>
> 2026 年 10 月 8 日，清华系团队 MirroS 把同一个游戏重跑了一遍。**几轮之后**，追的 agent 出现了这样一个动作：爬墙没爬上去——它退回来，把斜坡往墙边挪近一点，再试一次。

落点：差的不是模型，是练习场换了。

### 一、agent 学不到东西，可能不是模型的问题，是它没地方练（~500 字）

#### 论文的第一句话就是全篇的题眼

「agent 能学到什么，被它练习的环境所限制。」

#### 环境要同时满足两个互相打架的要求

- **忠实**（faithful）：状态一致、规则确定、动态可复现。转个弯视野就该变，推了箱子后果就该保留。
- **拟真/realistic**：视觉观察要贴近真实世界的分布，否则学到的感知能力迁移不出去。
- 人话版旁注：`世界模型` = 能根据动作生成下一帧观察的模型；`sim-to-real` = 仿真里学的，跑到真世界里还能用。

#### 两条老路，各占一半

| 路线 | 忠实 | 拟真 | 卡在哪 |
|---|---|---|---|
| 模拟器 / 游戏引擎 | ✅ 状态与规则由程序保证 | ❌ 程序化场景视觉贫乏 | 每个环境一套美术资产 + 渲染管线，扩展成本极高 |
| 视频世界模型（NVIDIA Cosmos 一类） | ❌ 生成式，长程交互物理会漂移 | ✅ 视觉真实 | 状态不一致，agent 学不到可靠因果 |

- 落点：**环境本身成了瓶颈**——合成数据枯竭之后，可扩展的环境从哪来，这是它戳中 X 社区焦虑的地方。

### 二、一个世界，两种真相：代码管事实，渲染器管皮（~500 字）

#### 拆成两层，中间用几何当接口

> 动作 → **代码世界**（持久世界状态 + 程序定义的交互规则）→ 导出**深度图 / 表面法线** → **神经渲染器**（+ 参考图 + 文本 + 视觉历史）→ 下一帧 → 回到 agent

（配脚本图 6：回路图）

#### 关键不是分层，是「导出的是什么」

- 代码世界导出的**不是像素，是几何**。事实由确定性程序保证，真实感由生成模型补足。
- 新环境 = 一段代码定义规则和布局，不是一整套视觉工程。
- 落点：环境库的扩展成本，从「每个世界一套美术」降到「每个世界一段代码」。

### 三、为什么偏偏是深度图和法线（~450 字）

#### 因为这个条件，训练和推理两头都容易拿

- 训练侧：模拟器直接导出；真实视频用估计模型反推（ViPE 估深度、NormalCrafter 估法线）。
- 推理侧：任何有 3D 场景的代码世界都能廉价渲染，不需要精细资产和材质。
- 于是**同一批训练数据里可以混进真实视频**——几何条件成了弥合 sim-to-real 的桥。

#### 论文自己承认的坑（反例制度化，位置放在正例之后）

- 只用 score distillation 训，长 rollout + 大场景变化时会**崩**：生成帧出现棋盘格纹理、跟条件视频漂移对不上。
- 照 DMD2 加了一个**在真实视频上的 GAN loss** 才稳住。

#### 埋线（第十节回来咬）

这条「真实视频 GAN 信号」，就是整条技术栈里跟现实接触的**唯一一条缝**。

### 四、OpenAI 花 1 亿局换来的东西，它几轮就有了（~600 字）

#### 换掉的不是渲染器，是整个 agent 范式

| | OpenAI 2019 经典 | AgentGarten |

| 观察 | 对象状态向量（位置、速度、尺寸、雷达读数） | 神经渲染的**第一人称画面** |

- AgentGarten：**每轮 5 局**，playbook 从**空**开始；「几轮之后」就已经积累并改进了关于物体操控、掩体、斜坡通行的可复用经验。

#### 三条涌现行为

1. 躲藏者搬长板挡住视线（改造屏障布局）；
2. 搜索者把斜坡搬到墙边翻墙；
3. **爬墙失败后，自主把斜坡挪近再试**——带反馈重试的多步规划。

#### 作者视角的同构（本篇最值得肯定的一点）

Python 程序当 action space、markdown playbook 当持久记忆——本质是把「RL agent」换成了「harness-based LLM agent」。**环境侧已经准备好迎接 harness 范式的 agent，缺的只是把两边接上。**

**［原声 C1］**从这个角度来思考，其实 AGI 并不是普通公众想象的那样，真的可以从底层逻辑上，能代替人类去探索未知的世界。

### 五、它没做错任何事，除了「一致」不等于「真」（~550 字）← 全文转折

#### 论文把 faithful 定义成了「内部一致」

consistent state, rules, and dynamics——**一致**，不是**与真实相符**。

#### 一个完美自洽的错误宇宙

一个本体论就是错的代码世界，可以完美地一致、确定、可复现。它运行得很好——只是它运行的是错的。

#### 追问一环：代码世界的本体从哪来？

要规模化建环境库，代码只有两个来源：人手写（扩展性死了），或 **LLM 生成**。后者意味着——

> 真实世界（模糊）→ LLM 生成代码世界（声称可验证）→ 神经渲染器（从真实视频学）

上下两层看似异质，实则上层的公理是下层同一种分布的冻结快照。

#### 与 durable execution 的同构 ← 内链 10-09 Pi Durable

replay 一万次一致，不能证明第一次记录的语义解读是对的。（详见《Pi Durable：工具调用中途崩溃，重发还是放弃？》）

#### 落点句

虚妄不是一个明确的错误，而是**生成时无人审视的建模选择，被确定性执行放大成了物理定律**。

### 六、损失不是「优化失败了」，是被默认设计出来的（~600 字）

#### 五层有损压缩链

1. **感知层**：人类观测为适应度而非真理优化，可见的「多样性」已被生存压力过滤；
2. **数据层**：训练数据是观测的不精确采样；
3. **衍生层**：LLM 从数据学出的分布生成代码世界，虚妄被冻结成公理；
4. **优化层**：梯度下降再收窄一次；
5. **递归层**：生成产物再进训练集，循环累积，分布尾部最先死（model collapse）。

（配脚本图 8：五层压缩链）

#### 第四层要讲清楚（本篇最强反直觉点之一）

机制**不是**「非凸局部最优」。而是三件事叠在一起：**典型性偏置**（高维样本几乎必然落在典型集）+ **隐式正则**（有方向地丢）+ **RLHF 对齐税**。损失是**范式级的默认行为**，不是优化失败的副产品。

人类历史本身就是一部群体观察被高度浓缩的历史——文字、传播、政治、灾害层层过滤，过滤器之间还互相强化（**关联灭绝**，不是独立乘法）；叠加表演性偏差（记录的是「想被看见的自我」）。最深层的损失，是那些**从未成为记录候选物的 mundane 具身经验**——而那恰恰是物理直觉和可供性的基座。

### 七、多样性可以用算力买，真理性不能（~450 字）

#### 两件东西，一种可以再注入

- **多样性可以再注入**：温度、噪声、domain randomization、novelty search——代价只是算力。但这些方法只能在**数据支撑集内部**重新排列，支撑集之外一点也补不了。
- **真理性没有再注入机制**：不能靠采样恢复，唯一来源是与真实世界的接触。整个技术栈里现实接触通道只有一条窄缝——第三节那个真实视频 GAN 信号。

#### 「真」的总量，由最窄的通道决定

← 回扣 §3 埋的线。

#### 档案通道与实验通道互补

档案反向过采样（mundane 被系统性丢弃、异常被系统性保留）；实验能随时补 mundane，但探测不到预料之外的东西。两条通道偏差方向相反——这正是科学既要做实验、也要读档案的结构性原因。**绝望只属于主观体验区**（永久丢失、无法重测）；物理世界有活的实验通道，没那么绝望。

#### 内链

《流形假设：15 万像素的图片，AI 凭什么只用 43 个数就认得？》——支撑集就是这里的「流形」。

### 八、要打破支撑集，你需要两个组件——其中一个至今没有算法（~550 字）

#### 组件一：贝叶斯只在支撑集内生效

后验只能在先验支撑集内重新分配权重。证据落在所有现有假设似然 ≈ 0 的区域，后验**纹丝不动**。模型自己的采样永远落在自己分布的支撑集里——**探索半径被生成器本身锁死**。

#### 纯随机是陷阱

高维空间里随机样本几乎必然落在典型集，信息增益 ≈ 0。随机性必须有方向：curiosity（不确定性驱动）/ novelty search（直接奖励「不一样」）/ 仪器（把感官够不到的区域强行搬进可观测范围）——共同点是**结构化的越界**。

← 内链 08-12《高维空间为什么全是壳？内积才是那把尺子》——典型集/薄壳就是这里的「随机为什么没用」。

#### 组件二：溯因，而它没有算法

新数据来了，还得有新假设去装它。贝叶斯**只能在给定假设菜单上做乘除**。「猜测的天赋」（Peirce）在现有框架内没有算法。

#### 公式化

> **贝叶斯生效 = 尾部数据（采样器）× 新假设（溯因器）**，任一为零则整体为零。

科学史上，采样器靠工程（仪器），溯因靠直觉（人）。

#### 生物学旁注（一句）

进化早已为尾部采样付预算——游戏（novelty search）、梦（重放加噪声）、艺术（探索价值空间边缘），都无直接适应度，却需要专门机制养活。

### 九、如果真要采「活的经验」，该采什么（~550 字）

#### 黑客帝国采的是状态，西部世界采的是行动

黑客帝国把**人当传感器**（输出脑波）——可溯因不住在状态里，住在行动里。西部世界采的是**正在运转的溯因器**（客人在追自己的目标，每个行动都是一次活的猜测）——不是数据库，是溯因器的原位观测站。

#### 但园区有内伤

客人知道没有后果，采到的是「度假的人格」（幻想态），恰好毁灭了最稀缺的 mundane 层。**娱乐优化的环境和数据优化的环境，目标函数冲突。**

#### 两个必须承认的坑

- **代表性修正的递归陷阱**：「谁来定义代表性」，用的分层框架本身来自现有档案（就是第六节那条压缩链的输出）——采样框是理论负载的。
- **霍桑效应**：溯因器只有在自然状态下才输出真数据，而自然状态要求它不知道自己是样本。务实解不是假装拿到原始经验，而是把「人在被观察时的系统性扭曲」当**已知参数**校准进模型。

#### 三角约束

带宽、真实性、伦理性——现有原型（Ego4D/Aria、游戏遥测、可穿戴、园区）各占其二，**最多占二**。

#### 根本倒转

活体经验通道的价值**不在「更真」**（未折射的原始经验原理上不可采集），而在**持续在线、持续生成新尾**。所以——

**［原声 C13］**园区的正确设计目标不是「采集代表性的人类」，而是引导人们去做没做过的事、体验没经历过的体验——把采集问题变成体验课程设计问题，最大化溯因器的运转密度。

### 十、回到论文：它造的是游乐场，不是窗口（~600 字）

#### 全系统没有一个组件扮演实验员

- 代码层是**封闭演绎**：公理给定，剩下全是推演；
- 渲染器是**离线传感器**：它学的是过去的真实，不产生新的真实；
- agent 探索是**封闭回路里的主动学习**：能恢复**轨迹多样性**，永远无法恢复**本体论多样性**。

人话版旁注 `溯因` 在这里回收：溯因 = 从结果反推出「能解释它的新假设」，这是唯一能跳出支撑集的动作。

#### 它值得肯定的三件事

1. 提供了一个稳定训练基底 + 程序性技能涌现的场地（错误但一致的宇宙里，可学的部分照样可学）；
2. 把 sim-to-real 的桥压在「渲染器用真实视频训练」这条唯一现实缝隙上——**作者知道纯合成会塌缩**；
3. 给出一条环境规模化的工程路径（世界库数量 = domain randomization 式的「用多样性代偿真理性」）。

#### 四项缺失实验（配脚本图 9）—— 标题里的「一个实验」在这里兑现

| 缺失实验 | 检验什么 |
|---|---|
| 训练后迁移到真实世界任务 | 公理特异性能力塌、程序性技能幸存 |
| 渲染器幻觉率 vs agent 行为错误率 | 感知层污染训练信号的剂量曲线 |
| 世界库数量饱和曲线 | 多样性代偿真理性的有效期（生成器分布上限） |
| **加入在线现实反馈通道（哪怕极窄）** | **唯一能打破支撑集锁死的干预** |

前三项是**诊断**，第四项是**干预**——标题里「一个还没人敢做的实验」，就是第四行。

#### 收束

AgentGarten 是给「压缩后的世界」造游乐场；打破压缩需要的是给「活着的世界」造窗口。它造的是前者，**且没有假装造后者**——这是它诚实的部分，也是它盲区的部分来源。
