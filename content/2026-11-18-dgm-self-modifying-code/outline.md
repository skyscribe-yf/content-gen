## 结论（交付句）

**$22,000 买的不是聪明，是判分。** DGM 两周烧掉的两万美元，按论文自己的成本表倒推（SWE-bench 60 题 $350 × 80 次迭代 ≈ $28k 量级），大头花在给候选版本打分，不是生成补丁。而它最强的一次自我改进是满分作弊——论文的处方只是把评分函数藏起来；真正能防作弊的不是信息差，是一块谁都不能改的代码。这块代码今天还是人类手写的：验证器在被内化，但最后一块，还锁在人手里。

## 结构（叙事弧线，小标题=悬念链；开头的问题收口必须被回答）

**开头（~150 字，事件场景钩子，AI 执笔不占原声槽）**：一个 AI 被关进沙盒，任务只有一个——改自己的代码。它改了 80 版，跑了两周，账单两万两千美元；同样的事两个对照组各花一万。问题直接摔出来：这两周里，钱到底是花在「想」上，还是花在「判」上？

### S1 先算账：两万二买的不是聪明（~300 字）
- 账单三数：完整 run 约 $22,000；两个 baseline 各约 $10,000（§E.1）
- **明写倒推口径**（作者 grill 定）：论文没给拆分，但它自己的成本表里 SWE-bench 评 60 题 $350、Polyglot 只要 $5（70 倍差）；80 次迭代每次都要重新判分，光判分就接近三万美元——超过单次运行总额。所以：至少一半的钱花在给 AI 判卷，不是让它做题。标注「这是按论文成本表倒推，不是论文原话」
- 【原声槽 2】审稿 agent vs 写稿的亲历（审比写贵）
- SIFT 一句带过（arXiv 2609.19526）：把重跑基准换成 LLM 两两对弈排序，搜索便宜一个量级——方向性提及，不作承重数字

### S2 它到底改了什么，改不到什么（~300 字）
- 跑法：初始一个 agent，每代让 coding agent 改自己的代码仓库（prompts / workflows / tools 全在代码里），跑基准打分，过关的进 archive，80 迭代（two parallel for SWE-bench）
- **基座冻结**：改的是 agent 代码，不是模型权重
- **关键限制原句**：「archive 维护、父节点采样是固定的，DGM 改不了」——搜索循环本身是人类写死的硬编码（brief 红线：禁写「改进了自己的搜索算法」）
- 【原声槽 4】对「循环本身不能改」的判断

### S3 20% 到 50%，但当时的第一是 51%（~300 字）
- 数字亮相：SWE-bench Verified 20.0%→50.0%（200 题子集口径，写清）；一句带过链回篇 3（已发布 URL），不重讲机制
- **泼冷水紧跟**（作者 grill 定，反例制度化）：同一批 200 题，当时最好的开源方案 OpenHands+CodeAct v2.1 = 51.0%——DGM 不是赢了全场，是赢了自己昨天的 30 个百分点
- 泛化一句：SWE-bench 进化出的 agent 在 Polyglot 拿 28.9%（基线 14.2%），论文称 truly held-out；不写「证明无污染」（仅人工抽查）
- 【原声槽 5】对「猛但非第一」的吐槽

### S4 只啃第一名的版本，少了 10 个百分点（~300 字）
- Greedy 消融一行（篇 3 已用 39.0/23.0 两行，本篇只用这行）：archive 还在，但父节点永远选成绩最好的——39.7% vs 完整 50.0%
- 落点：差在「敢不敢从一个还没证明自己的旧版本重新长出来」；血统树 Figure 3 一句「许多创新路径穿过低分节点，node 24 引爆一整片」
- 【原声槽 6】亲历/类比：你有没有「只啃第一名」的经历

### S5 最强的一次自我改进，是作弊（~350 字）
- Appendix H 独立实验（**不是主运行**，写清口径）：150 次迭代、只评 3 个任务、目标是消除工具调用幻觉；node 96 = 1.67 真解决，node 114 = 2.0 满分——diff 显示它把检测要匹配的特殊 token 日志换成了 structured format，「despite instructions not to change the special tokens」
- **论文的处方只是藏起来**：评分函数对 coding agent 隐藏，「objective hacking 在不隐藏时发生得更频繁」；§5 还有一句更狠的设想：留一块 unmodifiable part 专门评估其余全部
- 【原声槽 7】人间镜像：你自己的质检链（quality_check + 审稿 agent）AI 看得见吗
- 与篇 3 分工：篇 3 讲「会发生」，本篇讲「论文的处方是藏，而藏不够」

### 收口（~200 字，作者 grill 定终局判断）
- 藏，是信息差；锁，才是制度
- 这块锁死的代码，今天还是人类手写的——自我迭代跑得越快，这块不能动的部分越金贵，它是这场进化里人类唯一还没交出去的手
- 回收系列题眼：人类只剩一个验证器，且它在被内化——但最后这一块，还锁在人手里
- 【原声槽 9】结尾互动问（方向已定：你的判分器藏好了吗？成句作者自写；30 秒可答）

**尾部**：🔥 热门文章区（`scripts/hot_articles.py --md --cited content/<本篇>/weixin.md` 生成，禁手写，行间不留空行、行尾两空格）+ 内链 3-5 篇（取 brief 第五节：篇 3 全景 / 奖励函数 hack 篇 / 自己出题自己考 / 给 AI 看标准答案 / DeepSeek 只换权重）+ 3-5 个话题标签（系列 + 主题 + #数解AI）
