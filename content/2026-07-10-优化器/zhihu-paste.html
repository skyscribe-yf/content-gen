梯度已经告诉模型：该往哪边走。
但模型还有一个麻烦：每个参数都要走同样大的步子吗？

不行。

有些参数的梯度很大，走一步就冲过头；有些参数的梯度很小，走半天还没动。SGD 却只给所有参数同一个学习率。

同一把尺子，量不了所有参数。

这就是 Adam 要解决的问题： 让每个参数，都有自己的步长。

前五篇讲了梯度从哪里来、怎么传回去。今天看最后一步：拿到梯度之后，模型到底怎么迈步？

梯度下降那篇给出了最朴素的答案：沿负梯度方向走一步。更新规则简单到只有一行：

θₜ₊₁ = θₜ − η · gₜ

η 是学习率，gₜ = ∇L(θₜ) 是当前点的梯度。梯度说往哪走，就往哪走。步长 η 固定不变。

这是随机梯度下降（SGD）——深度学习里最基础的优化器。就一行公式，没有多余的东西。

但这行公式藏了一个致命假设：η 对所有参数一视同仁。 你的模型可能有百万个参数，权重 W 的梯度比偏置 b 大 100 倍——同一个 η，要么让 W 震荡不止，要么让 b 原地不动。一刀切。

怎么解决？看这个公式：

θₜ₊₁ = θₜ − η · m̂ₜ / (√v̂ₜ + ε)

这就是 Adam。名字不是人名——Adam 是 Adaptive Moment Estimation 的缩写，自适应矩估计。方向（m̂ₜ）÷ 尺度（√v̂ₜ），一步到位。

2015 年，Diederik Kingma 和 Jimmy Ba 在 ICLR 上发了这篇论文。一个博士生和一个教授，两个人，一篇论文，120,000+ 次引用——深度学习史上被引最多的优化器。

这篇把 Adam 公式拆开，看每一部分解决了 SGD 的什么问题。不只是"Adam 比 SGD 快"，而是为什么快，数学上哪一步起了作用。

💡 直觉解释：参数作为随机向量的视角

先退一步，问一个更基础的问题：模型的参数到底是什么？

在概率论视角下，训练模型本质上是最大似然估计（MLE）——找一组参数 θ，让观测到的数据出现的概率最大。这组参数不是一个确定的值，而是一个随机向量：每个参数都有一个"最可能取值"，但不同参数的不确定性不一样。

这个随机向量的分布形状，就是损失函数在最优解附近的样子。对于二次型损失（比如线性回归的均方误差），损失函数的等高线是一个椭球——每个轴的长度对应那个方向上的曲率（Hessian 矩阵的特征值）。

曲率大的方向 = 损失面陡峭 = 参数不确定度小（数据对它的约束很强）。曲率小的方向 = 损失面平缓 = 参数不确定度大（数据对它的约束很弱）。

这就是高斯椭球的由来——不是凭空画个椭圆，而是每一个机器学习问题，只要你用二次损失，最优解附近就一定是一个椭球。 椭球的长短轴比例，就是 Hessian 的最大特征值和最小特征值之比——数学上叫"条件数"（condition number）。

条件数越大，椭球越扁。越扁的椭球，SGD 越难受。

💡 直觉解释：椭球上的 SGD 困境

现在具体看一个例子。想象一个极端的二维损失函数：

f(x, y) = (x²/100) + y²

x 方向极平缓（梯度小），y 方向极陡峭（梯度大）。等高线是一个被压扁的椭圆——长轴 100 倍于短轴。条件数 = 100。

这个椭球对应一个真实场景：假设你有一个模型，两个参数 θ₁（对应 x）和 θ₂（对应 y）。数据告诉你 θ₂ 必须是 0.5（y 方向约束很强），但 θ₁ 在 0 到 10 之间数据都差不多能接受（x 方向约束很弱）。所以损失面在 y 方向像一个深谷，x 方向像一个平盘。

SGD 在这样的地形上怎么走？每一步沿负梯度方向迈固定步长：

θₜ₊₁ = θₜ − η · ∇f(θₜ)

梯度指向最陡下降方向——在椭球上，指向短轴（y 方向）。于是 SGD 沿着陡壁之字形震荡着往下走：跨一步冲到对面，再跨一步冲回来。而在 x 方向（真正该走的路），几乎没动弹。

为什么震荡？ 同一个 η 用于两个方向——y 方向本来就陡，η 显得太大；x 方向本来就平，η 显得太小。一刀切的结果就是：最该走的方向没走，最不该走的方向反复横跳。

这是所有一阶优化器的核心矛盾：参数的尺度不一样，但学习率只有一个。

回到概率视角：这不是 SGD 的算法缺陷——是数据本身的特性。你的数据对某些参数的约束强、对另一些弱，椭球是数据决定的，不是优化器决定的。数据越"偏心"（条件数越大），一刀切的 SGD 就越难受。

所以问题不是"优化器能不能练得更好"——而是需要一种方法，自动感知每个参数的不确定度，给不同方向分配不同的步长。

Momentum 迈出了第一步改进。它给梯度加惯性——上一步往右走，这一步也往右偏。震荡方向（反复横跳）的梯度会自动抵消，而一致方向（持续下坡）的梯度会累加：

vₜ = β·vₜ₋₁ + η·∇f(θₜ) θₜ₊₁ = θₜ − vₜ

Momentum 像滚雪球——方向一致时越滚越快，方向反复横跳时自然减速。它解决了震荡，但没解决尺度差异。y 方向依然比 x 方向受 η 的影响大 100 倍。

Adam 要解决的，就是这个问题。

🔬 Adam 的诞生

2015 年，阿姆斯特丹大学。Diederik Kingma 在读博士，导师是 Max Welling。他和 Jimmy Ba（当时在多伦多大学）合写了一篇论文投到 ICLR 2015。

当时优化器领域已经有很多尝试：RMSProp 用梯度平方的滑动平均来缩放步长，AdaGrad 累加所有历史梯度平方，Momentum 用惯性平滑轨迹。Kingma 和 Ba 把两件事合在一起——既要动量，也要自适应缩放——然后加了一个偏差修正的补丁。

论文标题很直接：Adam: A Method for Stochastic Optimization。8 页，4 个公式，没有复杂的理论推导。审稿人一开始给的分不高，但 ICLR 接收之后，引用量爆炸。

为什么这么简单的想法火成这样？因为它刚好站在了两个流派的交叉点上：Momentum 流（物理直觉）和 AdaGrad/RMSProp 流（自适应学习率）。Adam 是这两个家族的第一个结合品——而且是能用的那种。之前也有结合的尝试，但要么实现复杂，要么数值不稳定。

📐 数学原理

现在正式拆公式。Adam 的更新规则是四个方程：

mₜ = β₁·mₜ₋₁ + (1−β₁)·gₜ vₜ = β₂·vₜ₋₁ + (1−β₂)·gₜ² m̂ₜ = mₜ / (1−β₁ᵗ)     v̂ₜ = vₜ / (1−β₂ᵗ) θₜ₊₁ = θₜ − η · m̂ₜ / (√v̂ₜ + ε)

四个方程，逐个拆。

第一行：mₜ —— 给梯度加记忆

mₜ = β₁·mₜ₋₁ + (1−β₁)·gₜ

mₜ 是梯度的指数滑动平均。β₁ = 0.9 意味着：当前这一步，90% 看历史方向，10% 看新梯度。

打个比方：你在浓雾里下山，每一步踩下去，脚底感觉到一点的坡度——这是当前梯度。但你不能只看脚下，得记着上一步走了什么方向。 上一步往左走，这一步如果坡度也往左，你就放心迈大步；上一步往左、这一步坡度往右，你就犹豫一下，少走点。

这就是动量。它在做什么？震荡方向自动抵消，一致方向自动加速。

在二维椭球上：y 方向的梯度符号来回变（因为之字形震荡），累加后会趋近于 0；x 方向的梯度方向始终一致（因为一直往下走），累加后越来越大。mₜ 天然地放大了一致方向、抑制了震荡方向。

但 mₜ 只解决了方向问题，没解决尺度问题。100 倍的梯度差异还在。

第二行：vₜ —— 给每个参数自己的学习率

vₜ = β₂·vₜ₋₁ + (1−β₂)·gₜ²

vₜ 是梯度平方的指数滑动平均。别被"指数滑动平均"吓到——它就是"最近 N 步的平均"，只是越近的步子权重越大。

β₂ = 0.999 意味着：vₜ 在追踪——这个参数的历史梯度平均有多大？记忆窗口大约是 1/(1−0.999) = 1000 步。

关键来了。在最终的更新公式 θₜ₊₁ = θₜ − η · m̂ₜ / √v̂ₜ 里，vₜ 出现在分母。

打个比方：你家水龙头有两个旋钮——一个管冷水、一个管热水。冷水管很粗（大梯度），你拧 1 度就喷一脸；热水管极细（小梯度），你拧 10 度才出来一点点。 SGD 给你一把扳手，两个旋钮拧同样的角度——冷水那边早就泛滥了，热水还冰凉。

vₜ 做的事就是：记住每个旋钮的历史——冷水那个一直哗哗流，v 就大，自动减速；热水那个流水细，v 就小，自动加速。 拧几次之后，两个水龙头出水量自动平衡了。

在二维椭球上：y 方向的梯度一直很大 → v_y 大 → η/√v_y 小。x 方向的梯度一直很小 → v_x 小 → η/√v_x 大。Adam 自动给 x 方向迈大步，y 方向迈小步。

不需要手动调每个参数的学习率。vₜ 替你在做。

第三行：偏差修正 —— 一个工程补丁

mₜ 和 vₜ 初始化为 0。所以训练第一步时，m₁ = (1−β₁)·g₁，v₁ = (1−β₂)·g₁²——比真实值小了 10 倍（对 m）或 1000 倍（对 v）。

打个比方：你第一次去一家餐厅，Yelp 上没有评分（初值 = 0）。第一次吃完你觉得还不错，但因为你之前没有参考，你的评价会被"打折"。多吃几次后，你自己积累的评分权重越来越大，修正就自动淡出了。

m̂ₜ = mₜ / (1−β₁ᵗ)

除以 (1−β₁ᵗ) 就是放大前面几步。当 t 很大时，β₁ᵗ → 0，修正因子 → 1——不需要修正了。这个补丁只在训练开头有用，几分钟后就可以忽略。

💡 喘口气，回顾一下。 我们刚拆了四个方程：mₜ 给梯度加记忆（动量）、vₜ 追踪梯度尺度（自适应）、偏差修正是工程补丁（初始几步放大）、最后 m̂ₜ / (√v̂ₜ + ε) 合在一起就是方向 ÷ 尺度。每一步都是冲着 SGD 的一个缺陷去的——没有多余的符号。

每一个符号都有动机：

符号做了什么解决了什么
m̂ₜ（分子）梯度的方向估计SGD 的震荡——动量让方向更稳定
√v̂ₜ（分母）梯度的尺度估计SGD 的一刀切——大梯度自动减速、小梯度自动加速
ε（10⁻⁸）防止除以 0数值稳定，纯工程项
β₁ᵗ, β₂ᵗ 修正前几步放大m 和 v 初始为 0 的偏差

没有多余的符号。 四个方程，覆盖了 SGD 的所有已知缺陷。

合在一起：方向 ÷ 尺度

把四个方程压成一句话：

θₜ₊₁ = θₜ − η · (方向估计) / (尺度估计)

分子决定往哪走，分母决定走多大步。Adam 的本质是一个逐参数的 SNR 估计器。 把梯度想象成"信号 + 噪声"——m̂ₜ 估计信号（梯度的真实方向），√v̂ₜ 估计噪声（梯度的波动幅度）。信噪比高的参数大步走（方向明确），信噪比低的参数小步走（方向模糊）。

这也就是为什么 Adam 能同时解决震荡和尺度差异：震荡参数 = 高噪声 → 分母大 → 步长小。平缓参数 = 低噪声但信号也小 → 分母小 → 步长大。一切自动。

🌍 拓展：DeepSeek-V3 和 Qwen3 怎么用 Adam

Adam 不是教科书玩具。DeepSeek-V3 和 Qwen3 的训练配置里，清清楚楚写着 AdamW：

从 HuggingFace 仓库里直接拉数据：

模型优化器β₁β₂weight_decay
DeepSeek-V3AdamW0.90.950.1
Qwen3AdamW0.90.950.1

两个亮点：

第一，都用 AdamW，不是原版 Adam。 AdamW 是 2017 年 Ilya Loshchilov 和 Frank Hutter 的改进——把权重衰减从 L2 正则里拆出来，直接加到参数更新上。原版 Adam 的 L2 正则和自适应学习率会互相干扰，AdamW 一刀切干净了。现在所有大模型默认 AdamW。

第二，β₂ = 0.95，不是经典的 0.999。 为什么降这么多？大模型训练时，batch size 巨大（几千甚至上万），每一步梯度本身就比较稳定。β₂ = 0.999 意味着 vₜ 对历史梯度的记忆窗口是 1/(1−0.999) ≈ 1000 步——对稳定的大 batch 梯度来说，1000 步前的东西已经没有参考价值了。降到 0.95 相当于记忆窗口缩短到 20 步，让优化器更快响应最新的梯度变化。

（来源：DeepSeek-V3 Technical Report §4.2；Qwen3 torchtitan config_registry.py）

⚠️ 但这已经是 2024 年的配方了。2025-2026 年，优化器的牌桌变了。Kimi K2（2025，1万亿参数）率先全量采用 Muon 的改进版 MuonClip 从头训到尾——15.5 万亿 token，零 loss spike。DeepSeek-V4（2026年4月发布）紧随其后，把大部分参数换成 Muon 优化器，只留 embedding 和输出层给 AdamW。Adam 的文章还没写完，但下一章已经开始。

🌍 拓展：Adam 不是终点——SGD 的复仇

Adam 很强，但不是无敌的。

有研究发现：SGD 在某些任务上泛化更好。为什么？Adam 太快找到了一个平坦的极小值，但 SGD 带着噪声在损失表面上晃悠，有时候晃进了更深的谷底。Adam 的收敛速度 = SGD 缺少的探索噪声。

所以现在流行的策略是 SWATS（Switches from Adam to SGD）：先用 Adam 快速靠近最优区域，再切换到 SGD 做精细调优。或者反过来用 warmup——先用很小的学习率预热，再让 Adam 全速跑。

没有免费的午餐——优化器的选择本身也是一个超参数。 Adam 不是万能药，但它是工具箱里最好用的那把锤子。

而且锤子的下一代已经来了。2024 年，Keller Jordan 提出了 Muon 优化器——不再像 Adam 那样逐元素缩放，而是对整个参数矩阵做 Newton-Schulz 迭代，把梯度更新矩阵正交化，一步释放所有更新方向。Kimi K2（2025）率先自研 MuonClip，15.5 万亿 token 全程不用 AdamW；DeepSeek-V4（2026，1.6万亿参数）紧随其后，把大部分参数从 AdamW 换成了 Muon。 这篇我们后面单独讲。

🔄 回扣原理

回到开头的公式：

θₜ₊₁ = θₜ − η · m̂ₜ / (√v̂ₜ + ε)

SGD 的问题是一刀切——同一个 η 管所有参数，不管梯度大小。Adam 的解法是：给每个参数单独算一个学习率。

分子的 m̂ₜ 是方向估计——动量让震荡自动抵消、一致方向自动加速。分母的 √v̂ₜ 是尺度估计——梯度大的参数自动减速，梯度小的参数自动加速。两者一除，就是方向 ÷ 尺度。一个公式，一步解决震荡 + 尺度差异。

SGD → Momentum → Adam：每一步改进都对应公式里多出来的一个符号。动量加了一个 m，自适应加了一个 v，偏差修正加了一个 (1−βᵗ)。四条规则，没有第五条。

在二维高斯椭球上，SGD 之字形震荡着往下蹭，Adam 一条弧线切到谷底——不是"快了 10 倍"这种粗略估计，而是每一步都在最该走的方向上走了最合适的步长。

📌 一句话总结

SGD 用同一个学习率 η 更新所有参数，导致大梯度震荡、小梯度不动；Adam 用 m̂ₜ（方向估计）除以 √v̂ₜ（尺度估计），给每个参数自动调速——大梯度自动减速、小梯度自动加速；DeepSeek-V3 / Qwen3 用 AdamW 训练，β₂ 从经典 0.999 降到 0.95 让优化器更快响应新梯度；最新一代 DeepSeek-V4 和 Kimi K2 已转向 Muon 优化器。

Adam 自动调学习率，但 SGD 反而可能泛化更好——到底该信谁？
