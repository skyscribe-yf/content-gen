# 马尔可夫决策过程：AI 怎么在不确定里做选择

## 文章定位

- 本篇是「强化学习原理」系列第一篇（地基篇①），系列兑现 PPO 篇（07-31）文末预告「TRPO 的完整数学推导和 trust region 的几何直觉，我们留到强化学习系列」的起点。主线：**AI 做决策为什么不能只看眼前——序列决策需要一套数学语言：随机过程描述世界、马尔可夫性质描述「健忘」、MDP 五元组描述决策、折扣回报描述长远账**。
- 主线冲突（谜题式）：**一个 coding agent 修 bug，要调 30 次工具。第 3 步选错工具，后面 27 步全白费。** 悬念链：为什么不能只看眼前（序列决策的困境）→ 世界是随机的（随机过程）→ 马尔可夫性质（健忘）→ MDP（加上决策和奖励）→ 折扣回报（长远账的数学）→ 反常识爆点（大模型算不算马尔可夫）。
- 啊哈时刻（反常识点，文章高潮）：**大模型生成是「上下文窗口内的高阶马尔可夫」——窗口内严格只依赖当前上下文，窗口外完全健忘。这既是它高效的原因，也是 agent 长任务崩溃的根源**（呼应 KV 磁盘篇 08-10 与上下文并行篇 08-14）。
- **归属校准（系列惯例）**：马尔可夫性质来自 Markov（1906），MDP 框架由 Bellman 于 1950s 奠定（作者笔记简史）；现代 RL 的发明（PPO/GRPO 等）不回溯安到古人头上。折扣回报的收敛性（M/(1−γ)）是经典结果，非任何模型独有。
- **防炒冷饭边界**：已发 PPO（07-31）/GRPO（08-01）/RLVR（08-02）篇是概念+案例（数学 B 级不推导），本篇只立地基：随机过程、马尔可夫性质、状态转移矩阵、MDP 五元组、折扣回报收敛。不碰：Bellman 方程与值函数（篇2）、平稳分布与多维高斯（篇3）、Actor-Critic（篇4）、TD/策略梯度（篇3-4 经典算法段）、TRPO/PPO 数学（篇5-6）、GAE/GRPO/奖励设计（篇7-9）。
- 数学深度：B+ 级。三组数学：①马尔可夫性质形式化 $P(s_{t+1}|s_t,a_t)$ 与全历史无关；②状态转移矩阵（行和为 1 的随机矩阵）；③折扣回报收敛证明 $|G_t| \leq M/(1-\gamma)$（几何级数）。
- **素材来源（作者原声）**：作者笔记《强化学习及主要算法简介》（一）基本概念 +（二）数学基础——「健忘」的随机过程、婴儿学语言类比、状态转移矩阵、回报与折扣、守得云开见月明；Sutton & Barto《Reinforcement Learning: An Introduction》Ch3（MDP 定义、折扣回报）作数学权威；Obsidian 无 MDP 笔记（已核查）。
- 下一篇预告：篇2 **Bellman 方程**——价值函数怎么递归，所有 RL 算法（Q-learning→PPO→GRPO）本质都在解它。
- **案例方案（grill 收敛）**：通用 coding agent 修 bug 场景（30 步工具调用，第 3 步选错全崩）+ 推理模型 CoT（想 5000 字再回答，每步思考影响最终答案）；文末一句带过 GLM-5.2 长程任务（呼应 PPO 篇案例），不点名热点模型（避免热点过期）。

## 核心结论

1. **序列决策 ≠ 单步决策**：AI 的每一步都影响后面，只看眼前一步的最优，往往是全局的灾难（agent 修 bug 第 3 步选错工具）。
2. **随机过程是序列决策的语法**：状态序列 $S_1, S_2, \ldots$ 的数学；马尔可夫性质 = 「健忘」——下一步只依赖当前状态，与更早历史无关。
3. **状态转移矩阵**：行和为 1 的随机矩阵，描述「从哪到哪的概率」；不是每个环境都是满秩方阵（动作约束）。
4. **MDP 五元组 (S, A, P, R, γ)**：随机过程 + 决策（策略 π(a|s)）+ 奖励，构成强化学习的标准建模语言；轨迹 = 一次交互的状态序列。
5. **折扣回报**：$G_t = \sum_{k} \gamma^{k} R_{t+k+1}$，γ<1 保证有限（$|G_t| \leq M/(1-\gamma)$）；γ 是「今天的钱比明天值钱」的数学化，平衡短期利用与长期探索。
6. **反常识**：大模型 = 上下文窗口内的高阶马尔可夫——窗口内严格依赖当前上下文（高效），窗口外完全健忘（长任务崩溃根源）。

## 结构（预计 7 节 + 结尾，正文 ~3000 字）

- 开头（~300 字）：场景悬念——coding agent 修 bug 调 30 次工具，第 3 步选错，27 步白费。为什么不能只看眼前？+ 系列宣告：「强化学习原理」开篇，10 篇地图（地基 4 + 深潜 6），回链已发的 PPO/GRPO/RLVR 篇（读者见过算法，今天补地基）。
- 一、为什么不能只看眼前（~400 字）：单步决策 vs 序列决策；两个案例——agent 修 bug（30 步链条，一步错全崩）+ 推理模型 CoT（想 5000 字再回答，每步思考影响最终答案）；引出：需要一套描述序列决策的数学语言。
- 二、随机过程：世界是随机的（~400 字）：状态序列；每一步都有多种可能（机器人迈步可能被气流吹回原地——笔记原声）；随机过程 = 描述「随时间演化的不确定性」的数学。
- 三、马尔可夫性质（数学深潜①，~500 字）：「健忘」特征（原声句）；$P(s_{t+1}|s_t)$ 与全历史无关；状态转移矩阵（行和为 1，随机矩阵；非满秩方阵的说明）；为什么「健忘」是简化也是力量（只记当前状态，数学上才可处理）。
- 四、反常识爆点：大模型算不算马尔可夫？（~400 字）：大模型生成 = 给定上下文猜下一个 token——上下文窗口内的高阶马尔可夫；窗口外完全健忘；这解释 agent 长任务为什么崩（呼应 KV 磁盘/上下文篇）；「健忘」是高效的原因，也是崩溃的根源。
- 五、MDP：给随机过程加上决策（~400 字）：五元组 (S, A, P, R, γ)；策略 π(a|s)（确定性 vs 随机）；奖励（正负、稀疏——AlphaGo 只有终局 +1/-1/0，笔记原声）；轨迹。
- 六、回报与折扣（数学深潜②，~500 字）：$G_t = \sum_{k=t+1}^{T} \gamma^{k-t-1} R_k$；γ 的直觉（今天的钱比明天值钱；长期 vs 短期平衡）；收敛证明 $|G_t| \leq M/(1-\gamma)$（几何级数，拉读者算账：γ=0.9 时 1/(1−0.9)=10 倍）；为什么 γ<1 是数学必需（无穷和收敛）。
- 结尾（~200 字）：回扣 agent 修 bug——用 MDP 语言重述这个场景（状态=代码库+日志，动作=调工具，奖励=测试通过）；预告篇2 Bellman 方程（价值函数怎么递归，所有 RL 算法都在解它）；开放式问题（你遇到过「只看眼前」的 AI 决策翻车吗？）；关注引导 + 系列合集。
