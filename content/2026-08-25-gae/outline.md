# GAE：100步的功劳，为什么只认最近17步？

## 文章定位

- 「强化学习原理」系列第八篇。兑现三重预告：系列路标⑤「高斯 → TRPO → PPO 数学 → GAE → GRPO 数学」、策略梯度篇（08-19）正文立约「很多步的 δ 按衰减加起来，叫 GAE……完整式子放到后面」、PPO 篇 critic/GAE 一句带过。
- 一句话承诺（grill 定案）：**GAE 是把一场长跑的功劳按指数衰减分给每一步「意外」的功劳分摊器**——总回报明明拿到了，为什么还要额外猜每一步的功劳？因为训练要的是「哪一步立了功」，不是「总共立了多大功」。
- 认知交付三件套（grill 定案）：① 功劳分摊器主菜（A_t = Σ(γλ)ᵗδ_t，功劳 = 每一步的意外，越远越衰减）② λ 方差反差（λ=0.95→1 只差 0.05，方差炸 8.5 倍；λ=1 是 λ=0.5 的 91 倍——真实回报反而方差最大）③ 有效视野直觉（γλ=0.9405 → 只看最近 16.8 步）。
- 数学边界（grill 定案）：**全链轻推**。三处推导各 150–300 字：① δ_t = r_t + γV(s_{t+1}) − V(s_t)（TD error = 这步的意外）② 指数衰减求和 Σ(γλ)^l δ ③ λ=0/1 两端极限（MC vs 1 步 TD）+ 闭式权重和 1/(1−γλ)。复用系列已有工具：γ 折扣、V 值函数、策略梯度篇的 A_t 直觉。
- 数字例子（grill 定案 + 蒙特卡洛事实验证）：线性走廊随机游走 + 噪声奖励 + 带误差 critic（0.12·max|V| 系统性低估 + 白噪声），60 万轨迹 λ 扫描。

## 核心结论

1. **功劳分摊难题**：轨迹拿到了总回报，但训练需要「每一步该受到多大推动」——只有总账、没有分账，策略不知道该往哪改。
2. **TD error（δ_t）**：δ_t = r_t + γV(s_{t+1}) − V(s_t)，人话 = **这一步的实际收益，比预期好了多少**（意外）。它是「单步分账」的基本单位。
3. **GAE 公式**：Â_t = Σ_{l≥0} (γλ)^l δ_{t+l}——从这一步出发，把后面每一步的意外按 (γλ)^l 逐级打折收进来。**越远的步，功劳折扣越狠**。
4. **有效视野**：权重和 1/(1−γλ)。γ=0.99、λ=0.95 时 (γλ)=0.9405 → 只看 ~17 步；λ=1 时看全程。**16.8 步 vs 100 步**：只差 0.05，视野差 6 倍。
5. **λ 两端**：λ=0 只信这步（1 步 TD，低方差高依赖 critic）；λ=1 信全程（MC，方差爆炸）。实测 λ=1 方差是 λ=0.95 的 **8.5 倍**、λ=0.5 的 **91 倍**——「真实回报反而方差最大」是这篇的反直觉主菜。
6. **critic 误差进账**：λ 越大，起点 critic 误差全盘进账（λ=1 偏差 −0.39 vs λ=0.95 −0.09）——λ 也是「信 critic 还是信实测」的旋钮。
7. **结论**：λ≈0.95 不是玄学，是「信 17 步内的功劳 + 折扣远处的噪声」的工程平衡点。

## 结构（7 节 + 结尾，正文 ~4100 字）

- **开头（~280 字）**：连续剧场景钩子（零导航）——深夜 agent 跑完 100 步工具调用链终于成功，老板问「功劳记给谁？」它愣了：总回报拿到了，但每一步的功劳怎么分？抛问题：只记总账，模型凭什么知道下一步往哪改？（呼应 PPO 篇的 agent C 深夜连续剧）
- **一、只记总账，训练就瞎了（~450 字）**：为什么不能「总回报给每一步都记一份」？两个致命伤：方差爆炸（每次跑结果不一样，每一份都跟着抖）+ 功劳均摊（关键的转折步骤和摸鱼步骤被平均掉）。直觉例子：100 步流水线，第 73 步引入 bug、第 81 步修正——均摊功劳无法体现「哪步立了功」。悬念：单步分账的基本单位是什么？
- **二、TD error：这一步的「意外」（~500 字）**：δ_t = r_t + γV(s_{t+1}) − V(s_t)。人话拆解：V 是「从这里开始往后大概能拿多少」（策略梯度篇旧概念一句复述）；r_t + γV(s_{t+1}) 是「真走到了这一步之后的现实」；减 V(s_t) 是「出发前以为会拿多少」。差 = **意外**（现实比预期好多少）。负值 = 现实不如预期（该扣）。至此给出第一个新术语 δ（说人话：意外）。
- **三、功劳分摊器：把意外按指数打折汇总（~550 字）**：Â_t = Σ (γλ)^l δ_{t+l}。逐个符号人话：δ_{t+l} 是「第 t+l 步的意外」，(γλ)^l 是「越远越打折」，求和 = 把后面所有意外按折扣汇总成一步的总功劳。对应前面流水线例子：第 81 步修正的意外（正）会以 (γλ)^8 的折扣记到第 73 步头上——**功劳传到，但越远越淡**。给闭式：所有权重相加 = 1/(1−γλ)（几何级数，一行带过）——这就是「有效视野」的数学来源。
- **四、0.05 的距离：λ=0.95 与 λ=1 的视野差 6 倍（~500 字 + 数字图）**：λ 两个极端先摆明：λ=0 只看这步（1 步 TD）、λ=1 全程看（MC）。然后反差：γ=0.99 时 λ=0.95 → (γλ)=0.9405 → 权重和 = 1/(1−0.9405) ≈ **16.8 步**；λ=1 → 100 步。**0.05 的差距，视野差 6 倍**——因为 1/(1−x) 在 x→1 附近是发散的，越靠近 1 越敏感。数字图（脚本）：(γλ)^l 权重衰减曲线 λ=0.95 vs 1 对照 + 16.8/100 标注。
- **五、真实回报，方差为什么最大？（~550 字 + 数字图）**：反直觉主菜。蒙特卡洛实测（λ 扫描表）：λ=0 方差 1.03 → λ=0.5 是 1.40 → λ=0.95 是 15.0 → λ=1 是 128.1。**λ=1 是 λ=0.95 的 8.5 倍，是 λ=0.5 的 91 倍**。直觉：λ=1 把 100 步的随机奖励全加进来，方差当然滚雪球；λ=0.95 只加最近 17 步的意外，远端噪声被折扣挡在门外。反直觉点（标题燃料）：**「真实」不等于「好用」——全程真实回报方差最大，反而是折扣过的「近视估计」更稳**。数字图（02）：λ 扫描偏差/方差双线 + 反差标注。
- **六、critic 误差进账：λ 是信任旋钮（~450 字）**：λ=1 时起点 critic 误差一次全进（实测 −0.39）；λ=0.95 只进约 1/4（−0.09）；λ=0 差分抵消常数偏移（−0.00）。人话：λ 小 = 更信 critic 的局部判断（critic 错就跟着错）；λ 大 = 更信实测（critic 起点误差全盘入账）。工业默认 λ=0.95 的另一个理由：critic 是粗的，别全信，也别丢光实测。
- **结尾（~300 字）**：回扣开头 agent：100 步的链，功劳不是均分也不是全归最后一步——按意外大小、按距离打折。一句话总结卡（分享借口：「GAE 不是估回报，是把 100 步的功劳按 16.8 步的有效视野打折发放——0.05 的 λ 差距，8.5 倍方差」）。预告 GRPO 数学（路标⑤下一站，一句话不展开）。文末问题（功劳分法站队型）+ 点赞/关注/收藏 + 近期热门 + 参考资料 + 话题标签。
