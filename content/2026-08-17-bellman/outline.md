# 贝尔曼方程：为什么只看下一步就够了？

## 文章定位

- 「强化学习原理」系列第二篇（地基篇②），承接 08-16 MDP 篇。兑现第一篇结尾原话预告：「下一篇讲怎么算这笔账——Bellman 方程。价值函数怎么递归，为什么 Q-learning、PPO、GRPO 这些算法，本质都在解同一个方程。」
- 一句话承诺（grill 定案）：**价值函数把「从当前状态到终局的所有未来奖励」压缩成一个数；Bellman 方程就是这个压缩的递归恒等式。**
- 动机必须讲透（作者明确要求）：主论证 A——决策发生在「未来还没发生」的时刻，必须有一个只看当前状态就能算的数；辅助论证 B——把所有未来路径展开再平均会指数爆炸（30 步 × 每步 3 分支 = 3^30 ≈ 205.9 万亿条路径），价值函数把无数未来压成「每个状态一个数」。
- 数学边界（grill 定案）：**完整推导 V^π 的 Bellman 方程**（从回报定义拆到 V^π(S_{t+1}) 折叠一步，再摊开成 π/P/r 的求和形式）；**Q^π 方程只定义挂招牌不展开**；**Bellman 最优方程 max 只露脸不推导**。
- 符号先教（作者明确要求）：动机讲完、首个公式之前放符号卡，最多 8 个符号，每个符号一句话人话，全部挂在修 bug 例子上；随机变量（大写）与取值（小写）严格分流。
- 数字例子（grill 定案）：确定性三状态 A(刚读完代码)→B(改到一半)→C(测试即将全绿)，在 C 执行最后一步得 +1 并结束，γ=0.9。笨办法 G_A = 0 + 0.9×0 + 0.9²×1 = 0.81；Bellman 倒推 V(C)=1、V(B)=0.9、V(A)=0.81。与第一篇 0.81 呼应。**刻意不沿用第一篇那组有出入的转移矩阵数字。**
- 推导路数：沿用 Sutton & Barto 路数（Chapter 3），正文说明来源，文末给引用链接（书名 + 官方免费版 incompleteideas.net/book/RLbook2020.pdf）。
- 结尾公开修正（作者定案：诚实优先）：第一篇结尾「Q-learning、PPO、GRPO 本质都在解同一个方程」严格来说不成立。准确说法：**Q-learning 直接解 Bellman 最优方程；PPO 只用价值函数解评估那一半（策略改进走策略梯度）；GRPO 连价值函数都省了、用组内平均做基线，是绕开方程。**修正本身作为作者人设时刻，并把「绕开账本的代价」挂到篇 8 GRPO 数学。
- 反常识点：Bellman 方程右边又出现 V——用未知数定义未知数，看起来循环论证，实际是「账做平了」的不动点/自洽条件；这也是「只看下一步就够了」的全局性来源。
- 下一篇预告：篇 3 **TD / Q-learning**。方程右边有转移表，修 bug 没有这张表；下一篇用「实际奖励 + 下一步估值」当老师，从样本逼近方程。高斯已挪到 TRPO 前。

## 核心结论

1. **为什么非做不可**：回报 G_t 全是未来，决策必须现在做；价值函数 V^π(s) 把按策略 π 走下去的所有可能未来，按概率平均成一个数。
2. **为什么不能暴力算**：把未来路径全展开再平均是 3^30 ≈ 205.9 万亿条；价值函数每个状态只存一个数。
3. **符号铁律**：大写 S_t/A_t/R_t/G_t 是还没落定的随机变量；小写 s/a/r 是已经落定的具体取值。
4. **V 的 Bellman 方程**：V^π(s) = Σ_a π(a|s) Σ_s' P(s'|s,a)[r(s,a,s') + γ V^π(s')]；无限项从 t+2 起整体折叠成 V^π(S_{t+1})。
5. **三态算账**：G_A = 0.81 与倒推 V(C)=1→V(B)=0.9→V(A)=0.81 完全一致；Bellman 不是新目标，是同一笔账的复式记账。
6. **最优方程只露脸**：V*(s) = max_a Σ_s' P(...)[r + γ V*(s')]，贪婪对象是「一步奖励 + 折现未来」，不是眼前奖励；证明留给后续篇目。
7. **修正**：Q-learning 解它，PPO 用一半，GRPO 绕开它。

## 结构（7 节 + 结尾，正文 ~3200 字）

- 开头（~250 字）：回到第一篇停在原地的 coding agent；先提上篇结论「不能只看眼前」，再抛出本篇问题「那看什么？」——看一个数（价值函数），Bellman 方程把无限长的账改成只看下一步的记法。
- 一、为什么必须把未来压成一个数（~450 字）：G_t 定义回顾；决策时刻未来未发生，必须有一个只看当前状态就能算的数；暴力展开所有路径 = 3^30 ≈ 205.9 万亿条，堵住「算平均不就行了」。
- 二、先把符号说清楚（符号卡，~350 字）：大小写铁律（骰子未掷/已落定）；8 个符号表格，全部挂修 bug 例子；Q 不入卡；E 是「按概率加权平均」。
- 三、V：给未来开个一口价（~400 字）：V^π(s)=E[G_t|S_t=s]；一口价比喻；作者卡点——G_t 已是数为什么还要平均（随机变量 vs 取值）。
- 四、Bellman 方程：把无限求和改成一步加未来（~700 字，核心推导）：四步硬推导；R_{t+1} 单拎、提 γ、全期望折叠、摊开成 π/P/r 求和；报销记账比喻；Q 方程挂招牌。
- 五、拿三态例子算一遍（~500 字）：A→B→C 确定性转移、终局 +1、γ=0.9；笨办法 0.81 vs Bellman 倒推 0.81；点题「未来的长度被 C 的值吞掉了」。
- 六、为什么「只看下一步」反而是全局视角（~400 字）：循环论证疑问 → 不动点/账做平了；最优方程 max 露脸。
- 七、修正上一篇结尾的一句话（~450 字）：引用旧预告原文；公开修正；三条去向（Q-learning 解 / PPO 用一半 / GRPO 绕开）；挂篇 8 预告。
