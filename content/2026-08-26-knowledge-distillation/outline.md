# 蒸馏是抄袭？为什么越抄越学不会？

## 文章定位

- 恢复期数学番外（规划里的番外 A）。不占「强化学习原理」主线篇位。PPO / GAE 连发之后插一篇数学，配比回到 RL : 数学 ≈ 1 : 1。
- 一句话承诺（grill 定案）：**真蒸馏要传的是决策背后的概率分布，不是标准解法。** 大众以为蒸馏 = 抄大模型；只抄标准解法，才会越抄越学不会。
- 认知交付三件套：① 抄袭误会主钩（抄走的是最终解法，不是每个选项的把握）② 温度把尖峰摊开（T=1 几乎只剩一个选项；T=3 才露出 0.70 / 0.15 / 0.15）③ 软 CE 梯度 $p_{\text{学生}}-p_{\text{老师}}$（学生若已 0.99 死磕标准解法，软标签会把标准解法往下推 0.29、两个备选往上推 0.145）。
- 数学边界：温度 $\mathrm{softmax}(z/T)$ + 软标签交叉熵梯度。KL 只挂一句（这张软表之间的差距，就是那把尺子在量）。$T\to\infty$ 退成 logits MSE 只留一句。不写 KL 正反方向。
- 用词：开头「把握」；公式段点名「概率分布」。禁用「犹豫」「概率分布模型」「说人话就是」。老师 / 学生只在公式段出场。
- 数字例子：三分类玩具 logits，映射补丁场景（改实现 / 改断言 / 改配置）。不拿 671B → 7B / 90% 当标题或主数字。

## 核心结论

1. **抄袭误会**：蒸馏看起来像小模型抄大模型。若抄的是标准解法（hard label），小模型只会复述最终那一锤子，训练时的把握全丢。
2. **标准解法不够用**：测试可以靠「标准修法」变绿；下一个边界条件一来，没被传过来的那个选项才会爆。回扣不落在「别改断言骗绿」。
3. **R1-Distill 不是这篇的数学**：公开的 DeepSeek-R1 蒸馏是用老师写下的解题过程做 SFT，不是对 logits 做软标签。R1 总参 671B、激活 37B。只当对照，不当主证据。
4. **温度摊平**：同一组 logits，T=1 时 [0.981, 0.010, 0.010]，T=3 时 [0.70, 0.15, 0.15]。T=1 看起来像标准答案；T=3 才看得到另外两个选项各有多少把握。
5. **软标签**：老师那张表 $p_T=\mathrm{softmax}(z/T)$ 就是决策背后的概率分布。学生要学的是整张表，不是 $\arg\max$。
6. **梯度**：$\partial L/\partial z_S = p_S - p_T$。学生已经 0.99 抄死标准解法时，硬标签梯度几乎停（−0.010 / +0.005 / +0.005）；软标签仍在推（+0.290 / −0.145 / −0.145）——标准解法被往下拉，另外两个选项被往上抬。
7. **结论**：越抄越学不会，是因为抄走的是 $\arg\max$，不是分布。KL 挂钩一句收束。

- **五、回扣：抄走的到底是什么（~550 字）**：回到开头 agent。它越抄越学不会，不是蒸馏这个词骗人，是蒸馏时只抄了 $\arg\max$。此处**稍微**拆两对名字，不新开专题：① 硬蒸馏 / 软蒸馏——硬的只传 $\arg\max$（标准解法），软的传整张 $p_T$（第三节那张表）；② 黑盒 / 白盒——黑盒只能看见老师吐出来的词（第二节 R1-Distill 那种解题过程），白盒拿得到 logits，才能做软蒸馏。两对名字对上同一根刺：抄标准解法 = 硬的、往往是黑盒；传分布 = 软的、需要白盒。把分布传过去，agent 下次会对三个补丁都留把握。一句话总结卡（分享借口）。
