预训练：猜下个 token，为什么会写文章？

2019 年，OpenAI 发布 GPT-2 时采取了分阶段公开的方式，理由是担心模型被滥用。那时它有 15 亿参数；今天，能续写、能解释、能写代码的模型早已寻常。

最让人困惑的仍是同一个问题：**一个只被要求“猜下一个 token”的系统，为什么会写出像文章的东西？**

先给结论：它不必先被显式教会语法、故事或问答格式。为了把下一个 token 猜得更准，它会不断压缩训练文本里可预测的规律。这个过程能带来可迁移的能力表现；但“表现得像理解”，和“真的理解”，更和“拥有意识”，是三件不同的事。

## 一、它猜的不是一个词，而是一个概率分布

在 [损失函数那篇](https://mp.weixin.qq.com/s/zIWqYqYVzEaF1e8P6fcTfw) 我们讲过：MSE 常用于回归，交叉熵常用于分类。语言模型的每一步也是分类：给定前文 **c**，它要给词表里的每个候选 token 一个概率 **q(x|c)**。

拿到一条训练样本时，数据只告诉它一个实际出现的下一个 token。把这个标签写成 one-hot 分布 **p**：正确 token 为 1，其余为 0。交叉熵就变成：

> **H(p,q) = −Σ p(x) · log q(x) = −log q(正确 token)**

模型若把正确答案的概率从 1% 提到 10%，损失会明显下降；把不相干 token 的概率挪走，也会得到奖励。一次次这样的更新，把参数推向“在这个上下文后，哪些续写更常出现”的方向。

### 一个容易被说错的等式

在讨论整个数据分布、而不是某一条 one-hot 样本时，交叉熵可以拆成：

> **H(p,q) = H(p) + Dₖₗ(p‖q)**

其中 **H(p)** 是数据分布本身的不可预测性，**Dₖₗ(p‖q)** 是模型分布与数据分布的差异。对固定的数据分布，最小化交叉熵等价于最小化这项差异。

但要把两个层次分开：**单条 one-hot 标签的熵是 0；语言的多种合理续写，是从许多相似上下文的总体分布里显出来的。** 训练时我们只有样本，不会直接拿到“互联网的真实分布”本身。

所以，更低的交叉熵严格说明的是：模型在这类数据上预测得更准。它可能压缩出字词搭配、句法、人物关系、常见故事结构，甚至某些可复用的解题模式；但它并不自动保证事实为真、因果关系正确，或模型“知道自己在说什么”。

![交叉熵：区分单条独热标签与总体数据分布；更低交叉熵不等于理解或意识](02-cross-entropy-context-v3.png)

### PPL：看趋势的尺子，不是智力分数

常见的困惑度写作：

> **PPL = exp(NLL)**

PPL 越低，表示模型平均分给真实下一个 token 的概率越高。它适合观察**同一任务、同一分词器、同一验证集**上的训练趋势；换了语料、语言或词表，PPL 不能直接比高低。它更不是“模型有多聪明”的统一分数，更不可能是意识量表。

真实工程中的预测空间确实很大。以 2026 年公开的 [DeepSeek-V4-Pro 固定版本 `config.json`](https://huggingface.co/deepseek-ai/DeepSeek-V4-Pro/raw/b5968e9190ef611bbf34a7229255be88a0e937c1/config.json) 为例，词表大小是 129,280，隐藏维度是 7,168，层数是 61。这些配置能告诉我们每一步要在多大的候选空间里建模、表示有多宽；**它们不能单凭自己证明模型具有什么能力或体验。**

### 谁让这个概率真的变了？

交叉熵负责打分；让参数改变的是 [反向传播](https://mp.weixin.qq.com/s/oYj_qpwF4tZG84ImOn977g) 和 [梯度下降](https://mp.weixin.qq.com/s/V6mGvCVFpTvmC51pNtxiTw)。前向传播中，模型先把 token 变成向量；[词嵌入](https://mp.weixin.qq.com/s/rDryn1z_hLt7mwi3X8fsxQ)、注意力和前馈网络共同利用前文，给出下一个 token 的概率。反向传播再把“这次猜错了多少”的信号传回每个参数。

更新一次，什么也不会突然“懂”。更新很多次，统计上更有用的结构会被反复强化。问题是：这种统计改善在输出里究竟长什么样？

## 二、把 4090 上的 90 分钟如实摊开

我没有再用一小段文学文本反复训练。那种设置很容易把背诵误写成学习。

这次用公开中文短故事数据集 `adam89/TinyStoriesChinese` 的 50 万篇故事，按“整篇故事”确定性切分：490,011 篇训练、9,989 篇固定验证。也就是说，验证故事没有出现在训练集中。它仍然只是面向儿童故事的单一分布，不是互联网的缩影。

| 项目 | 设置 |
|---|---|
| 模型 | 8 层 Transformer，512 hidden，8 头注意力 |
| 词表与上下文 | 8,192 BPE token，256 token 上下文 |
| 参数量 | 33,739,776 |
| 硬件 | NVIDIA GeForce RTX 4090 D，24 GB 显存 |
| 训练 | 先训练 60 分钟，再从权重继续 30 分钟；共 24,112 个优化步 |
| 有效训练量 | 约 790,102,016 token |
| 最佳固定验证 PPL | 50.7278，发生在 step 24,100 |

为了不把续训计时重置当成“更快训练”，下表只按纯训练时间合并计时：

| 合并训练时间 | 全局 step | 固定验证 PPL |
|---:|---:|---:|
| 18.6 分钟 | 5,000 | 103.90 |
| 60.0 分钟 | 16,100 | 60.54 |
| 74.5 分钟 | 20,000 | 54.82 |
| 90.0 分钟 | 24,100 | 50.73 |

![固定验证困惑度：90 分钟内从 103.90 降至 50.73；仅表示同分布预测更准](04-validation-perplexity-v3.png)

验证 PPL 在继续下降：在这个数据分布上，模型确实比 18 分钟时更能预测没见过的故事。这比“训练集 loss 降了”强得多，因为它至少排除了直接记住训练篇目的解释。

但也别把这句话读得太大。它只支持**对同分布留出故事的预测泛化**。它不测世界知识、复杂推理、跨领域迁移，更不测理解或意识。

### 同一个验证前缀，输出到底变了什么？

下面均为固定验证故事前缀上的贪心生成，文本为便于阅读的截断。没有挑一条最顺眼的样例：这里保留了它不连贯的一面。

```text
前缀：从前，有一个小女孩叫 Lily……Lily 坐在她的舒适车座上

step 0：探索周围的世界摇试试看广不敢相信自己的志的东西同意了……

step 5,000：车。他们仍然是朋友。他们仍然是朋友。他们仍然是朋友……

step 24,000：都很高兴。这个故事的寓意是：朋友。结束。结束。
          她学会了分享……她学会了要有爱心和分享……
```

![固定验证前缀生成：从词片段到故事模板与复读；局部叙事统计改善，但未观察到稳定故事世界](05-generation-evidence-v3.png)

开头是词片段的碰撞；后来出现了儿童故事常见的角色、结尾和“学会了分享”一类模板。这是局部结构被学到的迹象。可同一段末尾也暴露了反面：人物和事件没有被持续维护，“结束”“朋友”“分享”会复读，语法也会断裂。

更重要的是，生成质量并不沿着每个 checkpoint 单调变好。单一解码样例受概率、解码策略和提示词影响很大；PPL 的平滑下降也不等于每一次续写都更好看。把曲线、固定样例和失败样例放在一起，才是这次实验真正给出的图景：**模型逐步学会了这个语料的局部叙事统计，却没有写出稳定、持续的故事世界。**

还有一项该公开的技术细节：60 分钟后的 checkpoint 保存了权重，却没有保存 AdamW 的动量状态；后 30 分钟复用了权重、随机种子和全局学习率日程，但优化器动量重新开始。因此，这是一条透明的单次训练记录，不是多随机种子的统计结论，也不该被包装成严格的“90 分钟对照实验”。

## 三、更会预测，究竟说明了什么？

可以把证据强度排成三层：

1. **训练 loss 下降**：模型更会拟合它见过的 token 序列。
2. **独立验证 PPL 下降，加上固定前缀能续写出局部模式**：模型对同分布的未见故事形成了某些可迁移的预测结构。
3. **理解、因果把握、主观体验**：需要额外定义和额外证据，不能从前两层直接推出。

前两层已经很有价值。若模型只存了原文，换一篇故事后预测应该立刻失灵；现在验证 PPL 下降，说明它至少抽取了在新故事中仍有用的规律。可“抽取规律”不等于拥有一幅可靠的世界模型。这个小模型会把“朋友”“结束”“学会了分享”放在高概率位置，却并没有稳定地守住“谁做了什么、为什么发生、接下来应如何收束”。

这也是为什么“模型把知识压缩在参数里”只能算一个有用的工程比喻，不能当作哲学结论。参数里可能有可复用的表征；但表征能否支撑反事实推断、长期规划、自我校验，仍要用相应的任务来测。更不用说，**语言行为像人，并不直接让我们看见一个第一人称视角。**

### “涌现”应该说得更窄

研究中有时把某项测评在尺度变化后出现的非线性提升称为“涌现”。这可能是模型、数据、提示方式和计分尺度共同作用的结果；换一个任务或指标，阈值形状也可能改变。

在这次实验里，我没有看到神秘的跃迁：验证 PPL 是逐步下降的，生成也只是从词片段逐渐显出故事模板，且仍反复失稳。最准确的说法是：**出现了局部、渐进的能力表现变化；没有观察到可宣称为相变的证据。**

Scaling law 同样要这样读。它是特定模型族、数据和算力范围内观察到的经验关系，提醒我们规模、数据质量和训练配比都会影响损失；它不是“只要加大就必然更聪明”的保证，更不是“损失每降一档就会解锁某项能力”的刻度尺。

## 四、像，算理解吗？

《西部世界》第二季里，Forge 把访客多年的选择压进图书馆般的“书”；Dolores 面对的是可被调用的行为档案。James Delos 的复制实验却不断失稳：它抓到了语气、习惯与某些选择，却没有得到一个能持续存在的“他”。这不是“翻一本记忆书，就完美复刻人格”的剧情，也不是现实技术预言。

它把问题推到一个尖锐的边界：若一本行为之书能预测你会说什么、爱谁、害怕什么；若一个系统能据此与你对话、在陌生处境里给出很像你的反应——它是否因此拥有你的感受？当它说“我疼”“我记得”，那里是否有第一人称的“我”？

预训练模型面对的是更宽、更嘈杂的档案：海量文本中的“上下文 → 下一个 token”。它学得越好，越可能复现语言里的解释、情绪、角色与论证；但预测得更准仍只是一项可观测的行为事实。**涌现是能力表现的变化，不是意识出现的证据。**

这不是断言模型必然没有理解或体验；而是说，PPL、续写和一次漂亮的对话都没有回答这个问题。

## 五、预训练之后：让续写器成为助手

预训练得到的首先是一个条件概率模型：它擅长在给定上下文后继续文本，却不会天然以“帮助用户、遵守边界、说明不确定性”为目标。

后训练、指令微调和人类偏好优化，解决的是另一件事：让这种预测能力更可靠地进入对话、工具调用和安全约束。它们能显著改变模型的可用性，却不是“补上意识”的步骤。

![从预训练到可用助手：预训练、后训练与部署提升可用性，但不构成意识证据](07-posttraining-boundary-v3.png)

所以，“猜下一个 token”并不笨。它是一种极强的压缩压力：凡是有助于预测文本的结构，都值得被模型编码进去。但它也有边界：**会预测，不等于会解释；会模仿，不等于有体验。**

> 如果一个模型能长期、稳定地解释自己的理由、修正错误、在新情境中维护同一套因果关系——你会把这当成“理解”的证据吗？还是你认为还缺少某种根本不同的东西？
