| S2 | 猜的不是词，是概率分布（交叉熵） | 前文 c → 词表 5 万个候选，每个一个概率条；one-hot 标签（正确 token=1 其余 0）；公式 H(p,q)=−log q(正确token)；1% → 10% 概率条涨起来；「压规律但不等于懂」标签 | 先看清楚"猜"是什么。它不是猜一个词，是给词表里每个候选，一个概率。前文是 c，模型输出 q(x|c)。训练时，数据只告诉它一个真正出现的词，剩下全是 0。这就是 one-hot。交叉熵算下来，等于负的 log——正确那个词的概率。概率从 1% 提到 10%，损失立刻下降。一次次更新，把参数推向"这种上下文后面，更常出现什么"的方向。但注意。预测得更准，不等于事实为真，不等于因果正确，更不等于它知道自己在说什么。 | 转折爆点（但注意。）+ 数字对比（1%→10%） |

| S5 | 四个 checkpoint 四次续写 | 同一前缀 Lily 卡片；step0 乱码 / step5000 复读 / step24000 开头出现「故事的寓意」条；「局部变好 vs 没守住故事世界」对比 | 再看续写。同一个前缀：从前有个叫 Lily 的小女孩。第 0 步，一堆乱码。5000 步，复读机：他们仍然是朋友，朋友，朋友。24000 步，冒出「这个故事的寓意是：朋友」。局部结构在变好，语法有一搭没一搭。可直到训练结束，它也没写出一个人物前后一致、事件有因果的故事。「结束」「朋友」「分享」反复出现。看曲线，90 分钟从 104 降到 50，很容易以为"稳步变好"。把输出摊开，就发现：预测更准，不等于输出更好。 | 转折爆点（可直到训练结束）+ 对比（曲线 vs 输出）|
| S6 | 三层证据 + 随机鹦鹉 | 三层金字塔（fit→泛化→理解）；前两层亮绿、第三层灰「要额外证据」；鹦鹉图案 + 「语言像人不等于有体验」标签 | 把结果放回证据框架，三层。一：训练 loss 下降——它更会拟合它见过的序列。二：没见过的验证集 PPL 也降，还能续出局部模式——它对同分布故事有了可迁移的结构。三：理解、因果、主观体验——这层要额外定义和证据，不能从前两层推出来。前两层已经很有价值。可"抽取规律"不等于拥有世界模型。语言行为像人，并不直接让我们看见一个第一人称的视角。这正是"随机鹦鹉"提醒我们的：复现语言模式，不等于理解自己在说什么。 | 数字分层 + 转折爆点（不等于拥有世界模型）|

## 关键数字核查（与 weixin.md 完全一致）

- 2019 GPT-2 15 亿参数，分阶段公开；今天能续写/解释/写代码
- 猜的不是词是概率分布：前文 c → q(x|c)；one-hot；H(p,q)=−log q(正确token)；概率 1%→10%
- PPL = exp(NLL)；负对数似然=意外程度；换语料/语言/词表不可比
- DeepSeek-V4-Pro（2026 config.json）：词表 129,280、隐藏 7,168、61 层
- 实验：RTX 4090、8 层 Transformer、33,739,776 参数、512 hidden、8 头、词表 8,192、上下文 256
- 数据集 adam89/TinyStoriesChinese 50 万篇中文短故事；验证集 9,989 篇训练中没见过；按整篇切分
- 24,112 步；训练量 ~790M token；PPL 103.90(18.6min) → 60.54(60min) → 54.82(74.5min) → 50.73(90min)
- 四个 checkpoint 续写：step0 乱码 / step5000 复读「他们仍然是朋友」/ step24000 「这个故事的寓意是：朋友」+「学会了分享」
- 三层证据：训练 loss 降 / 验证 PPL 降+局部模式 / 理解因果体验需额外证据
- 涌现=尺度变化后非线性提升；本实验无相变证据，只有局部渐进能力
- 预训练=条件概率模型；后训练/指令/RLHF 改善可用性，非「补上意识」

## 制作流程

1. 配音：`scripts/minimax_tts.py` 整段生成（full.txt）+ `--subtitle` 句子级时间戳 → `scripts/tts_split.py` 按时间戳切分 8 段（克隆音色 `branding/my-voice-denoised.wav`，speed 1.15 pitch +2，speech-2.8-turbo）；生成后 `silencedetect=d=-1.5dB:d=1.5` 扫段内长静音
2. 动画：每段一个 Manim Scene（S1..S8），`construct` 末尾 `pad_to_voice()`；动画节点按台词时间轴铺满（≥80% 配音时长）；工具函数复用 attention/transformer scenes.py 模板（boxed/fit/sqrt_group/play_red_cross）
3. 构建：`scripts/manim_video_build.py` mux 配音 + 无缝拼接 + 黄色字幕烧录（MarginV=210, 75 号，整行 + 150ms 淡入）+ 品牌尾卡
4. 封面：Cover 场景单帧渲染（复用「概率分布条 + 4090 实验」最有记忆点视觉）→ `<标题>-封面.png`（1080×1920，关键内容在中间 3:4 安全区 y∈[240,1680]）
5. 归档：`content/2026-07-27-预训练/shipinhao/`
