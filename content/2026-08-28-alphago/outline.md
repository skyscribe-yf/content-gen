# AlphaGo 十年：那只狗到底是靠什么赢的？

## 文章定位

- 8-30 档（8-28 信息熵文末预告兑现：「不讲数学，讲一个把『猜』玩到极致的案例——AlphaGo 当年到底靠什么赢的」）。番外归「强化学习原理」系列，不占主线篇位；与 8-26 蒸馏、8-28 信息熵、9-01 GRPO 数学形成「RL 主线 + 案例穿插」链条。
- 一句话承诺（grill 定案）：**AlphaGo 每步只随机模拟几千手，却赢过「穷举不了」的围棋——神不在算力，在两个函数：把棋感压成「直觉候选」的策略网络 + 把胜负压成「评分」的价值网络，搜索只是把两个函数组装起来的实习生。**
- 认知交付三件套（grill 定案）：① 反直觉「算得少反而赢」——每步几千手模拟 vs 围棋 10^170 穷举 ② 两个函数组装（策略网络 = 老棋手报候选、价值网络 = 形势判断师报胜率、MCTS = 实习生随机试下）③ R1 变奏——同一个 RL 思想换了不可验证的环境，DeepSeek-R1 用 GRPO 让模型在 token 空间自己长思维链（DeepSeek 试过 AlphaGo 式 MCTS 没落地）。

- 比例（grill 定案）：AlphaGo 80%（第一节～第五节）+ R1 20%（第六节 500-600 字）。

## 核心结论

1. **人类为什么觉得神**：2016-03-09 首局，围棋 10^170 局面、传统 AI（alpha-beta/穷举）碰不了——李世石赛前被认为是必胜（李开复曾预测李世石胜率 89%）。
2. **两个函数**（Nature 摘要核验）：策略网络 $p(a|s)$ = 「看到棋型，报几个候选」的价值网络 $V(s)$ = 「看到局面，估一个胜率」——两个网络各管一件事，把「棋感」压成函数。
3. **组装 = 每步只几千手**（Nature 摘要核验）：MCTS 把策略网络（哪些手值得试）+ 价值网络（试完判断）+ 随机模拟（真正下几盘）组装起来——每步只随机模拟几千手，没穷举。
4. **算得少为什么反而赢**：① 棋感裁剪搜索树（策略网络先把 200+ 候选砍到几个，价值网络再评分）② 随机模拟纠正单点误判（多试几盘，运气平均掉）③ 两个网络的误差互相纠偏——**它不是算得多，是「知道哪几条路值得试」**。
5. **R1 变奏**（DeepSeek-R1 论文核验）：AlphaGo 的爽点是「两个网络 + 每步可验证」（终局有明确输赢）；LLM 没有「每步评分」——DeepSeek 试过 AlphaGo 式 MCTS 未落地（三个挑战），最后 GRPO 让模型在 token 空间自己长思维链（多想几步再开口）——**同一个 RL 思想，换了不可验证的环境就换了形态**。
6. **回扣**：AlphaGo 不是「算穿了棋盘」，是「两个函数把棋感压成能组装的东西」——真正让 AI 赢的从来不是算力，是「知道该算什么」。

## 结构（6 节 + 结尾，正文 ~4000 字）

- **开头（~280 字，2016 场景）**：2016-03-09，首尔，李世石 vs AlphaGo 第一局。全球直播，人类「最后的堡垒」（围棋 10^170，传统 AI 碰不了）。赛前几乎所有人都赌李世石赢——李开复都预测李世石胜率 89%。结果 AlphaGo 白中盘胜，186 手。**第二段反转**：后来大家才知道，它每步平均只「模拟」几千手——比职业棋手长考时脑里推演的还少。那人类到底输给了什么？零导航。
- **一、人类为什么觉得神？因为围棋大到「算不完」（~450 字 + 穷举对比图）**：围棋局面数约 10^170（比宇宙原子数还多）。传统 AI（深蓝那种）靠「算几手 + 估个分」——围棋评估函数难写（没有简单「兵/马」价值），分支因子巨大，alpha-beta 剪枝碰不了。所以 2016 年前围棋是 AI 禁区——「人类智慧最后堡垒」。李世石赢面被普遍看好（李开复 89% 预测）。
- **二、第一个函数：策略网络——老棋手报候选（~600 字 + 策略网络示意图）**：策略网络 $p(a|s)$ 一句：**看到当前棋型，它给每个可下点一个概率**（哪个更像人下的）。老棋手比喻：扫一眼棋形，报 3 个候选——不是全盘 200+ 都算。AlphaGo 策略网络不穷举，它把「哪些手值得试」先筛一遍。第 37 手（第二局，AlphaGo 执黑第 19 子）作为案例：9 段 Michael Redmond 评它有「创造性」「独特」——「大多数职业棋手不会考虑」；李世石长考。策略网络选择了人类千年棋谱没有的路，但搜索验证这条路战略价值更高。（已核验 Redmond 引语；不写「被批为失误」——那是第 167 手的事。）
- **三、第二个函数：价值网络——形势判断师报胜率（~550 字 + 价值网络示意图）**：价值网络 $V(s)$ 一句：**看到当前局面，它估一个「这一方赢面多大」的数字**（0 到 1）。形势判断师比喻：不用真下完，扫一眼局面报个胜率。人类棋手也有这个能力（「这棋我八分胜」），但人类是经验启发式——价值网络把「胜负感」压成可计算的函数。为什么价值网络重要：搜索树每多一层就要问一次「这个局面值不值得继续」——没有它，树就只长不死。
- **四、组装：每步只几千手，怎么组装（~600 字 + MCTS 组装流程图）**：三个零件 + 组装逻辑：① 策略网络先筛（哪些手可能）② 价值网络评分（这个局面胜率）③ 随机模拟验证（真正下几盘）。实习生比喻：派几千个实习生，每个随机从候选里挑几手下到终局，看胜负——统计哪个候选胜率高。MCTS 树搜索 = 这几千个实习生结果反哺决策（访问量多的分支更值得试）。**每步只几千手模拟**——不到围棋 10^170 的亿亿亿分之一。黑 37 案例收在这里：策略网络报出的第 37 手「大多数职业棋手不会考虑」（Redmond 9p 评），但搜索+模拟验证了它的价值——李世石接到这手棋后长考。（已核验。）
- **五、算得少为什么反而赢？（回扣，~550 字）**：三个原因，一个比一个反直觉：① **棋感裁剪**——策略网络先砍掉 99% 的候选，搜索不用碰全盘 10^170；② **随机模拟纠偏**——单次判断可能错，几百次模拟把误差平均掉（蒙特卡洛的本质就是「多试几次」）；③ **两个网络互相纠偏**——策略网络擅长「哪条路像人下的」，价值网络擅长「哪条路胜率高」，两者不一致时说明「人类棋感在这里不可靠」——AlphaGo 正是靠这种「函数之间的张力」发现人类棋感盲区。收束：**它不是算得多，是「知道哪几条路值得试」——跟人类棋手一样，只是它的「棋感」是训练出来的函数。**
- **六、2026 变奏：DeepSeek-R1 在想什么？（~600 字 + R1 对照图）**：落点转折。AlphaGo 的「两个网络 + 每步可验证」爽点在围棋成立（终局明确输赢）；LLM 环境不同——每一步没有「这个字对不对」的评分，题目大多没有标准答案。DeepSeek 官方论文自述：试过 AlphaGo 式 MCTS 树搜索引导 LLM 推理，未落地（几个不可逾越挑战——核心是 LLM 没「价值网络」可依赖，预测下一步容易、评价「这一步好不好」难）。最后 DeepSeek 用 GRPO：让模型对同一个题生成多份答案，互相比较打分（组内相对优势）——**在 token 空间自己长思维链，多想几步再开口**。回扣：同一个 RL 思想（用试错学「想清楚」），AlphaGo 在棋盘（可验证），R1 在语言（不可验证，只能组内比）——这就是变奏。**为什么你现在读：DeepSeek-R1 的「闭眼想一会儿」，就是 AlphaGo 当年「多想几步」的延伸。**
- **结尾（~300 字）**：回扣开头——2016 年全人类以为 AlphaGo 算穿了棋盘，其实它每步只模拟几千手。它赢的不是算力，是「把棋感压成两个函数 + 知道哪几条路值得试」。AlphaGo 也不是全知（第四局白 78 李世石「神之一手」——黄士杰披露 AlphaGo 计算被误导入，是它 74 场官方对局唯一一败）。文末问题（30 秒可答）：**「你还记得 2016 年那几盘棋吗？当时你站哪边——觉得李世石能赢，还是觉得 AI 必败？那盘里你最难忘的是哪一手？」** + 点赞/关注/收藏 + 下一篇预告（GRPO 数学：一句，不展开）+ 合集 + 近期热门（脚本生成）+ 参考资料 + 话题标签。
