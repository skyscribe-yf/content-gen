# 05-output-projection — 输出：从向量回到下一个字

展示 Transformer 最后的输出投影：取最后一个 token → 映射到词表 → softmax → 选最高概率的词。

中文文字：
- 上方：[7,2048] 矩阵 → 标注"**取最后一行**" → 得到一个 [2048] 向量（用高亮方框表示"全过程"这个 token）
- 中间：[2048] 向量 × **嵌入表转置** [2048, 151936] = [151936] 分数向量
- 下方：151936 个分数 → 标注"**softmax**" → 概率分布 → 标注"**取最大值**" → 输出下一个 token
- 右侧注释框："15 万个候选词，每个都有一个概率"
- 底部小标注："**tie_word_embeddings = true**：输出矩阵 = 输入嵌入表的转置（同一个参数，用两次）"
- 左下角回顾标识：→ 指向输入阶段嵌入表的虚线，标注"**同一张表**"

风格：现代信息图，扁平矢量，白色背景。最后一个 token 用暖色高亮，概率分布用渐变色条（深蓝=高概率→浅灰=低概率）。禁止手写体、人物、品牌 logo。所有文字为中文。
