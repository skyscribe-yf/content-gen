# 封面 prompt：给 Agent 装了记忆，为什么它还是不懂我的项目？

- 比例：**21:9**（apimart `--size 21:9`）
- ⚠️ AI 底图**不画任何文字**（标题由 make_cover.py 脚本叠金字）；画面中不得出现任何可读文字、字母、数字
- 上部大面积留空（给金色标题让位）

## 画面

深蓝黑到近黑的电影宽幅横构图（21:9），冷静克制。画面上半部大面积留空、干净退暗。画面下半部偏中：一块由若干**发光半透明文档平面**整齐叠成的方形「文档方块」（每个平面带清晰的横向线纹/网格，但**没有任何字迹**）悬浮着，边缘透出青色微光；在方块的右侧，大量**零散的碎片/纸屑状光点**被撕开、向暗处飘散、逐渐熄灭——一边是「被整理成册的文档」，一边是「散落失焦的记忆碎片」。冷蓝为主调，少量琥珀金点缀高光。整体简洁、有工程感，不杂乱。

⚠️ **严格排除**：任何文字/字母/数字/符号、文档上的字迹、科幻 HUD 面板、机器人形象、人脸/人物、logo、水印、密集粒子噪声。

## 硬性规格

1. AI 底图**不含任何文字**；金色发光标题由脚本叠加（两行居中，字高约画面高 1/9–1/8，整块 ≤ 画面高 1/4）
2. 主视觉集中在画面中下部，**上部留空退暗**，避免叠字区背景过亮
3. 除主视觉外无其它抢眼元素；缩成信息流卡片大小后，画面仍清晰不糊
4. 重要元素避开画面上下左右边缘，四周留白（防 center-crop 切掉）
