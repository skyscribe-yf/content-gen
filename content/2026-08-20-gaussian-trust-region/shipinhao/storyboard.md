  - Σ = diag(0.01, 100)，Δμ = 0.1：窄方向 **KL = 0.5**，宽方向 **KL = 0.00005**，差 **1 万倍**

## S1 · 开场钩子：同一个 0.1，差一万倍（~38s）

**动画要点**：
- 页1：两团云「长得一样」示意图（脚本画，`_cloud()` 壳状点云，**禁 AI 图**）→ 同一 Δμ = 0.1 → **双条 grow_bar 对比**（窄方向 KL = 0.5 / 宽方向 KL = 0.00005）→ **emphasize 对比条**（强调 1/3）→ 金句卡「窄方向翻天覆地 / 宽方向几乎没动」
- 页2：概念图「云形策略」（`s1-cloud-round.png`）→ 卡「云有形状，直尺就失灵」+ 单卡「μ 中心：管往哪走 / Σ 宽度：管飘不飘」（2026-10-01：原本拆成两张窄卡，`layout_page` 会把窄卡横向压小、文字左对齐显得像被截断，合并为一张全宽卡解决）
- 开场小字（A12）：以 coding agent 改代码为例
- 结尾悬念：**为什么同一个数，效果差一万倍？**

**配音稿**（= `full.txt` 第 1 段，逐字一致）：
> 上一篇留了半句话：拧太猛，昨天会的今天忘。那把尺子，今天拿出来。(gasps) 先看一件怪事。同一个 agent，同一个 0.1。往窄方向挪，KL 跳到 0.5，行为整个掀翻；往宽方向挪，KL 只有 0.00005，几乎没动。同一个 0.1，效果差一万倍。为什么？因为策略不是参数，是一团云。云有形状，尺子就不能是直尺。云有两个东西：中心 mu 管最常做哪个动作，宽度 sigma 管飘不飘。

**爆点类型**：数字对比（0.5 vs 0.00005，差 1 万倍）

## S3 · 揭盖：云与云的距离是 KL（~38s）

**动画要点**：
- 页1：主视觉 **KL 公式组装**（`MathTex` 同 Σ 精确式，公式高亮 `½ΔμᵀΣ⁻¹Δμ`）+ **emphasize 公式**（强调 2/3）→ 卡「注意，这不是近似，是精确等式」→ 小字「Σ 相同，只有中心不同」（MUTED 停 ≥2s）
- 页2：人话卡两行——「用 π 走出来的轨迹，在 π-prime 眼里有多意外」（**π-prime 用文字写，禁 π‖π' 符号进配音**）
- 页3：金句「KL 量的不是坐标差，是形状差」
- 结尾悬念：**那把尺子的刻度，到底是什么？**

**配音稿**（= `full.txt` 第 3 段，逐字一致）：
> 那么，两团云差多远，拿什么量？(breath) 参数空间走一步，概率空间走多远，这是两码事。KL 说白了就一句话：用旧策略走出来的轨迹，在新策略眼里有多意外。新策略觉得这条路稀松平常，两个策略就几乎一样；觉得匪夷所思，那就差得远。两个云宽度相同的时候，KL 有现成公式：二分之一，乘上中心距离的平方，再除以 sigma。注意，这不是近似，是精确等式。KL 量的不是坐标差，是形状差。

**爆点类型**：转折爆点（「不是近似，是精确等式」）

## S4 · 揭盖二：尺子的刻度 F = Σ⁻¹（~42s）

**动画要点**：
- 页1：回放那两个数——窄方向 Σ = 0.01 → F = 100 → **counter_value 0 → 0.5**；宽方向 Σ = 100 → F = 0.01 → **counter_value 0 → 0.00005**（主视觉：数字滚动）
- 页2：**尺子刻度图**（脚本画：Σ 反向刻度尺，窄→敏感、宽→迟钝；禁 AI 图）→ 卡「云越窄，尺子越敏感」
- 页3：反直觉金句两行（`page_auto`）「越确定的策略，越经不起推」+ 追问条「为什么？」
- 结尾悬念：**确定不是好事吗？**

**配音稿**（= `full.txt` 第 4 段，逐字一致）：
> 同一个 0.1，为什么差一万倍？答案就藏在公式里。窄方向 sigma 小，才 0.01，同样的步被放大得狠，零点一的平方除以 0.01，再取一半，KL 是 0.5。宽方向 sigma 大，是一百，同样的步被稀释得干净，KL 只有 0.00005。这把尺子有名字：Fisher 信息矩阵。对高斯策略，它就是 sigma 的倒数。窄方向 sigma 0.01，刻度是一百；宽方向 sigma 一百，刻度只有 0.01。云越窄，尺子越敏感。这句话反直觉，越确定的策略，越经不起推。

**爆点类型**：数字对比（0.5 / 0.00005 复用，配 F = 100 / 0.01）

> 所以，确定不是好事吗？可确定意味着云窄，云窄意味着尺子敏感。参数轻轻一推，分布就面目全非。昨天会的今天忘，不是更新太猛，是云太窄，经不起推。(breath) 那把尺子拿来干嘛？限步。每次更新，不许让新旧策略的 KL 超过一个阈值，这就是信任域。阈值取 0.01 的时候，窄方向只允许挪 0.014，宽方向可以挪 1.41，差一百倍。小步不是保守，是看得懂云的长相。下一个问题变了：不是能不能拧，是一次能拧多大。下一篇 TRPO，拿着这把尺子去限步。(sighs) 给 agent 改策略，你更信参数距离，还是分布距离？评论区聊聊。
