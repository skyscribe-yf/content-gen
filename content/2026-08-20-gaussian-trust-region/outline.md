# 多维高斯：为什么同一步长差1万倍？

## 文章定位

- 「强化学习原理」系列第五篇。兑现篇4 结尾原话：「下一步的问题变了。不是能不能拧。是一次能拧多大。拧太猛，昨天会的今天忘。那把尺子，下一篇再拿出来。」
- 一句话承诺（grill 定案）：**不知道分布形状，就别用欧氏距离当尺子。概率是一团云，云与云的距离用 KL 量；同 Σ 时 KL = ½ΔμᵀΣ⁻¹Δμ 是精确等式，F=Σ⁻¹ 就是这把尺子的刻度。TRPO 的信任域，就是拿着这把尺子限步。**
- 双主菜结构：前半高维直觉（薄壳 / 集中测度 / 协方差椭圆），后半 KL 尺子（高斯 KL 闭式 → F=Σ⁻¹）。直觉先行，数学殿后，中间以「看起来和 RL 无关」的悬念最高点揭盖。2026-08-19 改：薄壳独立节压缩成第一节末尾一句（「维度一高，质量全挤到壳上」），不再单独成节；每节回扣 RL（更新策略、策略脆弱、信任域）。
- 「策略更新」不当主角（grill 定案：篇4 已把更新讲完）。换**距离维度**：策略是一团云，云与云的距离不能拿参数坐标直接量。高斯云 = 策略本身。
- 数字例子（grill 定案 + 事实验证）：**椭圆方向**——策略是二维高斯云 Σ=diag(0.01, 100)：改行数方向窄（确定，几乎总改 3 行），测试时长方向宽（没底，1 分钟到 20 分钟都干过）。同一 Δμ=0.1 的均值平移：
  - **窄方向**：KL = ½·0.1²/0.01 = **0.5**（翻天覆地，行为模式变了）
  - **宽方向**：KL = ½·0.1²/100 = **0.00005**（几乎无感，本来就在飘）
  - 同一 0.1，差 **10000 倍**。欧氏尺子一视同仁，KL 说方向不同天差地别。
  - **收尾（TRPO 允许步长）**：KL 上限 δ=0.01 时，窄方向最多挪 √(2·0.01·0.01)=**0.014**，宽方向最多挪 √(2·0.01·100)=**1.41**，允许步长差 **100 倍**——直接兑现篇4 预告「一次能拧多大」。
  - **事实验证记录**：高斯 KL 闭式（一维/二维对角/非对角）与蒙特卡洛按定义采样对照，差 ~1e-4（采样噪声）；同 Σ 时 KL = ½ΔμᵀΣ⁻¹Δμ 对 Δμ=0.1~2.0 全部精确相等（非近似）。旧候选「0.90 vs 0.99 确定性相近」数字虽对但静态、无方向性，已弃。
- 数学边界（grill 定案）：**含高斯 KL 闭式**——写高斯 KL 闭式（含 Σ 行列式项），同 Σ 时退化为 ½ΔμᵀΣ⁻¹Δμ（精确等式，不是小步近似），由此得 F=Σ⁻¹。不写 TRPO surrogate 目标、不写 conjugate gradient、不写信赖域算法完整推导。
- 高维直觉部分：**两维起步，高维一句**——第 1、2 维用双旋钮具体讲（椭圆长轴/短轴怎么来的），「维度一高，体积全挤到壳上」一句带过，不引入 d 维公式。
- 符号三拨（grill 定案）：① Σ、μ（高斯参数）② KL（分布距离）③ F（Fisher，曲率尺子）。每张 ≤3 个新符号，与前篇不重叠，不设附录。已教过的 θ/π 各回呼一句。
- 揭盖（TRPO）：**预告级**——只给「TRPO 信任域 = 用这把尺子限步」一句定性 + 允许步长数字（0.014 vs 1.41）+ 系列路标（高斯 → TRPO → PPO 数学 → GAE → GRPO 数学）。不写约束式、不写 conjugate gradient、不写 surrogate。
- 硬引用：**轻引用**——只在揭盖后回链 TRPO/PPO 一篇：「TRPO 的信任域几何直觉从这里来」（链接 + 括号一句）；高斯材料一句（来自高维概率书）。不另起「大模型为什么用」段落，GRPO/RLVR 不展开。
- 结尾预告钩子：**云的距离**——「分布是云，云与云的距离」意象收束全文（薄壳的壳 / KL 的尺子 / 高斯云都指向同一件事：概率是形状，不是点），勾下篇 TRPO。
- 反常识点：概率不是球——高维云的质量全在壳上；同一 0.1 的步，方向不同效果差 10000 倍；越确定的策略越经不起推。

## 核心结论

1. **策略是一团云**：篇4 的策略是一个数（σ(θ) 单旋钮）。现在把它看成云：中心 μ = 最可能的行为，宽度 Σ = 行为有多飘。两个旋钮 → 二维云 → 椭圆。
2. **概率不是球**：维度一高，体积全挤到壳上——球心几乎是空的，概率都集中在球壳。高斯云不是实心球，是壳。
3. **欧氏距离在概率空间失灵**：同一 Δμ=0.1，窄方向（Σ=0.01）KL=0.5 翻天覆地，宽方向（Σ=100）KL=0.00005 几乎无感，差 10000 倍。欧氏尺子一视同仁，但概率空间有形状。
4. **KL 是云与云的距离**：同 Σ 时 KL(N(μ₁,Σ)‖N(μ₂,Σ)) = ½ΔμᵀΣ⁻¹Δμ，精确等式。参数空间走一步 ≠ 概率空间走一步。
5. **高斯策略的尺子是 Σ⁻¹**：F=Σ⁻¹。云越窄，尺子越敏感——越确定的策略越经不起推。
6. **信任域 = 拿着尺子限步**：KL 上限 δ=0.01 时，窄方向最多挪 0.014，宽方向最多挪 1.41，允许步长差 100 倍。TRPO 每次更新不许让新旧策略的 KL 超过一个阈值。PPO 把这件事工程化了（clip）。高斯 → TRPO → PPO 数学 → GAE → GRPO 数学。

## 结构（6 节 + 结尾，正文 ~3600 字）

- 开头（~280 字）：回引篇4 结尾预告「那把尺子，下一篇再拿出来」（链接 + 括号一句）。直接抛 RL 问题：更新策略时，一步能走多大？挂锅盖：参数看着只差 0.1，行为可能天差地别——策略是一团云，云有形状。点题：步长不能拿参数坐标量。
- 一、策略是一团云（符号卡 1，~450 字）：篇4 的策略是一个数。现在把它看成云：中心 μ = 最可能的行为，宽度 Σ = 行为有多飘。两个旋钮 → 二维云 → 椭圆（长轴/短轴怎么来的：改行数方向窄、测试时长方向宽）。薄壳压缩成一句（维度一高，质量全挤到壳上）。V/Q/δ 不请回来。
- 二、同一 0.1，两种命运（数字例子，~550 字）：Σ=diag(0.01, 100) 的椭圆云。往窄方向挪 0.1：KL=0.5，翻天覆地；往宽方向挪 0.1：KL=0.00005，几乎无感。同一 0.1，差 10000 倍。回扣 RL：更新策略时你以为走了一小步，窄方向把策略整个掀翻，宽方向等于没走。欧氏尺子失灵。
- 三、揭盖：云与云的距离是 KL（符号卡 2，~600 字）：悬念最高点：概率是形状，形状之间的距离不能拿坐标差量。KL 散度 = 云与云的距离。直觉：用 π 走路，走出来的轨迹在 π' 下有多「意外」。高斯 KL 闭式（含行列式项），同 Σ 时退化为 ½ΔμᵀΣ⁻¹Δμ——精确等式，不是近似。回扣 RL：量「策略差多远」不能拿参数坐标。
- 四、高斯策略的尺子：F=Σ⁻¹（符号卡 3，~700 字）：F=Σ⁻¹。回看第二节：窄方向 Σ=0.01 → F=100，0.1 的步被放大成 KL=0.5；宽方向 Σ=100 → F=0.01，0.1 的步缩成 KL=0.00005。云越窄，尺子越敏感——越确定的策略越经不起推。回扣 RL：这叫策略脆弱，越接近收敛越经不起大步更新。回链 TRPO：「TRPO 的信任域几何直觉从这里来」（链接 + 括号一句）。
- 五、这把尺子拿去干嘛（~300 字）：TRPO = 拿着 KL 尺子限步：每次更新不许让新旧策略的 KL 超过一个阈值 δ。数字：δ=0.01 时，窄方向最多挪 0.014，宽方向最多挪 1.41，允许步长差 100 倍——这就是「一次能拧多大」的答案。PPO 把这件事工程化了（clip）。系列路标：高斯 → TRPO → PPO 数学 → GAE → GRPO 数学。不写约束式。
- 结尾（~250 字）：云的距离意象收束：概率是形状不是点；KL、高斯云都指向同一件事。预告：下一篇 TRPO——信任域怎么用这把尺子。开放式问题：给 coding agent 改策略，你更信参数距离还是分布距离？关注引导 + 近期热门 + 参考资料 + 话题标签。
