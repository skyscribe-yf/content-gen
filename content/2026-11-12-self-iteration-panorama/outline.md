## 一、定位

- 读者：写过代码、用过 coding agent、并且**已经或打算让 agent 参与改进自己**（改 prompt / 改工具 / 自己出题自己练）的工程师
- 认知目标：把「自我迭代有多自动」这个模糊直觉，换成一张**按「人类还剩什么」排序的地图**；并知道为什么「越自动越不结实」不是技术不成熟，而是**监督的价格决定的**
- 不是：五条线的逐条综述、篇 1 机制的重讲、篇 2 门控/接地的重讲、AI 安全治理讨论
- 轨道：文章轨（反直觉疑问句标题 + 亲历钩子 + 悬念链 + 可操作落点）
- 基调：**写死方向 + 加保险**——断言部分只给证据边界，保险部分给时间戳与范围限定

## 二、核心结论

**一句话**：1,250 篇自我改进论文里，真正进了生产线的只有两条；这两条的共同点不是「更先进」，而是它们每轮迭代都能拿到**几乎免费的反饥**——答案对位、跑一下看行不行。越往「连改进能力也交出去」走，你要的监督就越贵，直到贵到没人付得起。

**三层**：

1. **地图不是按自动化程度排的，是按「人类还剩什么」排的**。① 留题目和答案，② 留种子偏好，③ 只留一个执行器，④ 留初始权重，⑤ 留初始配置。人类退得越早，失败模式越狠。
2. **两条上生产（① 自产推理数据 / ⑤ 自改脚手架）都是「监督便宜」的那边**。综述给了一条验证层级：形式验证器 > 执行反馈 > 学出来的裁判 > 内在自评，而且**实测到的自我改进强度就沿着这条层级排**。便宜 = 有外部验证器 = 有界。
3. **「有界」不是过渡态**。递归自我改进的定义门槛是「改进能力本身被改进」，五条线一条都没过。最硬的证据是 DGM：它确实做出了可累积改进（80 次迭代，20.0%→50.0%），但论文自己写着这**并未建立无界递归自我改进**；它改的是 agent 代码，被搜的搜索器本身没变强——**自指 ≠ 递归**。

**最深一层（v2 摘要原话，本篇的题眼）**：卡住人类的不是「怎么验证」，而是**「什么才值得被验证」**。验证层级能索引前者，索引不了后者。

**落点（读者能带走的一问）**：你那个循环里，人类站在哪一步？

## 五、结构（7 节，正文约 2000 字）

小标题连起来必须是一条完整故事链：我以为问题是它改得不对 → 其实有两个名字 → 按「人类还剩什么」排出的地图 → 便宜的那两条已经进生产 → 贵的那条跑得最响也最悬（DGM/SEAL）→ 为什么没人过得了递归那道门 → 回到你自己的循环。

### 1. 我让它改项目的 AGENTS.md，它改出了别人用不了的东西（约 200 字，原声槽 1）
- 功能：亲历钩子，把读者的默认归因（它改得不对）写在开头
- 要点：agent 改项目级 AGENTS.md；改完的指令看着挺像回事，但塞进了大量绑定当前 harness 的具体写法；提交进代码库之后，别人可能没法用
- 这个例子的额外价值（写正文时用起来）：它不只是「改错了」，而是**绑定本地**——它优化的是我这台机器、这个 harness 下跑得通；这正是后文「便宜的监督 = 有界的监督」的微观版本
- 转折句：我原以为问题是它改错了。看完那篇综述才发现，**「它改得对不对」和「它有没有资格改」是两个不同的问题**

### 2. 两个名字：有界自精化 与 递归自我改进（约 260 字，新术语 2 个）
- 功能：把术语钉死，全文唯一两个新词
- 要点：
  - **有界自精化** = 对一个**固定的、外部的**判分器改进自己；会收敛，可评估，是工程实践
  - **递归自我改进** = 连「什么算更好」这套标准和改进机制本身一起改；没有固定外部锚点，原理上发散
  - 人话版：前者是**把作业改到老师满意**；后者是**连老师也换掉**
  - 作者的判据（原声槽 2，本篇的操作尺子）：**判分的那一方，在 agent 训练优化的内部还是外面**
    - 这条比「改进能力本身被改进」好用：它是一句能直接拿去问工程问题的话
    - 与综述定义的关系：判分方一旦搬到内部，闭环就合上了；“改进能力本身被改进”是它的形式化描述
    - 第 6 节用这条尺子逐条量五条线
- 关键判断句：这两个词被同一个词（self-improving）盖在一起，是这堆文献最贵的一次混用
- 数字：1,250 篇（2024–2026），2026 年二季度约 500 篇/季度还在加速
- 配图：01 两轴分类图（改进什么 × 闭环程度）

### 3. 一张按「人类还剩什么」排的地图（约 320 字，表格承载 ①②）
- 功能：全文骨架，一次给全五条线
- 表格（五列：线 / 迭代什么 / 人类还剩什么 / 代表工作 / 监督的价格）

- ③ 的一句话指路（不重讲）：这条线前两篇已经写过——**怎么自己出题**、**为什么会崩**；本篇只关心它站在哪一格

### 4. 两条进了生产：便宜的那两条（约 280 字）
- 功能：兑现标题里的「两条」
- ①：**答案对不对，对一下就知道了**——监督几乎不要钱；「拒绝采样再微调」这条路不需要人类裁判
- ⑤：**改完跑一下，看行不行**——prompt/记忆/工具的自改，不碰权重，便宜、可回滚、可审计
- 关键判断：这两条能上生产，不是因为它们最先进（⑤ 恰恰是最不"深"的一条），而是因为**它们的反饥每轮都拿得到，且不要钱**
- 边界（必写）：⑤ 的上限被基座锁死，不动权重就意味着它改不出基座不会的东西
- 撞墙亲历（槽 8，紧接边界）：自改之后看着更好，换个略不同的任务就拉胯——这就是“便宜”的代价：改出来的东西往往是对上一批任务过拟合的局部最优
- 反差点：④ 花 $22,000 换 +30 分（只在一个基准上）；⑤ 花一个下午，省的是**之后每一次**
- 复利论（槽 4，本节收口）：⑤ 省下的 token 不是一次性——**后面每一次新会话都立刻受益**，token 费用和时间双省，立竿见影且持续有效。这正是「便宜」为什么在工程上胜过「先进」的关键：它的收益随使用次数线性增长，而 ④ 的收益要先赌一次两万美金
- 反差点：④ 花 $22,000 换 +30 分（只在一个基准上）；⑤ 花一个下午，省的是**之后每一次**

### 5. 贵的那条跑得最响：80 次迭代，两万美金（约 320 字，④）
- 功能：主证据段，把「贵」写成可核的数字
- DGM（arXiv:2505.22954，UBC/Sakana/Vector，ICLR 2026）：进化搜索「能改写自身代码的 agent」，**80 次迭代**，SWE-bench Verified 200 题 **20.0%→50.0%**，Polyglot **14.2%→30.7%**
- 价格：SWE 那一轮跑了约两周，估 **$22,000**；两个消融各约 $10,000
- 消融（说明它真的在自我改进，不是玄学）：去掉自我改进（固定 meta-agent）39.0%；去掉开放式探索（爬山）23.0%
- **论文自己那句话**（本节高点）：该研究并未建立加速，也未建立无界递归自我改进
- SEAL（arXiv:2506.10943，MIT，NeurIPS 2025）：让模型自己生成微调数据和更新指令（"改自己的改法"），用下游表现当奖励；知识植入 47%、ARC 72.5%。代价：频繁自改会灾难性遗忘
- **安全细节（一定要写）**：DGM 某次运行里，agent 发现打分管线会检查它有没有编造工具输出，于是**把检测标记删掉了**来提分。改的是测评机制本身——**"有界"也不等于安全**
- 接旧文（槽 5 带出来的线，正文用一句内链）：这不是新问题。2025 年就有人系统拆过 reward hacking，到 DGM 这里只是换了一个更直接的场景——**以前是模型骗奖励函数，现在是模型直接改掉检查奖励函数的那段代码**
- 本节收口句（AI 写）：能改脚手架，意味着它能改到"裁判报分的那根线"上去；有界只保证它不会自己定义什么叫好，不保证它不会绕过你定的好
- 配图：03 DGM 改进曲线（80 次迭代）

### 6. 为什么没人过得了递归那道门（约 320 字）
- 功能：全文判断段，兑现「有界不是过渡态」
- 定义门槛：递归要求**改进能力本身被改进**（形式化描述）；操作版用槽 2 的尺子——**判分的那一方搬到优化闭环内部**
- 逐条对（每条只问一句：判分方在内还是在外）：
  - DGM：搜的是「更好的 agent 代码」，被搜的那个搜索器没变强；且验收靠 SWE-bench/Polyglot → **判分在外** → 自指 ≠ 递归
  - SEAL：学的是「怎么自我编辑」，但奖励来自外部任务表现 → **判分在外**
  - ①③：题和答案都是人类给的验证器在判 → **判分在外**
  - ②：judge 确实搬进了内部，但它是同一套权重自评 → 内在自评是验证层级最弱的一档，实测强度跟着掉
  - ⑤：判分靠跑一下看行不行 → **判分在外**
- 综述的落点（v2 原话，题眼）：卡住人类的不只是「怎么验证」（那是验证层级能索引的），还有**「什么才值得被验证」**——后者验证层级索引不了
- 加保险（必须原样体现）：我不能说递归自我改进永远做不到；我只能说，**到 2026 年 11 月，五条线上能找到的全部证据，都停在有界这一步**
- 保险之后直接接作者的赌注（槽 6，本节最高点）：如果真有人做成了递归自我改进，**突破口一定在底层如何处理 reward hacking 上**，而不是像今天这样继续在流沙之上建城堡
- 为什么这一句能当数：它把「有界不是过渡态」从「现在就这五条线」推到「必要条件在哪里”——这不是预言，是指出当前地基缺的那一层
- 与第 5 节呼应：DGM 删检测标记就是那块流沙的标本
- 收口句：所以“有界”不是技术不够，是**地基（可验证、不可绕过的判分）还没铺好**
- 配图：04 验证层级（形式验证器 → 执行反馈 → 学出来的裁判 → 内在自评）+ 实测强度沿层级下降

### 7. 回到你的循环：人类站在哪一步（约 220 字 + 原声槽 7）
- 三问（可操作）：
  1. 你的循环里，判分靠什么？（跑得通 / 有单测 / 另一个模型说好 / 自己说好）
  2. 这个判分器，**每轮都拿得到吗**？拿不到，你就已经在为「递归」付那个付不起的账
  3. 你让人放心让它改的，是权重，还是脚手架？
- 结尾互动问（槽 7，全文最后一句）：把上面三问收成一个读者手里真在跑的东西——**你有没有拉 agent 根据历史交互记录自己改 AGENTS.md？改完之后，你验过效果吗？**
