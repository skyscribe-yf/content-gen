# 梯度一步踩爆50倍预算，TRPO为什么敢走？

## 文章定位

- 「强化学习原理」系列第六篇。兑现三重预告：07-31 PPO 篇「TRPO 的完整数学推导和 trust region 的几何直觉，留到强化学习系列」、系列路标 ⑥TRPO、篇5 结尾「下一篇，拿着这把尺子，看 TRPO 怎么限步」。
- 一句话承诺（grill 定案）：**方向 + 刹车双主菜**——surrogate 回答「往哪走」（昨天的旧轨迹也能给新策略预打分），KL 约束回答「走多大」（拿篇5 的尺子限步），全推导出闭式解 $\theta_{new}=\theta_{old}+\sqrt{\frac{2\delta}{g^T F^{-1} g}}F^{-1}g$，这个解会自动把步子掰成椭圆的形状：窄方向小步、宽方向大步。
- 数学边界（grill 定案）：**全推导**。链条：重要性采样 surrogate → KL 约束优化 → 二阶泰勒近似（KL 二阶项出 Fisher）→ 拉格朗日乘子 → 闭式解。泰勒二阶展开、拉格朗日乘子均为**系列首秀**，各 ~250 字现场最小教学。Kakade-Langford 下界引用不证（Schulman arXiv:1502.05477 一句话给结论）。
- 数字例子（grill 定案 + 已蒙特卡洛事实验证）：**椭圆云续接**——沿用篇5 的 $\Sigma=\mathrm{diag}(0.01,100)$ 椭圆云（改行数窄/测试时长宽），普通梯度固定步长 vs 自然梯度同预算对照。

## 核心结论

1. **梯度只说方向，不说大小**：梯度上升 $\theta\leftarrow\theta+\eta g$ 用固定学习率 $\eta$，无视云的形状。篇5 说过：同一 0.1，窄方向 KL=0.5 翻天覆地、宽方向 KL=0.00005 几乎无感。
2. **surrogate：旧数据也能给新策略打分**：$\mathcal{L}(\theta)=\mathbb{E}_{\tau\sim\pi_{old}}\left[\frac{\pi_\theta(a|s)}{\pi_{old}(a|s)}\,G\right]$，重要性采样让昨天的轨迹可以预评今天的新策略——「往哪走」不用重跑新策略。
3. **约束优化：方向交给梯度，大小交给预算**。max $\mathcal{L}(\theta)$ s.t. $\mathrm{KL}(\pi_{old}\|\pi_\theta)\le\delta$，δ 就是篇5 那把尺子。
4. **二阶泰勒：曲率替直尺**。$\mathcal{L}$ 一阶展开给方向，KL 二阶展开给曲率 $F$（Fisher，篇5 的 $\Sigma^{-1}$ 推广到任意分布）——梯度走直线，曲率把直线掰成椭圆路径。
5. **拉格朗日乘子把约束折成罚金**，求导得到自然梯度 $F^{-1}g$，再用预算 δ 反解步长。
6. **闭式解 = 自动限步**：$\theta_{new}=\theta_{old}+\sqrt{\frac{2\delta}{g^T F^{-1} g}}F^{-1}g$。同样的预算，窄方向只挪 0.014、宽方向敢挪 1.41——篇5 的「允许步长」不再是上限，是 TRPO 每一步自动踩到的位置。**同一份梯度 $g=[1,1]$，普通梯度一步超预算 50 倍崩盘；TRPO 一步恰好踩满预算、行为几乎不变**。

## 结构（6 节 + 结尾，正文 ~5600 字）

- **开头（~250 字）**：场景对比钩子（对标 KV 缓存爆款，零导航）——两个 coding agent 同夜训练，A 普通梯度大步更新，第二天连昨天会的都忘了；B 用 TRPO 式限步，稳稳变强。抛问题：梯度只说往哪走，谁来决定走多大？挂锅盖：篇5 把尺子（KL）交给了读者，今天看 TRPO 怎么拿这把尺子当刹车。
- **一、篇5 的遗产：预算（~450 字）**：回引篇5 椭圆云（Σ=diag(0.01,100)，改行数窄/测试时长宽）。回顾两个数字：同一 Δμ=0.1，窄方向 KL=0.5 翻天覆地 vs 宽方向 KL=0.00005 几乎无感（1 万倍）；δ=0.01 预算下，窄方向最多挪 0.014、宽方向最多挪 1.41（100 倍）。但问题悬着：更新时每一步走多大，谁决定？梯度只有方向没有大小——普通梯度上升 θ←θ+ηg 用固定学习率 η。**篇5 告诉你「云窄的方向要小步」，普通更新器根本不看云**。
- **二、普通梯度：固定步长怎么崩的（数字例子第一部分，~600 字）**：回到椭圆云。目标函数对两个方向的梯度都是 1（改行数方向也该动、测试时长方向也该动，梯度说「两方向各走 0.1」）。固定学习率 η=0.1：一步把均值挪 $(0.1, 0.1)$。量一下：窄方向 KL 贡献 = ½·(0.1)²/0.01 = **0.5**，是预算 δ=0.01 的 **50 倍**。行为概率坍塌：窄方向云 σ=0.1，均值挪 0.1 恰好一个 σ，「改 3 行附近」的概率从 0.954 掉到 0.840——昨天会的，今天半忘。**反直觉点：不是学太快，是窄方向大步直接掀翻行为**。呼应篇4/篇5：「昨天会的今天忘」不是步长数字大，是云窄的方向经不起大步。
- **二、揭盖 1：surrogate——旧数据给新策略预打分（~550 字）**：问题：算新策略的回报要按新策略重跑轨迹，太贵。重要性采样：$\mathcal{L}(\theta)=\mathbb{E}_{\tau\sim\pi_{old}}\left[\frac{\pi_\theta(a|s)}{\pi_{old}(a|s)}\,G_\tau\right]$。直觉：昨天的轨迹还躺在仓库里，把「新策略在某个动作上的概率比」乘进去，就能预评新策略。数学合法性一句话（期望里乘 $\frac{\pi_\theta}{\pi_{old}}$ 把采样分布换掉，期望值不变——**只用旧数据，期望同一件事**）。例子：π_old 0.70/0.30，π_new 改成 0.80/0.20，用旧轨迹直接重加权预打分，不用重跑。**这个 surrogate 回答「往哪走」**。
- **四、泰勒展开——坡的直走与弯（~450 字）**：第一次正式请进泰勒。一阶项：站在山腰，看脚下这一格往哪翘（方向）；二阶项：坡本身在拐弯吗（曲率）。**KL 约束是弯曲的**：离得越远，限制越陡。展开到二阶，曲率矩阵就叫 Fisher（$F$，篇5 见过它的特例 $\Sigma^{-1}$——高斯云窄、曲率大、尺子敏感）。用一个二维抛物线手画二阶近似 vs 真值的图。
- **五、拉格朗日，把预算折成罚金（~450 字）**：想最大化 surrogate，但 KL ≤ δ 不能破。拉格朗日：**约束变成罚金**——每超出预算一个单位，罚 λ 的单价，λ 就是拉格朗日乘子。于是「max L - λ·(KL-δ)」一个式子同时表达「往收益多的地方走」和「别超预算」。
- **§5 主推导：从约束优化到闭式解（~900 字，符号卡 2：$F$、$\lambda$）**：
  1. 目标：max $g^T\Delta\theta$（一阶 surrogate）+ 约束 ½ΔθᵀFΔθ ≤ δ（KL 二阶）。其中 $F=\nabla_\theta^2 KL = \Sigma^{-1}$（高斯策略）→ 一般分布定义级推广，一句带过不证明。
  2. 拉格朗日：$g^T\Delta\theta - \lambda(\frac{1}{2}\Delta\theta^T F\Delta\theta - \delta)$，对 Δθ 求导为零 → $F\Delta\theta^* = g/\lambda$ → $\Delta\theta^*=\frac{1}{\lambda}F^{-1}g$。
  3. **自然梯度**：方向 $F^{-1}g$ 掰弯了——g 说两方向都走 0.1，$F^{-1}g$ 把窄方向压成 0.01、宽方向放大成 100，比例 1 万倍。
  4. 用预算定步长：代入约束正好取等 → $\lambda=\sqrt{2/(g^TF^{-1}g)\cdot\delta}$… 闭式解 $\theta_{new}=\theta_{old}+\sqrt{\frac{2\delta}{g^TF^{-1}g}}F^{-1}g$。
  5. 蒙特卡洛验收：g=[1,1]，δ=0.01 → 步长 $(1.4\times10^{-4},\,1.41)$，KL 恰好 = 0.010（贴预算边），窄方向挪 0.00014 ≪ 0.014 上限、宽方向挪 1.41 = 上限。**篇5 的「最多挪 0.014/1.41」变成 TRPO 每步自动踩到的数。**
  6. 工程注脚一句：真实现实里 F⁻¹ 用共轭梯度迭代算，不真求逆（一句，不展开）。
- **§6 TRPO 在 RLHF 谱系里（~400 字）**：TRPO → PPO（clip 工程化，篇7 预告）→ GRPO（DeepSeek-V4 后训练用）。Kakade-Langford 下界一句话：Schulman 证明「优化 surrogate 保证真目标不降」，本文引用不证。国产模型一句：GRPO 是这条线上工程化得最狠的一环，DeepSeek 用它训 V4（仅一句，不展开）。路标：下一篇 PPO 数学。
- **结尾（~300 字）**：回扣开头两个 agent：A 崩在「没看云」，B 稳在「预算+方向都在掌」。闭式解一句话收束：**方向由梯度定，大小由尺子定——尺子记得云的形状**。预告：TRPO 要真上线，每步求 F⁻¹ 太重——PPO 用一句 clip 就把这桌数学换成了工程。开放式问题 + 点赞/关注/收藏 + 近期热门 + 参考资料 + 话题标签。
