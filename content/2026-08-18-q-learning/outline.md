# Q-learning是什么？没有转移表怎么解

## 文章定位

- 「强化学习原理」系列第三篇。承接第二篇刚挂上的三条路：**Q-learning 解它，PPO 用一半，GRPO 绕开它。** 本篇走「解它」——不知道转移 \(P\) 时，怎么从样本逼近贝尔曼方程。
- 一句话承诺（grill 定案）：**不知道 \(P\) 时，用「实际拿到的奖励 + 下一步已经估过的值」当老师，就能一步步解贝尔曼方程。Q-learning 是这个办法里每步都按最优动作记账的那一个。**
- 开篇主论证（grill 定案）：方程里有一张转移表；修 bug、写代码、对话没有这张表。所以不能解方程，只能走一步、看一眼、用下一步估值当老师。第一次出现时用一句话拆开 RL 的 model（\(P\) 和 \(r\)）和大模型。收窄：下棋有模拟器，另说。
- 「大模型时代为什么还看」只放开头一两段（≤150 字），不当独立小节：不是给大模型铺 Q 表；PPO 请回的 critic、GAE 的误差，和 Q-learning 是同一种「下一步当老师」；GRPO 扔掉的就是这个。立刻进正题。
- 旧地图改口（第一篇已发）：第一篇说过「多维高斯打底」，顺序改了——方程还不会解，椭球用不上。高斯挪到 TRPO 前面。一两句，诚实优先，不展开。
- 数学边界（grill 定案）：**推完 TD(0)** \(\delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t)\)，以及 **Q-learning 更新**（\(V\to Q\)，下一步用 \(\max_{a'}\)）。价值迭代只当一两百字对照。SARSA 一句区分 on-policy。n-step / TD(λ) 挂到 GAE。
- 符号：不重复第二篇整张卡。只新增 \(\delta\)、\(\alpha\)、\(Q(s,a)\)、\(\max_{a'}\)，全部挂修 bug 例子。大小写铁律沿用上篇。
- 数字例子（grill 定案 + 本稿锁定）：coding agent 停在「改完一处，要不要跑测试」。\(\gamma=0.9\)，\(\alpha=0.5\)。不沿用 0.81，不另起 GridWorld。
  - **TD 两步**（学 \(V\)）：初值 \(V(s_0)=0.50\)，\(V(\text{红})=0.20\)，绿是终局 \(V=0\)。第一步跑测试看到红、\(R=0\)：\(\delta=-0.32\)，\(V(s_0)\leftarrow 0.34\)。第二步看到绿、\(R=+1\)：\(\delta=0.66\)，\(V(s_0)\leftarrow 0.67\)。
  - **Q-learning 两步**（同一场景，只多 \(\max\)）：初值 \(Q(s_0,\text{跑测试})=0.60\)，\(Q(s_0,\text{再改一处})=0.30\)，\(Q(\text{红},\text{重写})=0.40\)，\(Q(\text{红},\text{回退})=0.10\)。第一步跑测试→红、\(R=0\)：目标 \(=0.9\times\max(0.40,0.10)=0.36\)，\(\delta=-0.24\)，\(Q\leftarrow 0.48\)。第二步→绿、\(R=+1\)：\(\delta=0.52\)，\(Q\leftarrow 0.74\)。
- 推导路数：Sutton & Barto 第 6 章（TD(0) §6.1，Q-learning §6.5）。正文说明来源，文末给同一本书链接（上篇引过 Ch3，本篇点 Ch6）。
- 反常识点：下一步的估值是错的，也能当老师——错的老师带着你走近一点，再当一次老师。不是一次解出方程，是被样本推着逼近。
- 下一篇预告：篇 4 **策略梯度 + Actor-Critic**（三条路的「用一半」）。不预告高斯，不把后面路标写成死承诺。

## 核心结论

1. **没有转移表**：贝尔曼方程右边有 \(P(s'|s,a)\)。修 bug / 写代码 / 对话没有这张表，不能当线性方程组来解。
2. **有表就直接解**：价值迭代反复套最优方程。对照用，不当主角。
3. **TD(0)**：用一次真实转移替换对 \(P\) 的求和。\(\delta_t = R_{t+1}+\gamma V(S_{t+1})-V(S_t)\)，\(V(S_t)\leftarrow V(S_t)+\alpha\delta_t\)。
4. **错的估值也能教**：目标里的 \(V(S_{t+1})\) 本身是估计。两步数字 0.50→0.34→0.67，先被红单拉低、再被绿单拉高。
5. **Q-learning**：同一套 TD，记账对象换成 \(Q(s,a)\)，下一步用 \(\max_{a'}Q(s',a')\)——按最优动作记账，不按你实际走的那步。这就是「解它」。
6. **SARSA 只露脸**：若目标改成实际采取的 \(Q(s',a')\)，就是 on-policy。一句，不展开。
7. **不过时的那一半**：PPO 的 critic / GAE 的误差，是 \(V\) 上的 TD；GRPO 扔掉的是这个老师。点到为止。

## 结构（7 节 + 结尾，正文 ~3200 字）

- 开头（~280 字）：回到上篇停在原地的 agent，手里多了一个 \(V\)。点破：上篇方程里有一张 \(P\) 表，agent 没有。拆开「model ≠ 大模型」。三四句不过时（critic / GAE / GRPO）。旧地图改口一句。今天的问题：没有表，怎么解？
- 一、方程里有一张你没有的表（~400 字）：回写上篇 \(V^\pi(s)=\sum_a\pi\sum_{s'}P[\cdots]\)，把 \(P\) 圈出来。coding agent 没有「这一步之后测试变绿的概率表」。RL 的 model = \(P\) 和 \(r\)。
- 二、有表会怎么做（对照，~200 字）：价值迭代 = 反复套最优方程。有模拟器（棋）才走得通。我们关心的问题没有，所以要采样。
- 三、先把新符号说清楚（~280 字）：4 个新符号挂修 bug。\(\delta\)=账没做平的差额，\(\alpha\)=这一笔信多少，\(Q(s,a)\)=在这个状态下做这个动作值多少（上篇挂过招牌），\(\max_{a'}\)=下一步按最好的动作记账。
- 四、TD(0)：用下一步的估值当老师（~700 字，核心推导）：一次采样 \((s,a,r,s')\) 替换对 \(P\) 的求和；写出 \(\delta\) 和更新式；点明 \(V(s')\) 是估计不是真值；学习率 \(\alpha\) 防止一张样本把账改飞。来源 Sutton Ch6。
- 五、跑两次测试，账被改了两笔（~500 字）：上述 TD 数字；第一步 0.50→0.34，第二步 0.34→0.67。点题：不是一次解出，是样本在推。
- 六、Q-learning：只多一个 \(\max\)（~550 字）：\(Q\) 更新式；\(\max\) 的含义（解最优方程，不是解当前策略的评估方程）；同一场景两步 0.60→0.48→0.74；对比 TD 学 \(V\)，Q-learning 学「在这儿做哪件事」。
- 七、和后训练的半句话（~250 字）：SARSA 一句；n-step / λ 挂 GAE；critic 是 \(V\) 上的 TD，不当第三节。
- 结尾（~250 字）：回到 agent——现在它能在没有 \(P\) 表时改账。预告篇 4：解方程只是一条路，策略梯度不经过 \(P\) 直接改 \(\pi\)，Actor-Critic 把两条路接到一起。开放式问题（你更信「下一步估值」还是「这组回答的平均分」？）。关注引导 + 近期热门 + 参考资料 + 话题标签。
