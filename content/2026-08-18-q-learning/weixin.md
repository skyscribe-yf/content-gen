在上一篇《贝尔曼方程：为什么只看下一步就够了？》里，coding agent 手里多了一个数：价值函数 $V$。账本有了，记账法也有了。

可方程右边藏着一张表：$P(s'\mid s,a)$。从这一步跳到下一步，每一格都是概率。

agent 修 bug，没有这张表。它不知道「再改一行，测试变绿」的概率是 0.2 还是 0.8。

强化学习里说的 model，是这张转移表，加上奖励怎么发。不是你平时说的大模型。

下棋有模拟器，表可以自己滚出来。修 bug、写代码、对话，没有。

所以今天不是教你给大模型铺一张 Q 表。[PPO 把 critic 请回来](https://mp.weixin.qq.com/s/OEZtUhm8MT_En7enJo_8dw)，GAE 算的那笔误差，和 Q-learning 是同一种「下一步当老师」。[GRPO](https://mp.weixin.qq.com/s/t4sO-zC5v1_jq8hJT_YTGA) 扔掉的就是这个。

第一篇说过，地基里有多维高斯。顺序改了。方程还不会解，椭球用不上。

这是「强化学习原理」系列第三篇。上篇把三条路挂上：Q-learning 解它，PPO 用一半，GRPO 绕开。今天走「解它」。

## 一、方程里有一张你没有的表

上篇推完的贝尔曼方程，我再抄一遍：

$$V^\pi(s) = \sum_a \pi(a\mid s)\sum_{s'} P(s'\mid s,a)\left[r(s,a,s') + \gamma V^\pi(s')\right]$$

圈出中间那个 $P$。它是一张表：在状态 $s$ 做动作 $a$，下一步变成 $s'$ 的概率。

七成跑测试、三成改文件，是 $\pi$。跑完测试八成看到红、两成全绿，是 $P$。

$\pi$ 是你的习惯，你可以改。$P$ 是世界怎么变，你改不了。

coding agent 停在「改完一处，要不要跑测试」。它没有一张表写着：跑完之后红的概率多少、绿的概率多少。日志会撒谎，测试会偶发失败，同一处改动昨天绿、今天红。

我第一次看见贝尔曼方程，以为把 $P$ 填进去就能交差。后来对着 agent 的轨迹发呆：表在哪？没有。

没有表，方程右边那一层求和就写不出来。你不能把它当线性方程组求解。

![贝尔曼方程那张转移表是空的：没有地图，只能走一步看一步](01-no-transition-table.png)

## 二、有表会怎么做

假如你真有这张表，事情反而简单。

上篇露过脸的最优方程：

$$V^*(s) = \max_a \sum_{s'} P(s'\mid s,a)\left[r(s,a,s') + \gamma V^*(s')\right]$$

有 $P$，就反复套这个式子。每个状态更新一遍，再更新一遍，直到账做平。课本叫价值迭代。

下棋能这么干。规则写死了，模拟器就是 $P$。你在脑子里推下一步，等于在查表。

修 bug 查不了。对话也查不了。没有模拟器把「这句话说完用户会怎样」滚出来。

有表，解方程。没表，只能走一步、看一眼，拿看见的那一次当样本。

## 三、先把新符号说清楚

上篇的符号卡今天还管用：大写是没落定的随机变量，小写是已经落地的取值。

新出场四个，都挂在修 bug 上：

| 记号 | 人话 |
|------|------|
| $\delta_t$ | 时序差分误差。你以为值多少，和「实际奖励 + 下一步估值」差多少。账没做平的那一截。 |
| $\alpha$ | 学习率。这一笔差额，你信多少。0.5 就是信一半，留下一半给以后的样本。 |
| $Q(s,a)$ | 站在 $s$，先把动作 $a$ 说死，未来平均值多少。上篇挂过招牌：整店值多少是 $V$，今晚必须搞促销是 $Q$。 |
| $\max_{a'}$ | 下一步按最好的那个动作记账。不管你实际走了哪条。 |

$\delta$ 读作 delta。它不是新的目标，只是旧账和新情报的差。

$\alpha$ 别想太玄。一张样本就改光，账会被单次运气带飞。所以每次只挪半步。

## 四、TD(0)：用下一步的估值当老师

方程右边对 $P$ 求和，是在问：所有可能的下一步，平均下来值多少。

你没有 $P$。你只有一次真实发生的转移：在 $s$ 做了 $a$，拿到 $r$，走到了 $s'$。

那就别平均了。用这一次，替换那一层求和。

$$R_{t+1} + \gamma V(S_{t+1})$$

左边是你刚拿到的奖励。右边是站在新局面上，账本里已经写着的一口价，再打个折。

两样加起来，就是这一步给你的新估价。数学上叫 TD 目标。

它和旧估价 $V(S_t)$ 的差，就是 $\delta$：

$$\delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t)$$

账没做平，就按这个差额改一笔：

$$V(S_t) \leftarrow V(S_t) + \alpha\,\delta_t$$

这就是 TD(0)。时序差分，temporal difference。0 表示只看一步。

Sutton 和 Barto 的书第 6 章就是这么引入的。上篇 Bellman 用的是第 3 章。同一本书，往后翻三章。

我在这里卡过很久。目标里的 $V(S_{t+1})$ 本身就是估的，还可能错得离谱。错的老师，凭什么能教？

后来想通了。老师不用全对。它只要比你现在手里的数，多看见了一步真实奖励。这一步是落地的。错的估值带着你走近一点，再当下一次的老师。

不是一次解出方程。是被样本推着，一步步逼近。

$\alpha$ 就是怕你太听话。红了一次就把 $V$ 砍光，下一次全绿又拉满，账会抖。每次只信一半，抖得没那么狠。

![下一步的估值当老师：当前状态听一个可能还不准的老师改账](02-td-teacher.png)

用中文读，TD 在做三件事：

- 走一步，看见真实的 $r$ 和 $s'$；
- 拿「$r$ + 折扣后的 $V(s')$」当新估价；
- 新旧之差，按 $\alpha$ 掺进旧账。

对 $P$ 的求和，被一次采样换掉了。

## 五、跑两次测试，账被改了两笔

推导完了，必须手算。还是那个 agent，刚改完一处，状态叫 $s_0$。下一步跑测试，只会看到两种结局：红，或者绿。

绿是终局。测试通过，当场 +1，后面没了，$V(\text{绿})=0$。

红还要继续改，先随便估一个：$V(\text{红})=0.20$。

$s_0$ 自己先瞎估：$V(s_0)=0.50$。折扣 $\gamma=0.9$，学习率 $\alpha=0.5$。

它不知道红绿各占多少。表不存在。只能跑。

**第一次，测试红了。** $R=0$，走到红。

$$\delta = 0 + 0.9\times 0.20 - 0.50 = -0.32$$

新估价只有 0.18，旧账写着 0.50，高估了。改一半：

$$V(s_0) \leftarrow 0.50 + 0.5\times(-0.32) = 0.34$$

**第二次，测试绿了。** $R=+1$，走到终局。

$$\delta = 1 + 0.9\times 0 - 0.34 = 0.66$$

新估价是 1，旧账刚被砍到 0.34，低估了。再改一半：

$$V(s_0) \leftarrow 0.34 + 0.5\times 0.66 = 0.67$$

两步：$0.50 \to 0.34 \to 0.67$。先被红单拉低，再被绿单拉高。

没有一次给出「正确答案」。也没有用到任何 $P$。

![两步 TD：V(s0) 从 0.50 到 0.34 再到 0.67](03-td-two-updates.png)

假如红绿的真实概率是一半一半，长期平均下来，$s_0$ 大概值 $0.5\times(0+0.9\times 0.20)+0.5\times 1=0.59$。我们两步走到 0.67，还在晃，方向是对的。

这就是「没有转移表怎么解」。解，不是代入。是走、看、改。

## 六、Q-learning：只多一个 $\max$

TD 学的是 $V$：站在这个状态，值多少。它不区分你在这儿做了哪件事。

上篇把 $Q$ 挂了招牌。$Q(s,a)$ 把动作说死：在 $s$ 做 $a$，值多少。修 bug 时就是：现在跑测试值多少，再改一处值多少。

把 TD 的记账对象换成 $Q$，下一步不再用 $V(s')$，改成下一步最好的那个 $Q$：

$$Q(s,a) \leftarrow Q(s,a) + \alpha\left[R + \gamma \max_{a'} Q(s',a') - Q(s,a)\right]$$

括号里还是 $\delta$。只多了一个 $\max$。

这个 $\max$ 就是上篇最优方程里那个 $\max$。Q-learning 在解的，不是「按你现在这套习惯走下去值多少」，是「每步都挑最好的动作，值多少」。

所以它是三条路里「解它」的那一条。解的是贝尔曼最优方程。从样本里解。

同一场景再走两步。先瞎估：

- $Q(s_0,\text{跑测试})=0.60$
- $Q(s_0,\text{再改一处})=0.30$
- $Q(\text{红},\text{重写})=0.40$
- $Q(\text{红},\text{回退})=0.10$

绿还是终局，后面没有动作。

**第一次，它跑了测试，看到红。** $R=0$。下一步的最好动作是重写，0.40，不是回退 0.10。

$$\max_{a'}Q(\text{红},a') = \max(0.40,\,0.10)=0.40$$

$$\delta = 0 + 0.9\times 0.40 - 0.60 = -0.24$$

$$Q(s_0,\text{跑测试}) \leftarrow 0.60 + 0.5\times(-0.24) = 0.48$$

**第二次，又跑测试，看到绿。** $R=+1$，终局。

$$\delta = 1 + 0 - 0.48 = 0.52$$

$$Q(s_0,\text{跑测试}) \leftarrow 0.48 + 0.5\times 0.52 = 0.74$$

两步：$0.60 \to 0.48 \to 0.74$。和 $V$ 那两笔一样，被样本推着晃。

差别在红的那一步。TD 用的是 $V(\text{红})=0.20$。Q-learning 用的是 $\max(0.40,0.10)=0.40$。它按「到了红以后你会选最好的那招」记账，不按你当时心情。

![Q-learning 下一步取 max(0.40, 0.10)=0.40，不是实际可能走的 0.10](04-q-max.png)

假如目标里不用 $\max$，改成你下一步**实际采取**的那个 $Q(s',a')$，那就是 SARSA。它跟的是你正在用的策略，不跟最优策略。今天记住这一句差就够。

## 七、和后训练的半句话

n 步以后再结算，或者把很多步的 $\delta$ 按衰减加起来，叫 n-step、TD($\lambda$)。PPO 里的 GAE，就是这条线的后代。完整式子放到那一篇。

回到大模型后训练。critic 学的是 $V$，更新套路就是今天的 TD：用下一步估值当老师。Q-learning 只是把老师换成了 $\max Q$。

GRPO 连这个老师都不要，改用同一道题几份回答的平均分。省显存，长程任务会变粗。上篇说过，这里不再展开。

你不是要给 LLM 铺一张状态-动作表。你要看懂：后训练里还在用的，和 1989 年 Watkins 写下的更新，是同一种「下一步当老师」。

## 结尾

回到那个停在第 3 步的 agent。

上篇给它一个 $V$。这篇告诉它：没有 $P$ 表，也能改账。走一步，看红或绿，用下一步估值当老师，错一点没关系。

Q-learning 只多问一句：到了下一步，最好的那招值多少？

解方程只是一条路。还有一条路根本不经过 $P$，直接改策略 $\pi$。那是策略梯度。再下一步，Actor-Critic 会把「改策略」和「下一步当老师」接到同一根管子上。
