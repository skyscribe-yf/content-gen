## S1 · 开场钩子：方程里那张表，你没有（~40s）

**动画要点**：
- 页1 主视觉：贝尔曼方程在屏幕上组装 → 圈出中间的 P(s'|s,a) → **play_red_cross 盖掉 P**（强调 1/5）→ 概念图「空表 / 没有地图」（s1-empty-table-round.png）
- 页2：π 可改 vs P 改不了 双卡对比；「model = 转移表 + 奖励规则，不是大模型」警示条
- 结尾悬念条：「有表，方程能解。可你要解的，偏偏是那张不存在的表。」

**配音稿**：
> 方程右边藏着一张表：从 s 做动作 a，跳到哪个状态，每一格都是概率。(gasps) 真拿来修 bug 你会发现：这张表根本不存在。改一行代码，测试变绿的概率是零点二还是零点八，没人知道。这里的 model，指转移表加奖励，不是大模型。下棋有模拟器，表能自己滚出来。修 bug、写代码、对话，没有。所以今天，不是教你给大模型铺一张 Q 表。

**结尾悬念**：有这张表，方程可以直接解。可你手里的，偏偏是张不存在的表。

## S2 · 有表会怎么做 + 认四个符号（~45s）

**动画要点**：
- 页1 概念图：下棋模拟器 vs 修 bug（s2-chess-bug-round.png）→「有表：反复套方程，账做平」卡 →「没表：走一步、看一眼、拿一次当样本」卡
- 页2 主视觉：三个符号徽章排开（delta 旧账和新情报的差 / Q 把动作说死值多少 / max 才是主角），逐枚弹出（α=学习率留到 S3 更新式登场）
- 结尾悬念条：「看这一眼，怎么变成账本里的一笔？」

**配音稿**：
> 真有这张表呢？反而简单：有 P，就把最优方程反复套，每个状态更新一遍，再更新一遍，直到账做平。课本叫价值迭代。下棋能这么干，规则写死，模拟器就是 P。修 bug 没模拟器。没表，方程右边那层求和就写不出来，只能走一步、看一眼，把看见的那一次当样本。动手前认两个符号：delta，旧账和新情报的差；Q，把动作说死值多少。还有一个 max，它才是主角。

**结尾悬念**：走一步、看见奖励，可这一眼怎么变成账本里的一笔？

## S3 · TD(0)：用下一步的估值当老师（~45s）

**动画要点**：
- 页1 主视觉：公式逐块组装——「实际奖励 R」+「折扣后的下一步估值 γV(s′)」→ 合成「新估价」→ 减旧账 V → δ（δ 高亮圈出，画面出组装公式，上标锚 UR）
- 页2：更新式 V ← V + αδ（α 用「信一半」标注）→「TD(0)，只看一步」爆点条
- 页3：「错的老师，凭什么能教？」问句爆点 → 「老师不用全对」+「被样本推着，一步步逼近」结论卡（强调 2/5）
- 结尾悬念条：「但这个老师，本身就是个错的。」

**配音稿**：
> 没有 P，你只有一次真实发生的转移：在 s 做了 a，拿到奖励 r，走到 s′。那就别平均了，用这一次替换求和。新估价，等于刚拿到的奖励，加下一步状态的估值，打个折扣。它和旧账的差，就是 delta。账没做平，就按差额改一笔：旧账，加学习率乘 delta。这就是 TD 零，时序差分，只看一步。我卡过很久：目标里的 V(s′) 本身是估的，可能错得离谱。(breath) 错的老师，凭什么能教？后来想通了：老师不用全对，只要比你多看见一步真实奖励。这一步是落地的。错的估值，带着你走近一点，再当下一次的老师。

**结尾悬念**：可这老师的课，真能教出对的账吗？拿真实数字算一笔。

## S4 · 手算两笔：0.50 → 0.34 → 0.67（~48s）

**动画要点**：
- 页1：状态卡片 s₀ / 红 / 绿 + 参数条（γ=0.9、α=0.5、V(红)=0.20、V(s₀)=0.50）
- 页2 主视觉：**counter_value 滚动 0.50 → 0.34**（第一次红，δ=-0.32 展示）→ **0.34 → 0.67**（第二次绿，δ=+0.66）→ 终值卡片 0.50→0.34→0.67 链条
- 页3：「长期平均 ≈ 0.59，方向是对的」小字说明（停 ≥2s）+「解，不是代入。是走、看、改」金句条
- 结尾悬念条：「可要是记账对象，从 V 换成 Q 呢？」

**配音稿**：
> 推导完必须手算。agent 刚改完一处，状态 s 零。跑测试就两种结局：红或绿。绿是终局，当场加一；红还要改，先估零点二。s 零瞎估零点五。折扣零点九，学习率零点五。第一次，红了。新情报：零加零点九乘零点二，零点一八。旧账零点五，高估了。差值负零点三二。改一半，零点三四。第二次，绿了。奖励一，新情报一。旧账刚被砍到零点三四，低估了。再改一半，零点六七。没有一次给过正确答案，也没用到任何 P。红绿一半一半的话，长期平均零点五九。两步走到零点六七，还在晃，方向是对的。解不是代入，是走、看、改。

**结尾悬念**：可要是记账对象，从 V 换成 Q 呢？

## S5 · Q-learning：只多一个 max（~52s）

**动画要点**：
- 页1 主视觉：Q 更新公式组装（V(s′) 划掉 → 换成 max Q(s′,a′)，**max 黄色高亮放大**，强调 3/5）
- 页2：动作估值四卡（跑测试 0.60 / 再改一处 0.30 / 到红·重写 0.40 / 到红·回退 0.10）
- 页3：手算——第一次红：max(0.40, 0.10) = 0.40（0.40 高亮、0.10 变暗）→ counter 0.60 → 0.48（δ=-0.24）；第二次绿：counter 0.48 → 0.74（δ=+0.52）
- 页4：**对比卡**：TD 用 V(红)=0.20 vs Q 用 max=0.40（强调 4/5）→ SARSA 一句话小卡（max 换成实际动作）
- 结尾悬念条：「真实大模型的后训练，用哪一本账？」

**配音稿**：
> 把记账对象换成 Q：下一步不用 V(s′)，改成下一步最好的那个 Q。公式几乎一样，只多一个 max。它解的是每步挑最好动作，值多少。先估：跑测试零点六，再改一处零点三；到了红，重写零点四，回退零点一。第一次，红了。下一步最好动作是重写零点四。delta：零加零点九乘零点四，减零点六，负零点二四。改一半，零点四八。第二次，绿了。奖励一，终局。delta 零点五二，改一半，零点七四。差别在红那一步：TD 用的是零点二，Q-learning 用的是 max 出来的零点四。它按你到了红以后会选最好的那招记账，不按当时心情。把 max 换成实际走的动作，就是 SARSA，记这一句就够。

**结尾悬念**：可真实大模型的后训练，用哪一本账？
