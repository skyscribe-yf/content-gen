# 封面 Prompt — AI 多想 3 秒，正确率为什么从 71% 涨到 86.7%？

- 类型：conceptual（推理篇封面：64 路汇聚为背景层，标题为全幅前景主角，与训练篇封面同构）
- 画幅：21:9 电影宽幅（生成后 center-crop）
- 调色板：深炭灰 + 暖金色（与训练篇封面同语言，姊妹篇）
- 渲染：flat-vector / notion editorial
- 文字层级：title-only（画面中除主标题外禁止出现任何其他文字，包括数字）
- 语言：主标题为中文，一字不差（含 % 符号）
- 输出：00-cover.png（文章目录，与 weixin.md 同级）
- **版式：无左右分栏。标题作为前景元素横贯整个横幅，完全占满宽度，是画面唯一主角**

## Prompt

为微信公众号技术文章生成电影宽幅 21:9 封面图，1K 分辨率。构图：**背景层**是无数细小的浅灰色路径曲线交织成的轨迹网络底纹，铺满全幅、被压暗、低对比度、轻微虚化；网络左侧伸出 64 条细小的金色线条（象征同一道题答了 64 遍），向画面中部汇聚成一条宽阔的暖金色主干道，带几个小圆点检查点，由左向右延伸——金色主干道是背景层里唯一亮色，象征「多数票把答案稳稳拽回主路」。**前景层是超大号标题文字，横贯整幅画面，是绝对主角**。整体像高端技术电影海报：背景深邃克制，标题巨大醒目。不使用人物面部，不出现真实人脸、棋盘、文字草稿。

**标题文字（唯一允许出现的文字）：「AI 多想 3 秒，正确率为什么从 71% 涨到 86.7%？」**

标题排版硬性要求：
1. 标题是整张封面唯一的主角，**横向完全铺满整幅画面的宽度，从画面左边缘一直延伸到右边缘**（左右不留边距，两行各自用满全宽），每行字高约占画面高度的 1/8，两行标题合计约占画面高度的 1/3，字体极粗（ultra-bold 黑体），从缩略图尺寸看依然醒目、一眼能读完整句；
2. 标题颜色用**高饱和金色（金黄到琥珀金，如 #FFD700/#FFB800，金属质感）**，带柔和发光（glow），在深炭灰背景上像霓虹灯一样醒目——金色标题是整张封面最强的视觉元素，对比极强，无花纹、无复杂描边，边缘锐利；
3. 标题分两行横排、居中：第一行「AI 多想 3 秒，正确率为什么」、第二行「从 71% 涨到 86.7%？」（两行均为整句换行，不得拆散词组）；
4. 数字与百分号必须准确：「71%」「86.7%」一个字符都不能错；
5. 背景层完全退居标题之后：64 条金线、主干道、灰色路径都可以延伸穿过画面，但必须被压暗或降对比，不得与文字重叠、不得遮挡标题，标题永远在最上层、清晰锐利。

**除此之外，画面中绝对禁止出现任何其他文字、小字、副标题、标语、英文、数字——一个字都不行。**

## ZONES

- 全幅背景：压暗的灰色轨迹网络底纹 + 64 条金线汇成一条暖金主干道（左→右，带检查点小圆点），低对比度、虚化退后。
- 全幅前景：两行超大号发光标题横贯整幅画面宽度，居中排列，标题面积约占画面 30%。
