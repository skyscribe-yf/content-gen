# Prompt — 03-policy-network.png（策略网络：报候选的老棋手）

## Prompt

为微信公众号技术文章生成 1:1 插图（flat vector / notion editorial 风格）。主题：一个围棋棋盘上，一位抽象的「老棋手」剪影（戴帽、拄拐或简单几何人形）站在棋盘旁，目光扫向棋盘，棋盘上只有 3 颗被高亮的暖金色棋子（代表他报出的候选），其余棋子都是模糊的小灰点（代表被排除的 200 多个可下点）。画风：逻辑示意图，克制、简洁、理性，无文字、无数字、无面部特写、不出现真人脸。背景为深炭灰到米白的柔和渐变。整个画面除几何图形外无任何文字。

**画面中绝对禁止出现任何文字、数字、字母、标语。**

## ZONES

- 左侧 40%：老棋手剪影（深炭灰，简单几何人形，戴帽或持扇），面向右侧棋盘。
- 右侧 60%：围棋棋盘（米白线格，俯视），棋盘中央 3 颗暖金色高亮棋子排成一线，周围 200 多颗棋子全部处理成浅灰/浅米色小点（模糊、淡化），象征「只挑 3 个候选，其他都不看」。
- 整体留白充足。

## COLORS

- 背景：深炭灰 #1E1B18 到 #F7F3EB 米白渐变（左深右浅）
- 老棋手：深炭灰 #2C2A26 剪影
- 高亮候选棋子：暖金 #D97706
- 模糊棋子：浅灰 #8A8478 / 米白 #F7F3EB

## STYLE

flat vector illustration，geometric，editorial，克制，简洁，无文字。
