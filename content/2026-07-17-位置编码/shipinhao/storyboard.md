## 段落设计（8 段）

| # | 场景 | 动画要点 | 配音稿 |
|---|------|---------|--------|
| S1 | 开场钩子 | 「猫追老鼠 / 老鼠追猫」两张牌对比；词嵌入「认词」vs 位置「分先后」；注意力盲区 → 座次表 | 猫追老鼠。老鼠追猫。词，一模一样；意思，完全相反。词嵌入让模型认出"这是猫、那是老鼠"——可谁是主动者，谁被追，它不知道。注意力能看见所有词，却天生分不清先后。位置编码补的，就是这张"座次表"。可注意力，为什么看不见顺序？ |
| S2 | 注意力无顺序感 + 绝对位置编码 | x1 x2 x3 换序 vs 集合不变；hᵢ = xᵢ + pᵢ 公式；「猫」在第 1 位 / 第 7 位加不同 p；绝对位置编码标签 + 缺点（相邻关系要自己学） | 因为它只看向量之间的关系：谁和谁更像。把 x1、x2、x3 换成 x3、x1、x2——集合没变，向量没变，模型看不出换了座次。输入里，根本没有"第几个"。怎么办？加一个位置向量：第 i 个 token 的输入，等于词向量加位置向量。"猫"在第 1 位，加 p1；在第 7 位，加 p7——词相同，向量不同。这叫绝对位置编码。但 p1、p2 只是两张不同的向量，"第 2 个紧挨第 1 个"，模型得自己学。怎么破？ |
| S3 | 正弦位置编码 | 多频率波形（快/中/慢三条波）；钟表隐喻（秒/分/时针）；sin+cos 坐标轴转动；「不用存表」；仍是加法 | 让位置向量自己带上规律！2017 年，Transformer 论文给出一个漂亮方案：用不同频率的正弦、余弦生成位置。不同维度，波速不同——有的变化快，分清相邻位置；有的变化慢，看更远的距离。像一组钟表：秒针管近处，分针管中距，时针管远方。为什么同时用 sin 和 cos？它们像垂直的坐标轴，位置移动，向量就在平面里转动。不用存表，任意位置代入公式就能生成。但它还是加法：位置和内容，混在一起。还有别的路吗？ |
| S4 | 可学习位置编码 + 长度外推 | 可训练参数表（p1 p2 p3...随机数 → 学出特点）；2048 vs 8192 外推断层；长度外推问题标签 | 另一条路：位置向量不手工生成，全部设成可训练参数。p1、p2 一开始是随机数，模型每猜错一次，反向传播就调一次。p1 可能学会"句首的特点"，p100 学会"长文本中段的特点"。灵活，是优点。但代价很明确：训练只见过 2048 个位置，推理时突然给 8192 个 token——后面的位置向量，根本没学过。这叫长度外推问题。能不能把"相隔多远"，直接送进注意力？ |
| S5 | RoPE 旋转 Q/K | 向量箭头按位置旋转（0°→iθ→jθ）；R(θ) 旋转矩阵；j−i 相对距离推导（qᵢᵀR((j−i)θ)kⱼ）；间隔 1 相同 | 有——RoPE，旋转位置编码，2021 年苏剑林提出。思路很特别：不把位置加进向量，而是根据位置，旋转 Query 和 Key。位置 0 不转，位置 1 转一点，位置 2 再多转一点。旋转只改变方向，不改变长度。第 i 个 Query 转 iθ，第 j 个 Key 转 jθ——算相关性时，关键藏在括号里：j 减 i。两个词的相关性，只和相隔多远有关。第 3 个词看第 4 个，间隔 1；第 100 个看第 101 个，间隔也是 1。绝对位置参与计算，留下的是相对距离。 |
| S6 | 二维小实验 | q=(1,0) 箭头；旋转 60°/120° 变 (0.5,0.866)、(−0.5,0.866)；位置 1↔2 夹角 60°，位置 7↔8 夹角仍 60°；角度差携带距离 | 旋转到底改变了什么？做个二维小实验。取 q 等于 (1, 0)——位置 0 不转，指向 x 轴。位置 1 旋转 60 度，变成 (0.5, 0.866)。位置 2 再转 60 度，变成 (−0.5, 0.866)。位置 1 和 2 的夹角：60 度。换成位置 7 和 8，每步都转 60 度，夹角还是 60 度。相邻位置，有固定的相对旋转。那真实模型里，旋转速度由谁决定？ |
| S7 | 真实模型 θ 对比 | rope_theta 旋钮卡片；三个模型对比表（θ / max_position / 策略）；拧快 vs 拧慢取舍结论 | config.json 里的 rope_theta，就是那个旋钮。拆三个国产模型：DeepSeek-V4 Pro，2026 年 4 月发布，θ 是 10000——旋转最快，近处最清；远距离靠 YaRN 从 64K 插值到 1M。Qwen3-235B，θ 是 100 万，原生 32K。GLM-5.2 最狠，θ 拧到 800 万——旋转几乎停住，原生覆盖 1M。所以 θ 不是越大越好：拧快了，近处清、远处糊；拧慢了，看得远、近处靠训练补。回到最初的问题—— |
| S8 | 总结 + 品牌尾卡 | 词嵌入 vs 位置编码分工；五种方案回顾链（绝对→正弦→可学习→RoPE）；尾卡：avatar 圆角图 + 黄色「关注「数解AI」」+ 当期文章标题 + 「查看公众号文章」绿色引导 + 下一篇预告（Q/K/V 注意力） | 词嵌入告诉模型：这是猫，那是老鼠。位置编码告诉模型：猫排第 1，老鼠排第 3。正弦编码，用多频率记位置；可学习编码，让模型自己调；RoPE，旋转 Q 和 K，让注意力感知相对距离。所以位置编码不是贴座位号——它告诉注意力：词是谁很重要，词和词隔了多远，同样重要。关注数解AI，下一篇，拆开 Q、K、V，看注意力到底怎么算"该看谁"。 |

## 制作流程

1. 配音：`scripts/minimax_tts.py` 整段生成（tts.txt = 8 段合并）+ `--subtitle` 句子级时间戳 → `scripts/tts_split.py` 按时间戳切分 8 段（克隆音色 `branding/my-voice-denoised.wav`，speed 1.15 pitch +2，speech-2.8-turbo）
2. 动画：每段一个 Manim Scene（S1..S8），`construct` 末尾 `pad_to_voice()`；动画节点按台词时间轴铺满（≥80% 配音时长）
3. 构建：`scripts/manim_video_build.py` mux 配音 + 无缝拼接 + 黄色字幕烧录（MarginV=210, 75 号，整行 + 150ms 淡入）+ 品牌尾卡
4. 封面：Cover 场景单帧渲染（复用 RoPE 旋转箭头视觉）→ `<标题>-封面.png`（1080×1920）
5. 归档：`content/2026-07-17-位置编码/shipinhao/`
