## 🎯 驱动问题

前两篇我们知道了：梯度下降沿负梯度走一步就能降低误差（[梯度下降：蒙着眼下山](https://zhuanlan.zhihu.com/p/2063147154118644063)），交叉熵比MSE给的梯度信号更强（[损失函数：打分标准决定学习方向](https://zhuanlan.zhihu.com/p/2063150067784082359)）。

但一直有个问题被绕过了：**梯度到底怎么算？**

单层网络好办——手写求导就行。但一个5层的神经网络，第1层的参数想算梯度，得穿过后面4层。每层都有自己的权重和激活函数，梯度要一层一层"传"回去。

这就是反向传播要解决的问题：**误差信号从输出层往回传，经过每一层都被放大或缩小，最终告诉每个参数"你该调多少"。**

这篇我们用三层闭环讲透：先建立直觉，再拆链式法则的数学，最后用代码验证——让你看到误差是怎么一层层传回去的。

## 💡 直觉解释

想象一排人在拔河。

你站在最后面，前面有4个人，最前面的人握着绳子端头。对面突然猛拽了一下——这个拉力从绳头开始，一节一节传到你手上。

但传到你手上时，力已经不是原来的大小了。中间每个人都对力做了一件事：**有人握得紧，力传得多；有人手滑，力被吃掉了一截。**

你感受到的力 = 对面原始拉力 × 第1个人的传递系数 × 第2个人的传递系数 × …… × 你前面那个人的传递系数。

**这就是链式法则的全部直觉：每一层的梯度 = 上一层传来的误差信号 × 本层的偏导数。**

![](01-tug-of-war.png)

**① 力从哪里来？** → 输出层的误差（对面拽了一把）

**② 力怎么传？** → 一层一层乘（每个人传递时放大或缩小）

**③ 每个人只关心什么？** → 自己手上的力（传来的误差）× 自己的传递系数（偏导数）——不需要知道整条绳子的状态

第③点是反直觉的：**你不需要全局信息，只需要"传到我这里的力"和"我的手有多紧"**。这正是反向传播高效的原因——每个参数只需要局部信息就能算出自己的梯度。

> 💡 预告：这个直觉会变成链式法则的数学公式，然后用5行NumPy代码实现。

## 📐 数学原理

### 先回到单层

上一篇我们算过交叉熵对预测值 ŷ 的梯度：**∂L/∂ŷ = −1/ŷ**（y=1时）。

但 ŷ 不是网络的参数——**权重 w 和偏置 b 才是**。我们要的是 **∂L/∂w** 和 **∂L/∂b**，这样才能更新参数。

单层网络很简单：

> **ŷ = σ(w·x + b)**

σ 是 sigmoid。从 L 到 w 的梯度，要经过 ŷ → σ → w 三步。链式法则说：**把每一步的偏导数乘起来**。

> **∂L/∂w = (∂L/∂ŷ) × (∂ŷ/∂z) × (∂z/∂w)**

其中 z = w·x + b。

拆开看每一项：

| 步骤 | 偏导数 | 结果 |
|------|---------|------|
| L → ŷ | ∂L/∂ŷ | −1/ŷ |
| ŷ → z | ∂σ(z)/∂z | ŷ(1−ŷ) |
| z → w | ∂z/∂w | x |

乘起来：

> **∂L/∂w = (−1/ŷ) × ŷ(1−ŷ) × x = −(1−ŷ)·x**

当真实标签 y=1 时，**ŷ(1−ŷ)/ŷ = 1−ŷ**，所以更常见的写法是：

> **∂L/∂w = (ŷ − y)·x**

**看到了吗？sigmoid 的导数 ŷ(1−ŷ) 和交叉熵的 1/ŷ 刚好约掉了！** 这就是上一篇说的"链式法则的魔法"——交叉熵帮你在 sigmoid 那一层把阻力抵消了，力原封不动传过来。

![](02-chain-rule.png)

拔河的直觉：本来 sigmoid 这个人手滑（ŷ 接近 0 或 1 时 ŷ(1−ŷ)≈0，力传不过去），但交叉熵恰好补了等量的力（1/ŷ 在 ŷ 接近 0 时爆炸），两者一乘，净效果就是 **ŷ − y**——干净利落。

### 多层网络：链式法则的真正威力

单层只是热身。反向传播的真正价值在多层网络。

3层网络：x → h₁ → h₂ → ŷ → L

每一层都有自己的权重 W₁, W₂, W₃ 和激活函数。想算 **∂L/∂W₁**，误差信号要从 L 出发，穿过 ŷ → h₂ → h₁ → W₁，每一步乘一个偏导数：

> **∂L/∂W₁ = (∂L/∂ŷ) × (∂ŷ/∂h₂) × (∂h₂/∂h₁) × (∂h₁/∂W₁)**

拔河的直觉：4个人排一排，力从绳头传到最后。每个人传递时乘以自己的系数——系数大则放大，系数小则衰减。

**如果中间某个人手滑（偏导数≈0），力就传不到后面。** 这就是梯度消失——第1层几乎收不到误差信号，参数基本不更新，等于白学。

> 💡 梯度消失是深层网络训练的头号难题，本系列第5篇"残差连接"会讲怎么解决它——给绳子加一条捷径，力不用经过手滑的人就能传过去。

### 链式法则的通用规则

把直觉翻译成通用规则：

**前向传播**（从输入到输出）：每一层算出自己的输出，**存起来**——反向传播时要用。

**反向传播**（从输出到输入）：每一层拿到"传来的误差信号"δ，算两件事：

1. **本层参数的梯度**：∂L/∂W = δ × 本层输入
2. **传给前一层的误差信号**：δ_prev = δ × Wᵀ × ∂σ/∂z

就这么简单。每一层只需要三样东西：传来的 δ、本层的权重 W、本层激活函数的偏导数 ∂σ/∂z。**不需要知道其他层在干什么。**

## 🔧 算法实现

用一个2层网络手动实现反向传播，看误差信号怎么一层层传回去。

```python
import numpy as np

# ── 激活函数和它的导数 ──
def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def sigmoid_grad(a):
    # a = sigmoid(z)，导数 = a(1-a)
    return a * (1 - a)

# ── 前向传播（边算边存） ──
def forward(x, W1, b1, W2, b2):
    z1 = x @ W1 + b1       # 第1层线性变换
    a1 = sigmoid(z1)       # 第1层激活
    z2 = a1 @ W2 + b2      # 第2层线性变换
    a2 = sigmoid(z2)       # 第2层激活 = 预测值
    return z1, a1, z2, a2  # 全部存下来

# ── 反向传播（误差从后往前传） ──
def backward(x, y, a1, a2, W2):
    m = len(y)  # 样本数

    # 输出层：交叉熵 + sigmoid 的简化梯度
    delta2 = a2 - y                  # (ŷ - y)，链式法则的魔法

    # 第2层参数的梯度
    dW2 = a1.T @ delta2 / m         # 传来的力 × 本层输入
    db2 = np.mean(delta2, axis=0)   # 偏置梯度

    # 传给第1层的误差信号
    delta1 = (delta2 @ W2.T) * sigmoid_grad(a1)  # 力继续往前传

    # 第1层参数的梯度
    dW1 = x.T @ delta1 / m
    db1 = np.mean(delta1, axis=0)

    return dW1, db1, dW2, db2, delta1, delta2
```

**关键行解读**：

| 代码 | 拔河直觉 | 数学含义 |
|------|---------|---------|
| `delta2 = a2 - y` | 对面拽了一把，力直接传到绳头 | 交叉熵+sigmoid的简化梯度 |
| `dW2 = a1.T @ delta2 / m` | 第2个人感受到的力 × 他手里的绳 | 第2层参数梯度（除以样本数） |
| `delta1 = (delta2 @ W2.T) * sigmoid_grad(a1)` | 力经过第2个人传到第1个人 | 链式法则：上一层δ × 权重 × 激活导数 |
| `dW1 = x.T @ delta1` | 第1个人感受到的力 × 他手里的绳 | 第1层参数梯度 |

**注意 `delta1` 那行**——力的传递路径：`delta2`（第2层传来的力）× `W2.T`（第2层权重的转置，决定力怎么分配）× `sigmoid_grad(a1)`（第1层激活函数的导数，决定力被放大还是吃掉）。**三个因子相乘，就是链式法则。**

## 🧪 实测：误差信号在两层之间怎么变化？

同样的二分类数据，我们追踪 `delta2` 和 `delta1` 的大小，看力在传播过程中被放大还是吃掉。

```python
# ── 训练循环，同时记录每层的误差信号 ──
np.random.seed(42)
x = np.random.randn(100, 4)
y = (x[:, 0] + x[:, 1] > 0).astype(float).reshape(-1, 1)

W1 = np.random.randn(4, 8) * 0.5
b1 = np.zeros((1, 8))
W2 = np.random.randn(8, 1) * 0.5
b2 = np.zeros((1, 1))

lr = 0.1
for step in range(300):
    z1, a1, z2, a2 = forward(x, W1, b1, W2, b2)
    dW1, db1, dW2, db2, delta1, delta2 = backward(x, y, a1, a2, W2)

    if step % 50 == 0:
        d2_avg = np.mean(np.abs(delta2))
        d1_avg = np.mean(np.abs(delta1))
        print(f"Step {step:3d} | δ2={d2_avg:.4f} | δ1={d1_avg:.4f} | ratio={d1_avg/d2_avg:.2f}")

    W1 -= lr * dW1; b1 -= lr * db1
    W2 -= lr * dW2; b2 -= lr * db2
```

输出：

```
Step   0 | δ2=0.5092 | δ1=0.0474 | ratio=0.09
Step  50 | δ2=0.4522 | δ1=0.0461 | ratio=0.10
Step 100 | δ2=0.4021 | δ1=0.0471 | ratio=0.12
Step 150 | δ2=0.3505 | δ1=0.0475 | ratio=0.14
Step 200 | δ2=0.3025 | δ1=0.0469 | ratio=0.16
Step 250 | δ2=0.2617 | δ1=0.0456 | ratio=0.17
```

**关键发现**：δ1 始终只有 δ2 的 9%∼17%。**力传了一层，就被吃掉了超过 8 成。**

![](03-gradient-vanishing.png)

为什么比 sigmoid 导数的理论最大值 0.25 还低？因为力的衰减来自两个因子相乘：权重 W₂ 的传递（初始化为 randn×0.5，平均缩放约 0.5）× sigmoid 导数（最大 0.25）。0.5 × 0.25 ≈ 0.125，和实测的 0.09∼0.17 吻合。

**sigmoid 导数是力衰减的硬上限**——无论权重多大，经过 sigmoid 这道门，力最多只能传过去 1/4。如果权重也小，衰减就更严重。

**如果网络有5层呢？** 0.25⁴ ≈ 0.004——第1层收到的误差信号只有输出层的 0.4%，基本等于没有。**这就是梯度消失。**

### ReLU：让力无损通过的门

sigmoid 梯度消失的根源是它的导数 ŷ(1−ŷ) 最大才 0.25——每经过一层，力至少被吃掉 3/4。

**ReLU 的导数不一样**：

| 输入 | ReLU 输出 | 导数 |
|------|-----------|------|
| z > 0 | z | **1** |
| z ≤ 0 | 0 | 0 |

z > 0 时导数恒为 1——**力经过 ReLU 这道门，不被放大也不被缩小，原封不动传过去**。

拔河的直觉：sigmoid 是手滑的人（最多传 25% 的力），ReLU 是握得死紧的人（要么传 100%，要么完全不传）。你宁愿队友有时不传力，也不要他每次都吃掉 3/4 的力——因为不传的时候，至少不会让整条链路指数衰减。

**但 ReLU 也有自己的问题**：z ≤ 0 时导数为 0，对应的神经元完全不更新。如果某个神经元对**所有训练样本**都输出 ≤ 0，它就永远不会被激活——这就是 **ReLU 死亡问题**（dying ReLU）。

直觉：握得太紧也有代价——如果一个人一直不传力（导数为 0），那他手里的那段绳子就废了，前面的力永远到不了后面。

**解决方案**：Leaky ReLU 给 z ≤ 0 一个很小的斜率（如 0.01），让力至少能传一点点过去，避免神经元彻底死亡。

### 对比实验：sigmoid vs ReLU

同样的 2 层网络，把隐藏层的激活函数从 sigmoid 换成 ReLU，看误差信号的传递比例：

```python
def relu(z):
    return np.maximum(0, z)

def relu_grad(z):
    return (z > 0).astype(float)  # z>0 导数为1，否则为0

def forward_relu(x, W1, b1, W2, b2):
    z1 = x @ W1 + b1
    a1 = relu(z1)           # 隐藏层用 ReLU
    z2 = a1 @ W2 + b2
    a2 = sigmoid(z2)        # 输出层仍用 sigmoid
    return z1, a1, z2, a2

def backward_relu(x, y, z1, a1, a2, W2):
    m = len(y)
    delta2 = a2 - y
    dW2 = a1.T @ delta2 / m
    db2 = np.mean(delta2, axis=0)
    delta1 = (delta2 @ W2.T) * relu_grad(z1)  # ReLU 导数
    dW1 = x.T @ delta1 / m
    db1 = np.mean(delta1, axis=0)
    return dW1, db1, dW2, db2, delta1, delta2
```

同样的数据和初始化，跑 300 步：

```
Step   0 | δ2=0.5247 | δ1=0.1216 | ratio=0.23
Step  50 | δ2=0.3003 | δ1=0.0868 | ratio=0.29
Step 100 | δ2=0.1746 | δ1=0.0731 | ratio=0.42
Step 150 | δ2=0.1168 | δ1=0.0628 | ratio=0.54
Step 200 | δ2=0.0890 | δ1=0.0542 | ratio=0.61
Step 250 | δ2=0.0738 | δ1=0.0496 | ratio=0.67
```

**对比 sigmoid 的 9%∼17%，ReLU 的传递比例是 23%∼67%——力传过去的多得多。**

为什么不是 100%？因为 z₁ ≤ 0 的那些神经元导数为 0，不传力。这个网络中大约 51%∼57% 的神经元处于激活状态（z > 0），其余的完全不传力。但激活的部分导数恒为 1，力无损通过——不像 sigmoid 即使激活也最多只传 25%。

注意一个细节：ReLU 的 δ2 下降得更快（0.52 → 0.07，sigmoid 是 0.51 → 0.26），说明 ReLU 网络学得更快。但 δ1 的绝对值反而比 sigmoid 更低——这是因为 ReLU 输出值域是 [0, +∞)，不像 sigmoid 压在 [0,1]，权重会自适应地调大，导致传回隐藏层的力被权重分配稀释。**关键是比例（ratio），不是绝对值**。

**5 层网络的对比**：

- sigmoid：0.25⁴ ≈ 0.4% 传到第 1 层
- ReLU：假设每层约 55% 的神经元活跃 → 0.55⁴ ≈ 9% 传到第 1 层

**9% vs 0.4%——差了 20 多倍。** 网络越深，差距越大。这就是为什么现代深度网络不再用 sigmoid 做隐藏层激活函数。

不过，实际产品里用的也不完全是原始 ReLU——而是它的变体 **SwiGLU**。SwiGLU = SiLU（也叫 Swish，x·σ(x)）配合门控结构，导数在 z > 0 时接近 1，保留了 ReLU 不吃力的优点，同时因为 SiLU 在 z = 0 附近有平滑过渡，不会像 ReLU 那样突然「死亡」。目前主流大语言模型的 MLP 层几乎都用 SwiGLU：

| 模型 | 激活函数 | 来源 |
|------|---------|------|
| DeepSeek-V4 | SwiGLU (SiLU) | config.json: `hidden_act: "silu"` |
| GLM-5.2 | SwiGLU (SiLU) | config.json: `hidden_act: "silu"` |
| Kimi K2.6 | SwiGLU (SiLU) | config.json: `hidden_act: "silu"` |

**核心逻辑不变**：这些变体的导数在 z > 0 时都接近 1，力能传过去——只是比 ReLU 多了一点平滑，让训练更稳定。

> 💡 第5篇「残差连接」会讲另一种解决梯度消失的方法：给绳子加捷径，让力不用经过中间的人就能直达。残差连接 + SwiGLU 是现代深度网络的标配组合。

## 🔄 回扣原理

回到开头的问题：**多层网络的梯度怎么算？**

链式法则给出了答案：**把每一步的偏导数乘起来，误差信号从后往前一层层传。** 每个参数只需要"传到我这里的力"和"我的偏导数"就能算出自己的梯度——不需要全局信息。

但链式法则也暴露了一个问题：**如果中间某一层的导数很小，误差信号就传不到前面的层。** sigmoid 的导数最大才 0.25，加上权重的衰减，每经过一层力就缩水 80% 以上——这就是梯度消失。交叉熵 + sigmoid 在输出层帮我们省掉了 sigmoid 的导数（力原封不动传过来），但内部层的 sigmoid 照样吃力。

上一篇的承诺兑现了：**交叉熵 + sigmoid 的梯度等于 ŷ − y**，因为 1/ŷ 和 ŷ(1−ŷ) 约掉了——交叉熵帮你把最关键的那层阻力抵消了。但这个魔法只发生在输出层，内部层的 sigmoid 仍然是梯度杀手。

**反向传播的精髓不是"反向"，而是"链式"——每一层只做局部乘法，全局梯度自然涌现。选对激活函数（ReLU 及其变体替代 sigmoid），是让这条链路真正传得动的关键。**

---

## 📌 一句话总结

反向传播的核心是链式法则，误差像拔河的拉力从输出层往回传，每层乘以偏导数；交叉熵+sigmoid的梯度约化为ŷ−y是链式法则的魔法，但内部层sigmoid的导数最大0.25是梯度消失的根源；ReLU导数恒为1（z>0时），传力比例远高于sigmoid，是深层网络的标准选择。
