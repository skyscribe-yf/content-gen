## 一、定位

- 读者：用过 coding agent / 调过 API、**默认「读思维链」是监控手段**的工程师；不一定听过 latent reasoning，但一定见过「隐藏思考」和「思考计费」
- 认知目标：把「隐藏思维链」和「latent reasoning」这两个被混为一谈的东西，换成一条**八档可见性光谱**；并知道 2026 年它们正在合流——而合流的证据（塞废话涨点）有明确的边界
- 不是：四条技术路线的论文综述（路线在光谱里各就各位，不当主菜）、监控替代方案清单（L3 的事）、厂商计费细账（L2 的事）
- 轨道：文章轨（反常识数字钩子 + 亲历开场 + 悬念链 + 论文数字验证 + 回扣开头）
- 基调：**先信，带限定**——13 模型数字立论，同段写明「论文口径、无第三方复现」；负面结果（训练放大不了）必须同段进稿，不停在「隐藏里有 latent 成分」

## 二、核心结论

**一句话**：给 13 个前沿模型塞一串「1、2、3……」的废话 token，Gemini 3 Flash 的多步算术从 51.0 涨到 61.7——这说明**「隐藏思维链」里本来就有 latent 计算的成分**；而同一篇论文的负面结果说明你训练不了它。思维链的可见性是一条八档光谱，「不给你看」和「根本没有」是两种完全不同的东西，2026 年它们正在合流。

**三层**：

1. **光谱 ①–⑧**：显式可见 CoT → 摘要式 → 完全隐藏 → 哑 token → 抽象 token → 连续 latent thought → 循环/隐藏计算 → neuralese。③ 是显示策略（token 照常生成，只是不返回）；④–⑦ 是计算机制（没有思维链 token，计算在隐状态/循环里）。
2. **「不给你看」不省钱反而加价**：隐藏思维链的 token 照常生成、照常按输出计费——四家现役输出单价全是输入的 3–5 倍（OpenAI/Anthropic 5×，DeepSeek 3–4×，2026-11-17 核）。Gemini 定价表原文「Output price (including thinking tokens)」是一手确认。
3. **合流有证据也有边界**：invisible reasoning 证明 ③ 类模型已在做 ④ 类的事（13 模型 filler 涨点）；但 RL/SFT 放大不了这个收益（Qwen3-235B 零涨点，「neither RL nor SFT produces a filler token benefit that persists at test time」原话）。**成分本来就有，训练捏不出来。**

**落点（读者能带走的一问）**：如果你的工作流靠「读思维链」判断 agent 有没有跑偏——这件事在光谱的哪一档开始失效？

## 五、结构（6 节，正文约 2000 字）

### 1. 塞 100 个废话 token，算术涨了 10.7 分（约 260 字，原声槽 1+2）
- 功能：反常识钩子 + 立 stakes（读思维链定位跑偏是我的工作流）
- 要点：13 模型 × 3 合成任务（4 位乘法/多步算术/代码变量计数）、10-shot、filler = 计数 token「1–100」、Δ 相对无 filler 基线；Gemini 3 Flash 算术 51.0→61.7（+10.7pp）为主数字；乘法 +1.0 不显著；Opus 4.6* 算术 +30.0 有选择效应（API 不支持 assistant prefilling），**禁当主数字**；论文自报、无第三方复现，限定同段写明
- 转折句：先别问这有没有用——它照出来的是：**「思考」这件事，本来就可以不落在 token 上**
- 配图：无（数字留给正文，概念图不承载数字）

### 2. 同一件事，八个刻度（约 300 字，新术语 0 个，配图 01）
- 功能：全文骨架，一次给全光谱
- 光谱（vault §10.2，每档一句人话判据：给不给你看 / 有没有 token / 谁付钱）：
  - ① 显式可见 CoT——DeepSeek V4 thinking（全量流式可见，vault 口径，行文带限定）
  - ② 摘要式 CoT——GPT-6.1 Sol / Claude 默认
  - ③ 完全隐藏 CoT——token 存在，用户不可见，厂商可读
  - ④ 哑 token 推理——pause/filler tokens
  - ⑤ 抽象 token 语言——Abstract-CoT（过渡带）
  - ⑥ 连续 latent thought——Coconut / CODI（无 token，向量）
  - ⑦ 循环/隐藏计算——Ouro、Astra recurrent depth、Hidden Decoding
  - ⑧ neuralese——模型完全在私有稠密表示里思考（概念下限，非已有技术，必须标注）
- 判据（原声槽 3）：作者对「可见性/成本/速度」的排序

### 3. 「不给你看」是显示策略，而且不省钱（约 300 字）
- 功能：把 ③ 这一档钉死——最常见的误解在这里
- 要点：隐藏思维链的 token 照常逐 token 生成、占上下文、每 token 一次前向，只是 API 不返回；o1 发布时官方原话可引（「综合权衡用户体验、竞争优势、保留 chain-of-thought 监控的选项之后，我们决定不向用户展示原始思维链」）；四家现役输出单价全是输入 3–5 倍（OpenAI/Anthropic 5×、DeepSeek 3–4×，2026-11-17 核，检索日刊例）；Gemini 定价表「Output price (including thinking tokens)」一手确认 thinking 按输出计费
- 关键判断句：**隐藏思维链在商业上是加价项，不是省钱项**——它买的是「不给你看」，不是「更便宜」
- 原声槽 4：我为隐藏思维链付过的钱/意识到计费的时刻
- 内链：《上下文压缩省了 77% token，为什么账单反而更贵？》（10-27，`https://mp.weixin.qq.com/s/p-2YkAFT6sBwdU5_dw5O2g`）——同一笔账的另一半

### 4. 「根本没有」是计算机制：四条路线各就各位（约 350 字，配图 02）
- 功能：④–⑦ 四档用四条路线填实，每条一段（arXiv + 一句人话 + 一个数）
  - A. Pause / Filler tokens（2310.02226 / 2404.15758）：零成本试水，天花板低——Pfau 的 filler '......' 解两道算法任务，需密集监督
  - B. Coconut / CODI（2412.06769 / 2502.21074）：最纯 latent——连续向量当思考；CODI 在 GPT-2 规模 GSM8k 追平显式 CoT、3.1× 压缩；训练最重、推理串行
  - C. WeLM Hidden Decoding（2607.08186，47 作者）：工程最干净、唯一验证到前沿规模（80B/617B，n=4，九基准自报全涨）；**国产唯一前沿规模玩家，官方博客定位研究、未确认上线微信产品线**
  - D. Ouro looped（2502.05171 / 2510.25741，33 作者）：参数效率最高——7.7T token 预训练，同一组权重反复用 T 次；项目页原话「gains come from better knowledge manipulation, not more knowledge storage」
- 原声槽 5：四条路线里我最信哪条/觉得谁被高估
- 配图：02 四条路线在光谱上的就位图（AI 概念图，无数字）
- ⚠️ Ouro「1.4B≈Qwen3-4B」禁入本篇（MMLU 67.3 < 73.2，特定任务口径，留给 L4 拆解）

### 5. 成分本来就有，但训练捏不出来（约 250 字）
