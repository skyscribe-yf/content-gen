## 一、定位

- 读者：写过代码、被 coding agent 坑过、正在（或打算）让 agent 自己出题 / 自己跑测试自己判分的工程师
- 认知目标：把「自我迭代崩了 = 奖励没调好」换成「自我迭代稳不稳，先看**哪些题有资格进训练池**」；并知道给模型看更多标准答案不一定是好事

- 轨道：文章轨（反直觉疑问句标题 + 亲历钩子 + 悬念链 + 可操作落点）
- 基调：先立后破——篇1 留的乐观（只剩一个验证器）被本篇拆成两把杠杆，且指出命门在更上游

## 二、核心结论

**一句话**：同一套奖励信号，加一个「两次跑不出同样结果就不许进池」的过滤器，分数从 0.002 回到 0.71；反过来，出题器能看见标准答案、却配一个自己跟自己对答案的判分器时，它会**崩得更快**。

**三层**：
1. 自我对弈稳定与否由两把杠杆决定：**门控**（哪些题有资格进训练池）与**接地**（进池后用真值还是自洽信号打分）。两者不对称：门控严格就稳，没有门控时**任何奖励都救不回来**。
2. 反直觉的耦合：**出题器能看见真值，配上自洽判分，反而加速崩塌**（Grounded Proposer Paradox）——它把训练集中在干净、语义清晰的题上，而那正是通往「自洽但错」吸引子的最省力通道。
3. 崩塌不是悬崖式的：泄漏率 ε 有**两阶段相变**——训练侧在 ε≈0.05 就解耦，验证侧要到 ε=0.40 才现形，混合指标甚至骗到 0.70。你能看到「训练不错」的同时，域内已经崩了。

**落点（读者能带走的两问）**：① 你的题池准入是「跑通了就算」还是「两次跑出同样结果才算」？② 你的判分信号，能不能在输出模糊的地方拿到高分？

## 五、结构（7 节，正文约 2000 字）

小标题连起来必须是一条完整故事链：我以为是判分 → 论文说有两把杠杆 → 关掉门控会怎样 → 坏数据为什么被奖励喂饱 → 给标准答案反而更快崩 → 泄漏多少才崩（相变）→ 严格门控不亏 → 回到你的 agent。

### 1. 我以为是判分不准（约 200 字，原声槽 1）
- 功能：亲历钩子，建立「我见过」，把读者的默认归因写在开头
- 要点：agent 自评 / 自测分数好看，但方向错了；我第一反应是「它的判分不可靠」
- 转折句：论文说，判分只是第二把杠杆

### 2. 两把杠杆：进池的资格，和进池后的打分（约 280 字）
- 功能：把术语钉死，全文唯一的两个新术语
- 要点：自我对弈的三件套（出题器 proposer / 解题器 solver / 执行器验证）；**门控** = 哪些题允许进训练池；**接地** = 进池的题用什么信号更新
- 关键细节（决定可操作性）：论文的门控不是「判难易、判质量」，只要求**同一段程序跑两遍输出一致**——不确定、要报错的，一律不许进池
- 人话类比：不是挑好题，是**挑稳题**

### 3. 关掉过滤器：0.71 掉到 0.002（约 300 字）
- 功能：主证据
- 设定一句话：Qwen3-4B-Base、GRPO、8×A100 单节点、7 组配置 × 2 个任务（Python 输出预测 + 15 算子确定性 DSL 双胞胎）
- 数字：coding 域门控开 0.71 / 0.67 / 0.67（三种奖励组合都稳）；门控关 0.002 / 0.006 / 0.002——**连有真值的 grounded 奖励也崩**
- 一句话结论：没有任何一种奖励能在没有门控时救回来；门控单独就够
- 配图：论文 Figure 2（门控开/关的训练曲线）

### 4. 坏数据不是被降权，是被奖励喂饱（约 260 字）
- 功能：机制，全文数学点（也是读者最容易「啊」的一处）
- 公式：自洽奖励 $R^{i}_S(a^{(i)}) = \frac{1}{n}\sum_{j=1}^{n}\mathbb{1}[\kappa(a^{(j)})=\kappa(a^{(i)})]$，$n=16$，取值 $1/n \sim 1$
- 要点：模糊题（浮点、集合顺序、副作用）上组内最容易「一致」；一致 = 高分 → **坏数据的奖励比干净数据更高**
- 反直觉句：优化器不会自动给坏样本降权，它被坏样本喂饱
- 配图：自绘脚本图（干净题 vs 模糊题的奖励分布对照，示意 k/n）

### 5. 给标准答案，反而崩得更快（约 300 字）
- 功能：全文最强反常识（标题兑现处）
- 现象：出题器能看真值 → 输出集中在干净、语义清晰的题 → 自洽判分在这些题上最快达成伪共识
- 数字：GI+off 0.002 vs II+off 0.007（终点几乎一样，差别在**轨迹斜率**：更少步数到吸引子）；门控一开（GI+exec 0.67）悖论消失
- 边界（必须写）：悖论要求自洽判分；出题器只是**加速一条本来就会走的路**，不是起因
- 一句话：给模型更多标准答案，配上错的判分，等于给它修了一条更快的高速路

### 6. 泄漏 5% 就开始坏，20% 才看得出来（约 300 字）
- 功能：相变，把「我怎么知道自己在崩」讲成可观测
- ε 定义：执行失败的题被放进池的概率（$\varepsilon$，0~1）
- 两阶段数字：ε=0.05 时训练侧 gap 0.16→0.44，验证几乎不动（0.674→0.668）；ε=0.20→0.40 域内 0.651→**0.004**；混合指标到 0.70 才跌破基线（0.305 vs 0.316）
- 旁证：静态任务下「验证器 15% 标签噪声」还能恢复大部分（Plesner et al. 2026），但**闭环里 20~40% 就崩**——循环会放大噪声（Youden 指数 $J=1-\varepsilon$，静态判据给不出这个更早的阈值）
- 补一刀：前 150 步严格、之后放 0.05，也救不回（step 450 0.420 vs 0.674）——**崩了就是不可逆**
- 配图：论文 Figure 4（ε 相变）

### 7. 严格门控不亏：只有不到 1% 的题进得了池（约 220 字）
- 功能：堵住「放宽点能换多样性」的幻想
- 数字：ε=0 时末期题池准入率 ≈0.007；三阶段（1–160 步靠新题学，160–440 步靠回放，之后停滞）；ε=0 在两个验证视角都是最好（0.619 / 0.674）
- 结论句：想扩题池，靠课程设计或外部出题，别靠放松准入

### 8. 回到你的 agent：两个问题（约 180 字 + 原声槽 8）
- 一是准入：跑两遍结果一样吗？（不确定的别进池）
- 二是接地：你的判分信号在输出模糊处是不是更容易拿高分？
- 结尾互动问（原声槽 8）
- 关注引导 + 尾部惯例（热门文章 / 参考资料 / 标签）
