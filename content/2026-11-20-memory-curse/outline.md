## 结论（交付句）

**记忆不是中性存储，是主动行为调制器——诅咒不是「记性太好」，是滤镜沾满旧账后，agent 每一轮都看见带前科的对手。** 机制：论文里扩记忆不升偏执（偏执词频率各 HL 基本不变），塌的是合作词（GPT-OSS-20B −57%）与前瞻意图（前瞻比率 immune 0.504 vs cursed 0.340）；更狠的是 10 月后续论文 CoopShift——SFT/对齐不仅治不了，还放大它（7 lineages 里 6 个降幅超 Base）。

## 结构（叙事弧线，小标题=悬念链；开头的问题结尾必须被回答）

**开头（~150 字，行业冲突钩子，零系列导航）**：2026 年 10 月下旬，两篇论文不约而同开审 agent 记忆——上交独作的 MemoryTax 把话说得很难听，「agent 记忆是给弱模型打的昂贵补丁」，Mem0 只在 GPT-4o-mini 上赢过完整上下文；The Value of Memory 更学究，把记忆价值折算成「避免的任务损失」，3,075 个问题给记忆第一次记了账。都在问：设计过的记忆还有没有价值？紧接着砸钩子：5 月有篇论文给出更狠答案——记忆不止可能没价值，还主动破坏合作：同一个 Llama-3.3-70B，信任博弈里给它 80 轮记忆，合作率从 100% 掉到 6.9%。−93.1pp 从哪来？

### S1 论文设定：四个博弈，一条滑窗（~250 字）
- 论文身份一句：*The Memory Curse*（arXiv:2605.08060，2026-05-08，CMU/密歇根/哈佛 Conitzer 组，双盲审稿中）；7 模型 × 4 竞争性社会困境 = 28 settings；agent 自博弈 500 轮、温度 0.7、3 seeds、378,000+ 轨迹
- 人话解释博弈：囚徒困境（各自最优选背叛，双输）与信任博弈（先手把筹码交出去，全凭对手还不还）各一句
- HL 设定：记忆 = 最近 HL 条历史记录的扁平滑窗，HL 从 2 拉到 80
- 吐槽槽靶子：每轮只有一个二元动作（~12 token），HL=80 全部历史也才 ~2,660 token——128K 窗口的 2.1%

### S2 诅咒现场：28 个设置，18 个中招（~350 字）
- 承重数字：18/28 中招；GPT-OSS-120B 在囚徒困境全 HL 100% 免疫，信任博弈却从 92.7%（HL=2）崩到 7.3%（HL=80）
- 免疫组 vs 中招组的分野：前瞻比率 0.504 vs 0.340（HL=80）
- 曲线讲法：诅咒随 HL 增长——长记忆不是线性变差，是过了某个点信任崩塌（配图 1 诅咒曲线）
- 一句自含分工：这不是「模型不行」，7 个模型里强的弱的都有中招的

### S3 机制：不是变偏执，是不敢先伸手（~350 字）
- 反常识核心：偏执词绝对频率各 HL 基本不变（不是「变得疑神疑鬼」），塌的是合作词——GPT-OSS-20B 合作词 −57%
- 论文原话口径：eroding forward-looking intent rather than rising paranoia——毁掉的是「先伸出手」的意愿
- 滤镜比喻承载：记忆是滤镜，决定 agent 每轮看见什么世界；诅咒 = 滤镜沾满旧账，每个对手都带前科出场（配图 3 滤镜概念图）
- 信任博弈场景落地：先手方看着历史里越来越多的「没还」，越来越不敢交筹码

### S4 论文也试了救：净化与微调（~200 字，压半节）
- 记忆净化（内容非长度）：信任博弈 HL=80 固定，80−X 轮换合成合作记录，X=2 时强模型恢复 87–97%（Llama-3.3-70B 97.4%）——决定伤害的是记忆里「有什么」，不是「有多少」
- 前瞻性微调（干预证据）：1,751 条轨迹 LoRA 微调 Mistral-7B，不过滤动作标签，98% 前瞻轨迹以合作结束；通用能力 Table 15：GSM8K +2.43 / TriviaQA −0.71 / HumanEval −0.61 / MBPP −0.40
- 吐槽槽靶子：1,751 条轨迹、单个 7B 模型、循环因果未除——「可上线」三个字论文自己都没说

### S5 断裂：论文的滑窗，不是你的记忆（~400 字，差异化主场）
- 作者独有角度：HL 是扁平滑窗，混淆了工作记忆的窗口大小与长期记忆的容量（逐字短引候选①，需作者认领）
- 五维断裂一笔带过：真实 agent 记忆是检索/摘要/反思三道工序，诅咒更可能长在检索偏差、摘要偏差、反思方向偏差上（逐字短引候选③）
- 口径纪律（grill 拍板）：HL 曲线可引，「HL=5~10 最优窗口」的值断不可搬进真实 agent
- 落点：论文推翻的是「更多记忆=更好 Agent」的直觉（短引候选④），但它测的是滑窗里的诅咒；你的 agent 中的诅咒得另外审

### 结尾（~200 字，CoopShift 升级一刀 + 保险句式）
- 回扣开头「−93.1pp 从哪来」：来自 5 月这篇论文的信任博弈表格；而 10 月的后续更扎心
- CoopShift（arXiv:2610.24086，2026-10-16，同一作）：post-training 放大诅咒——7 lineages × 7 dilemmas，post-trained 各阶段降幅超 Base 的 6/7，放大主要来自 SFT。你没法靠「不训它」躲开
- 保险一句：论文只覆盖竞争性社会困境 + 自博弈，协作任务是否成立是作者自认盲点
- 反问收：你的 agent 记忆库里，有几笔旧账？
