上一篇《Q-learning是什么？没有转移表怎么解》结尾写过一句：

> 还有一条路根本不经过 $P$，直接改策略 $\pi$。

那条路今天走。

上篇那个 $\delta$，你先别急着乘。它上篇改账本。今天它会改职业。但得先把另一件事说清楚：不记账本，直接拧概率，这件事合法吗？

![上篇那张纸条先搁着，手去拧概率旋钮](01-dont-multiply-yet.png)

coding agent 还停在老地方。改完一处，下一步是跑测试，还是再改一处。

上篇问：跑测试值多少？账本改一笔。

今天换个问题：下次再走到这儿，跑测试的概率该升，还是该降？

这是「强化学习原理」系列第四篇。

## 一、今天不问账本，问概率

先把场景钉死。状态叫 $s_0$：刚改完一处，测试还没跑。

两个动作：跑测试，再改一处。

它现在的习惯不是最优，是它眼下的脾气。七成会去跑测试，三成会再改一处。

$$\pi(\text{跑测试}\mid s_0)=0.70,\qquad \pi(\text{再改}\mid s_0)=0.30$$

$\pi$ 你已经见过。第一篇就说了：策略是「在这个状态下，选哪个动作」的习惯。

今天多一件事。这个习惯带着旋钮。

拧旋钮，两个概率会变。七成可以变成六成，也可以变成八成。世界怎么变，你拧不动。你自己的习惯，可以拧。

新出场两个符号，都挂在修 bug 上：

| 记号 | 人话 |
|------|------|
| $\pi_\theta$ | 带旋钮的策略。还是那张「在 $s$ 选 $a$ 的概率表」，但表里的数由旋钮决定。 |
| $\theta$ | 旋钮本身。一个参数。拧它，跑测试的概率就动。 |

$\theta$ 读作 theta。别把它想成什么高深对象。就是一个数。

为了手算省事，这篇只用一个旋钮。它专门管「跑测试」的概率。另一个动作吃剩下的。

旋钮和概率之间，还隔着一层压扁。旋钮可以拧到很大，也可以拧到很小。概率必须停在 0 和 1 之间，两个动作加起来还得是 1。

所以不直接把 $\theta$ 当成概率。先过一道关：

$$\pi_\theta(\text{跑测试}\mid s_0)=\sigma(\theta)=\frac{1}{1+e^{-\theta}}$$

$\sigma$ 是 sigmoid。你在深度学习里见过：一个数进来，被压到 0 和 1 之间。概率正好落在这段。

$\theta=0$ 的时候，两边五五开。$\theta$ 往大拧，跑测试抬头。往小拧，跑测试低头。

$\theta=\ln(0.70/0.30)\approx 0.847$ 的时候，$\pi=0.70$。待会手算，就从这儿拧。

你暂时不用记住公式长什么样。你记住一件事：$\theta$ 动一格，$\pi$ 跟着动一格。方向相同，幅度被压过。

$V$、$Q$、$\delta$ 先搁着。它们上篇刚当完主角。今天前半场请它们靠边。

我第一次看到「直接改策略」，反应很土：那不就是拍脑袋调概率？绿了就加一点，红了就减一点？

后来才知道，拍脑袋那一下，背后有一条能求导的路。

## 二、乘回去为什么合法

先问目标是什么。

你拧旋钮，不是为了让跑测试的概率好看。是为了让以后拿到的回报，平均下来变大。

这个平均值写成：

$$J(\theta)=\mathbb{E}[G]$$

$J$ 就是目标。期望回报。$G$ 你在第一篇见过：从现在走到终局，折扣加起来的总账。

这里 $G$ 先当一个更朴素的角色：走完一条路，手里攥着的分数。绿了是 $+1$，红了是 $0$。

目标清楚了。你想让 $J$ 变大。深度学习里让损失变小，靠的是梯度下降。这里让回报变大，靠的是梯度上升。

差一个符号。思路一样：算出 $J$ 对 $\theta$ 的导数，顺着它拧。

问题来了。$J$ 里没有一张写着 $P$ 的表，也没有一个现成的 $V$。它是「按现在这套习惯走很多条路，分数的平均」。

平均里藏着 $\pi_\theta$。因为每条路会不会被走出来，跟你当时的概率有关。

你可以把平均想成两堆筹码。七成的路是跑测试。三成的路是再改。每堆上面搁着那条路的分数。$J$ 就是两堆的加权平均。

拧旋钮，堆的大小会变。跑测试那堆变厚，再改那堆变薄。平均分跟着变。这就是 $J$ 对 $\theta$ 的导数在问的事：堆怎么挪，平均分往哪边走。

所以求导时，一定会碰到 $\pi_\theta$ 对 $\theta$ 求导。

对概率求导，手感很差。概率要加起来等于 1，还得夹在 0 和 1 之间。直接拧 $\pi$，一不小心就拧出界。

有一刀，专门砍这个别扭。

$$\nabla_\theta \pi_\theta = \pi_\theta\,\nabla_\theta\log\pi_\theta$$

左边是「概率怎么随旋钮变」。右边换成「$\log\pi$ 怎么随旋钮变」，再乘回概率自己。

为什么能换？因为 $\log$ 的导数是 $1/x$。

$$\nabla_\theta\log\pi_\theta=\frac{1}{\pi_\theta}\nabla_\theta\pi_\theta$$

两边乘 $\pi_\theta$，就是上面那一刀。小学数学。

这一刀叫对数导数。Sutton 和 Barto 的书第 13 章，策略梯度就是从这儿起笔。上篇 TD 用的是第 6 章。同一本书，往后翻。

换完之后，目标的梯度长这样：

$$\nabla_\theta J(\theta)=\mathbb{E}\big[G_t\,\nabla_\theta\log\pi_\theta(A_t\mid S_t)\big]$$

用中文读：走很多条路。每条路用自己的分数 $G$，去乘「当时那个动作的 $\log\pi$ 对旋钮的导数」。再平均。

期望为什么能写在外面？因为你本来就是在平均。走一条路，记一笔。走很多条，把这些笔加起来除以条数。每一笔都是「分数 × $\log\pi$ 的导数」。

这就是策略梯度。REINFORCE 是它最老实的算法：走完一条，用整段回报当分数，乘回去，拧旋钮。

新出场三个符号，还是挂修 bug：

| 记号 | 人话 |
|------|------|
| $\log\pi_\theta(a\mid s)$ | 这个动作当时有多「意料之中」。概率 0.70，对数值是负的，但比 0.30 大。越常见的动作，这项越大。 |
| $\nabla_\theta$ | 对旋钮求导。问：拧一点点，$\log\pi$ 往哪边动。 |
| $G_t$ | 走完之后手里的分数。今天先当分数用，不当折扣回报定义重讲。 |

我在这一刀上卡过。不是卡公式，是卡那句「乘回去」。

乘回去？乘到哪？

乘到你走过的那个动作上。绿了，就让当时选的那个动作，下次更容易被选。红了，分数是 0，乘完是 0，等于没拧。

合法不合法，不靠拍脑袋。靠的是：$J$ 对 $\theta$ 的导数，恰好等于「分数 × $\log\pi$ 的导数」的平均。

你不是在解贝尔曼方程。你在爬 $J$ 这座山。

![走完一条路，终点的分数乘回到沿途动作上](02-multiply-g-back.png)

两个动作的时候，还有一句人话就够。走了跑测试，$\nabla_\theta\log\pi=1-\pi$。

$\pi=0.70$，这一项就是 $0.30$。跑测试加一截，再改一处就让出一截。加和减是绑在一起的。概率还是加起来等于 1。

更新就一句话：

$$\theta\leftarrow\theta+\alpha\,G\,\nabla_\theta\log\pi_\theta(A\mid S)$$

$\alpha$ 上篇见过：学习率。这一笔你信多少。今天仍取 $0.5$。

上篇那个 $\delta$，还是别乘。先看 $G$ 自己能拧出什么。

## 三、两条轨迹，$G$ 推了两笔

推导完了，必须手算。还是那个 agent。为了先看清「分数怎么推概率」，两条路都在看到颜色时结束。

绿：$R=+1$，终局，$G=1$。

红：$R=0$，终局，$G=0$。

两条都从 $\pi=0.70$ 起算。不是连着训。是同一把旋钮，分别看红和绿会把它拧向哪。

旋钮现在 $\theta\approx 0.847$。走的都是跑测试。所以 $\nabla_\theta\log\pi=1-0.70=0.30$。

**红的那条。** $G=0$。

$$0.847+0.5\times 0\times 0.30=0.847$$

旋钮不动。概率还是 $0.70$。

失败乘回去，是 0。等于没改。

**绿的那条。** $G=1$。

$$0.847+0.5\times 1\times 0.30=0.997$$

新概率：

$$\sigma(0.997)\approx 0.73$$

跑测试从 $0.70$ 抬到 $0.73$。再改一处从 $0.30$ 让到 $0.27$。

赢的那条会教。输的那条沉默。

![G 两笔：红 0.70 不动，绿 0.70 到 0.73](03-g-two-episodes.png)

这就是我一开始说「先别乘 $\delta$」的原因。

你要是这时候把 $\delta$ 塞进来，读者会以为我们又在改账本。其实还没轮到它。

$G$ 先把「直接改概率」做合法了。它也把自己的毛病摊开了：只有分数不是 0 的路，才拧得动旋钮。

coding agent 红了一次，概率纹丝不动。它不知道这次跑测试偏差。它只知道：手里没分。

同一条习惯，有时赚到 1，有时赚到 0。旋钮被赢的那几条单方面推着走。输的那几条在旁边看着。

这就是 $G$ 太吵的一种具体样子。不是数字乱跳那么简单。是一半的课，老师没来。

## 四、揭盖：分数从 $G$ 换成「比平均好多少」

上篇那个 $\delta$，可以改职业了。

但 $G$ 不能直接换成 $\delta$。中间隔着两级台阶。跳过去，像变魔术。

**第一级。减掉一个只跟状态有关的数。**

$s_0$ 这个局面，不管你跑测试还是再改，先有一个「平均下来值多少」。这就是 $V(s_0)$。上篇的账本。今天不当答案，当尺子。

从分数里减掉它：

$$G-V(s)$$

绿是 $1-0.50=+0.50$。红是 $0-0.50=-0.50$。

红终于有负数了。失败不再是 0，是「比这个状态的平均分还差一截」。

为什么减完还合法？直觉就一句：你给这个状态下所有动作，加减同一笔。相对高低不变。跑测试比再改好，还是比再改好。变的是晃动。

正式的「期望里这项是零」，今天不写。你记住相对高低就行。

$V(s)$ 在这里有个名字：基线。只跟 $s$ 有关，不跟你选了哪个 $a$ 有关。

**第二级。真正该乘回去的，是「这个动作比平均好多少」。**

《贝尔曼方程：为什么只看下一步就够了？》里挂过一句（$Q$ 和 $V$ 的差别，讲到这里会变成主角）。

现在还这笔。

$V(s)$：站在 $s$，不挑动作，平均账。整店值多少。

$Q(s,a)$：站在 $s$，先把动作 $a$ 说死，那本账。今晚必须搞促销，值多少。

两本账的差，才是打分：

$$A(s,a)=Q(s,a)-V(s)$$

$A$ 叫优势。advantage。这个动作，比「在这儿随便选」好多少。

我第一次把 $Q$ 和 $V$ 写在一起，愣了一下。两个都是账，为什么还要相减？

后来对着 agent 想通了。$V$ 说的是这个局面值多少。$Q$ 说的是你在这个局面选了某一招值多少。你要改的是习惯，不是局面。局面改不了。习惯改得了。所以该听的是差额，不是两本账里的任何一本。

正的：下次多选它。负的：下次少选它。零：跟平均差不多，不用拧。

绿的时候，跑测试这本账接近 $1$，$V$ 是 $0.50$，优势约 $+0.50$。

红的时候，跑测试这本账接近 $0$，优势约 $-0.50$。

$G$ 是整段走完才知道的数。$A$ 是「这个动作相对平均」的数。后者才是旋钮该听的话。

**第三级。现场没有现成的 $Q$。**

你不会在走一步之前，先把 $Q(s,\text{跑测试})$ 算出来。没有转移表，这本账跟 $V$ 一样，只能估。

上篇那个 $\delta$，就是估 $A$ 的现场办法：

$$\delta_t=R_{t+1}+\gamma V(S_{t+1})-V(S_t)$$

中文还是三件事：实际拿到的奖励，加上下一步账本打过折，再减去当前账本。

今天两条轨迹都在看到颜色时结束。下一步没有了，$V(s')=0$。于是

$$\delta=R-V(s)$$

绿：$\delta=1-0.50=+0.50$。红：$\delta=0-0.50=-0.50$。

跟刚才用 $G-V$ 算出来的优势，是同一个数。

不是巧合。一步就结束时，$\delta$ 就是 $A$ 的现场估计。路更长的时候，$\delta$ 仍在估同一件事，只是用下一步的 $V$ 把后面折进来。那是上篇的本事。

管子接上了。同一个 $\delta$，上篇拿它改账本。这篇拿它推 $\pi$。

这套班子有个名字：Actor-Critic。

Actor 是演员，被梯度推的那个，就是 $\pi_\theta$。

Critic 是评委，打分的那个，就是 $V$。

评委不解出最优策略。它还在做贝尔曼那件事：用下一步把账做平。演员听打分拧旋钮。

对照一下。符号不是新的。是贝尔曼那套班子换了工种。

| 贝尔曼里的符号 | 这篇里的工种 |
|------|------|
| $V(s)$ | Critic。这个状态下不挑动作的平均账，当基线。 |
| $Q(s,a)$ | 带动作的账。选跑测试还是再改一处，两本账不同。 |
| $A=Q-V$ | 这个动作比平均好多少。真正乘回去的分数。 |
| $\delta$ | $A$ 的现场估计。上篇拿它改账本，这篇拿它推 $\pi$。 |
| $\pi$ | Actor。被梯度推的那个。下次遇到 $s_0$，各动作的概率。 |
| 贝尔曼方程本身 | Critic 还在做这件事：用下一步把账做平。它不解出最优策略。 |

[PPO 把 critic 请回来](https://mp.weixin.qq.com/s/OEZtUhm8MT_En7enJo_8dw)（请的就是这个打分员；策略改进那一半，就是今天这条梯度）。

三条路里，「用一半」从这里接上。一半是 critic 做平账。一半是 actor 拧概率。

GRPO 连打分员都不要，改用同一道题几份回答的平均分。那是绕开。点到为止。

## 五、同一红、同一绿，换成 $\delta$

数字还是从 $0.70$ 起。$V(s_0)=0.50$。$\alpha=0.5$。走的还是跑测试，$\nabla_\theta\log\pi=0.30$。

更新式只换了分数：

$$\theta\leftarrow\theta+\alpha\,\delta\,\nabla_\theta\log\pi_\theta(A\mid S)$$

**红的那条。** $\delta=-0.50$。

$$0.847+0.5\times(-0.50)\times 0.30=0.847-0.075=0.772$$

$$\sigma(0.772)\approx 0.68$$

跑测试从 $0.70$ 掉到 $0.68$。失败终于会教了。

**绿的那条。** $\delta=+0.50$。

$$0.847+0.5\times 0.50\times 0.30=0.847+0.075=0.922$$

$$\sigma(0.922)\approx 0.72$$

跑测试从 $0.70$ 抬到 $0.72$。还是往上。幅度比用 $G=1$ 时小一截。因为减掉了平均分，不再把整段 $1$ 都算成「全是这个动作的功劳」。

并排放：

| 轨迹 | 用 $G$ | 用 $\delta$ |
|------|--------|-------------|
| 红 | $0.70\to 0.70$（不动） | $0.70\to 0.68$（往下） |
| 绿 | $0.70\to 0.73$ | $0.70\to 0.72$ |

绿还是往上。红终于会往下。管子接上了。

![同一红绿：G 列红不动，δ 列红降到 0.68](04-delta-vs-g.png)

我对着这两列看了很久。不是看小数点。是看红的那一行。

同一条失败，$G$ 说「没事，当没发生」。$\delta$ 说「比平均差，下次少这么干」。

评委在场和不在场，差的就是这一行。

## 六、半句话

Actor 和 Critic 可以是一张表。状态不多的时候，格子就够。

状态是代码、对话、长轨迹的时候，格子铺不开。两边都换成网络。更新式还是今天这个：一边用 $\delta$ 做平账，一边用 $\delta$ 乘 $\log\pi$ 拧旋钮。

很多步的 $\delta$ 按衰减加起来，叫 GAE。PPO 里 token 级优势，走的就是那条。完整式子放到后面。

今天不写 clip，不写新旧策略的概率比。那是「一步能拧多大」的机关。旋钮还没说完，先别加锁。

你也不是要给大模型手写一个 $0.70$。你要看懂：后训练里改的是生成每个 token 的概率。打分的如果还在，打的就是「比平均好多少」。

## 结尾

回到那个停在第 3 步的 agent。

上篇给它一个 $V$，教它没表也能改账。

这篇让它直接拧概率。走完看分数，乘回到刚才那个动作上。这就是策略梯度。合法，因为那一刀对数导数。

分数太粗，再请回 $V$。不当答案，当评委。$\delta$ 换了职业：上篇改账，这篇改习惯。

两头接到同一根管子上，就是 Actor-Critic。

下一步的问题变了。不是能不能拧。是一次能拧多大。拧太猛，昨天会的今天忘。那把尺子，下一篇再拿出来。
