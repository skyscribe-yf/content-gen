## S1 · 开场钩子：今天不问账本，问概率（~38s）

**动画要点**：
- 页1 主视觉：状态卡「刚改完一处，测试还没跑」+ 概率双条（跑测试 0.70 / 再改一处 0.30，grow_bar）→ **旋钮概念图**（s1-knob-round.png）→ **emphasize 旋钮**（强调 1/5）→ 卡「世界怎么变，你拧不动；自己的习惯，可以拧」
- 页2：三卡（πθ 带旋钮的策略 / θ 就是旋钮本身 / σ 把 θ 压进 0 到 1），θ=0 五五开、θ=ln(0.70/0.30)≈0.847 时 π=0.70（counter 0.847）
- 结尾悬念条：「合法吗？」

**配音稿**：
> 上一篇算账本，今天换问题：下次再走到这儿，跑测试的概率该升还是该降？状态是刚改完一处，测试还没跑。习惯七成跑测试，三成再改。今天多一件事：这个习惯带着旋钮。拧旋钮，两个概率会变。七成可以变成六成，也可以变成八成。世界怎么变，你拧不动。你自己的习惯，可以拧。新出场两个符号：带旋钮的策略，还有一个西塔，读作 theta。别把它想成什么高深对象，就是一个数，它专门管跑测试的概率。旋钮可以拧到很大很小，概率必须停在 0 和 1 之间，两个动作加起来还得是 1。所以先过一道关：sigmoid，一个数进来，被压到 0 和 1 之间。西塔等于零的时候，两边五五开。西塔大约零点八四七的时候，跑测试正好七成。

**结尾悬念**：拍脑袋调概率，合法吗？

## S2 · 乘回去为什么合法（~45s）

**动画要点**：
- 页1：目标 J=E[G] 公式组装 → 两堆筹码示意（七成跑测试 / 三成再改，各堆顶分数）→ 问题条「平均里藏着 π，求导一定会碰到它」
- 页2 主视觉：**公式 morph / 组装「∇π = π·∇logπ」**（对数导数那一刀，logπ 高亮）→ **emphasize**（强调 2/5）→ 结论「小学数学」→ 目标梯度 E[G·∇logπ]
- 页3：概念图「走完一条路，终点的分数乘回沿途动作」→ 更新式 θ ← θ + α·G·∇logπ →「绿了，让当时那个动作下次更容易被选；红了，乘完是 0，等于没拧」
- 结尾悬念条：「先看 G 自己能拧出什么。」

**配音稿**：
> 你拧旋钮，不是为了概率好看，是为了以后拿到的回报，平均下来变大。这个平均值就是目标 J，期望回报。深度学习里让损失变小靠梯度下降，这里让回报变大靠梯度上升，差一个符号。麻烦在于：平均里藏着概率，因为每条路会不会被走出来，跟你当时的概率有关。你可以把平均想成两堆筹码，七成的路是跑测试，三成的路是再改。拧旋钮，堆的大小会变。对概率求导，手感很差：概率要加起来等于 1，还得夹在 0 和 1 之间，一不小心就拧出界。有一刀专门砍这个别扭：概率的梯度，等于概率自己，乘上 log 概率的梯度。为什么能换？因为 log 的导数是 x 分之一。两边乘回去，就是上面那一刀，小学数学。这就是策略梯度。走完一条路，用自己的分数 G，乘当时那个动作的 log 概率的梯度，再平均。乘回哪儿？乘到你走过的那个动作上。绿了，就让当时选的那个动作，下次更容易被选。红了，分数是 0，乘完是 0，等于没拧。

**结尾悬念**：可只有分数不是 0 的路，才拧得动旋钮。

## S3 · 手算两条轨迹，G 推了两笔（~48s）

**动画要点**：
- 页1：参数卡（π=0.70 / θ≈0.847 / α=0.5 / ∇logπ=1-π=0.30）+ 红绿两条轨迹卡（绿 G=1 / 红 G=0）
- 页2 主视觉：**红那条 counter 0.70→0.70 不动**（δ 式 0.847+0.5×0×0.30=0.847）→ **绿那条 counter 0.70→0.73**（σ(0.997)）→ **emphasize 绿**（强调 3/5）
- 页3：对比卡「赢的那条会教，输的那条沉默」+「一半的课，老师没来」（MUTED 小字停 ≥2s）
- 结尾悬念条：「那个 delta，该上场了。」

**配音稿**：
> 推导完必须手算。还是那个 agent，两条路都在看到颜色时结束。绿是加一，红是零。两条都从七成起算，同一把旋钮，分别看红和绿会把它拧向哪。现在旋钮大约零点八四七，走的都是跑测试，所以 log 概率的梯度是 1 减 0.70，等于 0.30。先看红的那条，分数 G 是零。零点八四七，加 0.5 乘 0 乘 0.30，还是零点八四七。旋钮不动，概率还是七成。失败乘回去，是 0，等于没改。再看绿的那条，G 是一。零点八四七，加 0.5 乘 1 乘 0.30，等于零点九九七。过一遍 sigmoid，概率从 0.70 抬到 0.73，再改一处从 0.30 让到 0.27。赢的那条会教，输的那条沉默。这不是数字乱跳那么简单，是一半的课，老师没来。

**结尾悬念**：那个 delta，该上场了。

## S4 · 揭盖：分数换成「比平均好多少」（~52s）

**动画要点**：
- 页1：三级台阶（第一级减基线 V(s)：绿 1-0.50=+0.50 / 红 0-0.50=-0.50）→ 基线卡「只跟 s 有关，不跟你选哪个 a 有关」
- 页2 主视觉：两本账并排（V(s) 整店值多少 / Q(s,a) 说死动作值多少）→ **相减出 A=Q-V**（A 高亮，**emphasize** 强调 4/5）→「你要改的是习惯，不是局面」
- 页3：δ 就是 A 的现场估计（δ=R+γV(s′)-V(s)，今天一步结束 δ=R-V(s)=±0.50）→ **概念图「评委给演员打分」**（s4-critic-actor-round.png）→ Actor-Critic 双卡（Actor=πθ / Critic=V）
- 结尾悬念条：「换成 delta，红那行会变吗？」

**配音稿**：
> 那个 delta，可以改职业了。但分数 G 不能直接换，中间隔着两级台阶。第一级，减掉一个只跟状态有关的数，就是这个局面的平均账。绿是 1 减 0.50，正 0.50；红是 0 减 0.50，负 0.50。红终于有负数了。失败不再是零，是比这个状态的平均分还差一截。这个数有个名字：基线。只跟状态有关，不跟你选了哪个动作有关。第二级，真正该乘回去的，是这个动作比平均好多少。两本账：一本是站在状态上不挑动作的平均账，另一本是先把动作说死的那本账。两本账的差，才是打分，叫优势。正的多选它，负的少选它。你要改的是习惯，不是局面。局面改不了，习惯改得了。现场没有现成的 Q，上篇那个 delta，就是估优势的现场办法。一步就结束时，delta 就是优势的现场估计。这套班子有个名字：Actor-Critic。演员是被梯度推的那个策略，评委是打分的价值函数。评委不解出最优策略，演员听打分拧旋钮。

**结尾悬念**：换成 delta，红那行会变吗？

## S5 · 同一红、同一绿，换成 δ（~50s）

**动画要点**：
- 页1：更新式只换分数（θ ← θ + α·δ·∇logπ）→ 参数不变条（V(s₀)=0.50、α=0.5、∇logπ=0.30）
- 页2 主视觉：**红 counter 0.70→0.68**（δ=-0.50，σ(0.772)）→ **emphasize 红那行**（强调 5/5）→ **绿 counter 0.70→0.72**（δ=+0.50，σ(0.922)）
- 页3：两列对比表（用 G：红不动 / 绿 0.73；用 δ：红 0.68 / 绿 0.72）+ 金句「评委在场和不在场，差的就是这一行」
- 结尾悬念条：「一次能拧多大？」

**配音稿**：
> 数字还是从七成起。平均账是 0.50，学习率 0.5，走的还是跑测试，梯度还是 0.30。更新式只换了分数。先看红的那条，delta 是负 0.50。零点八四七，加 0.5 乘负 0.50 乘 0.30，等于零点七七二。过一遍 sigmoid，跑测试从 0.70 掉到 0.68。失败终于会教了。再看绿的那条，delta 是正 0.50。算下来零点九二二，概率从 0.70 抬到 0.72。还是往上，但幅度比用 G 的时候小一截，因为减掉了平均分，不再把整段 1 都算成全是这个动作的功劳。并排放：用 G 的时候，红不动，绿到 0.73；换成 delta，红降到 0.68，绿到 0.72。绿还是往上，红终于会往下。评委在场和不在场，差的就是红这一行。

**结尾悬念**：不是能不能拧，是一次能拧多大？
