# 策略梯度是什么？直接改概率行不行

## 文章定位

- 「强化学习原理」系列第四篇。兑现 Q-learning 文末原话：「还有一条路根本不经过 \(P\)，直接改策略 \(\pi\)。再下一步，Actor-Critic 会把「改策略」和「下一步当老师」接到同一根管子上。」
- 一句话承诺（grill 定案）：**不知道转移表，就别先解 \(V/Q\)。走完一步或一条路，把「这笔动作事后值多少」乘回去，提高那些动作的概率。Actor-Critic 只是把这个分数从整段回报 \(G\) 换成上篇那个 \(\delta\)。**
- 「别先解」禁的是「先把账本解完再改策略」，不禁 \(V\)。\(V\) 在本篇不是答案，是打分员。主菜始终是改 \(\pi\)。
- 叙事三拍，先合法、再降噪。锅盖 =「上篇那个 \(\delta\)，今天会改策略」：开头只挂（这个数上篇改账本，今天它会改职业——但先别乘），中间两拍走 \(G\)，第 3 拍揭盖。Actor-Critic 这个名字跟在揭盖之后，不当开场主角。
- 揭盖三小步，不跳：① \(G\) 太吵 / \(G=0\) 教不了失败，减掉只跟状态有关的基线 \(V(s)\)；② 真正乘回去的是 \(A(s,a)=Q(s,a)-V(s)\)；③ 现场没有现成 \(Q\)，\(\delta=R+\gamma V(s')-V(s)\) 是 \(A\) 的在线估计。
- 符号分三拨，每拨一张小卡，每张 ≤4 个，每个一句人话，挂修 bug，不设文末附录。
  - 第 1 拍：\(\pi_\theta\)、\(\theta\)。
  - 第 2 拍：\(\log\pi\)、\(\nabla\)、当分数用的 \(G\)。
  - 第 3 拍：\(A=Q-V\)。已教过的 \(V/Q/\delta/\pi\) 各回呼一句。
- 揭盖后立刻放六格对照卡（工种，不写算法名）：\(V(s)\)=Critic 基线；\(Q(s,a)\)=带动作的账；\(A=Q-V\)=真正乘回去的分数；\(\delta\)=\(A\) 的现场估计；\(\pi\)=Actor；贝尔曼方程本身=Critic 仍在用下一步把账做平。
- 数字例子（grill 定案 + 本稿锁定）：同一 coding agent，「跑测试 / 再改一处」，红 / 绿。开场 \(\pi(\text{跑测试}\mid s_0)=0.70\)，\(\pi(\text{再改}\mid s_0)=0.30\)。\(\alpha=0.5\)。为了先看清「分数怎么推概率」，两条轨迹都在看到颜色时结束（绿 \(R=+1\)，红 \(R=0\)）。不沿用上篇 \(Q\) 的 \(0.60\to0.48\to0.74\)，不另起 GridWorld，不沿用 0.81。
  - **旋钮**：一个参数 \(\theta\) 决定跑测试的概率，\(\pi=\sigma(\theta)\)。\(\theta=\ln(0.70/0.30)\approx 0.847\) 时 \(\pi=0.70\)。走了跑测试时，\(\nabla_\theta\log\pi=1-\pi=0.30\)（softmax 那一句挂在这里：这个动作加、另一个减）。
  - **\(G\) 两笔**（都从 \(0.70\) 起，并排不是连着训）：红 \(G=0\)，乘回去是 0，概率不动，仍是 \(0.70\)。绿 \(G=1\)，\(\theta\leftarrow 0.847+0.5\times 1\times 0.30=0.997\)，\(\pi\to 0.73\)。
  - **校准（相对 grill 原话）**：grill 曾写「红的那条概率往下掉」。手算后 \(G=0\) 乘任何梯度都是 0，红在 \(G\) 阶段不动。正文就用这个反差当揭盖理由，不另造负奖励。红往下掉发生在减掉 \(V\) 之后。
  - **\(\delta\) 两笔**（同一红、同一绿，初值仍从 \(0.70\)、\(V(s_0)=0.50\)）：终局时 \(\delta=R-V\)。红 \(\delta=-0.50\)，\(\theta\leftarrow 0.847-0.075=0.772\)，\(\pi\to 0.68\)。绿 \(\delta=+0.50\)，\(\theta\leftarrow 0.847+0.075=0.922\)，\(\pi\to 0.72\)。
- 数学边界（grill 定案）：从 \(J(\theta)=\mathbb{E}[G]\) 推到 \(\nabla_\theta J=\mathbb{E}\big[G_t\,\nabla_\theta\log\pi_\theta(A_t\mid S_t)\big]\)，核心是对数导数 \(\nabla\pi=\pi\nabla\log\pi\)。期望换到轨迹外用一句人话。不写 \(d^\pi(s)\)，不写定理积分形式。基线不变性只给直觉。来源 Sutton & Barto 第 13 章。
- 硬引用三处，形式一律「链接 + 括号里一句」，不另起段落：① 开头逐字回引 Q-learning 文末；② 揭盖对照卡前回引贝尔曼「\(Q\) 和 \(V\) 的差别，讲 Actor-Critic 时会变成主角」；③ 对照卡后回链已发 PPO 篇。MDP / 上篇两笔账 / GRPO 只点名不展开。
- 反常识点：不解方程、直接改概率是合法的——对概率求导可以换成对 \(\log\pi\) 求导再乘回去；失败轨迹的 \(G=0\) 教不了人，请回 \(V\) 不是走回头路，是给梯度一把尺子。
- 下一篇预告：只挂「\(\pi\) 一步能改多大，需要一把尺子」。不点名多维高斯，不当十篇死承诺。

## 核心结论

1. **可以直接改 \(\pi\)**：目标是让期望回报 \(J(\theta)=\mathbb{E}[G]\) 变大。不必先解出 \(V^*\) 再贪心。
2. **对数导数**：\(\nabla_\theta\pi=\pi\,\nabla_\theta\log\pi\)。对概率求导，换成对 \(\log\pi\) 求导再乘回去。这就是「乘回去」的合法来源。
3. **REINFORCE**：\(\nabla_\theta J=\mathbb{E}[G_t\,\nabla_\theta\log\pi(A_t\mid S_t)]\)。走很多条路，每条路用自己的 \(G\) 给走过的动作打分。
4. **\(G=0\) 教不了失败**：红的回报是 0，乘回去整项是 0，跑测试的概率原地不动；只有绿把它从 \(0.70\) 推到 \(0.73\)。
5. **基线不改方向、改晃动**：减掉只跟 \(s\) 有关的 \(V(s)\)，相对高低不变。真正该乘的分数是优势 \(A=Q-V\)。
6. **\(\delta\) 换职业**：终局时 \(\delta=R-V\) 就是 \(A\) 的现场估计。同一条红，分数从 \(0\) 变成 \(-0.50\)，概率从 \(0.70\) 掉到 \(0.68\)。上篇拿 \(\delta\) 改账本，这篇拿它推 \(\pi\)。
7. **Actor-Critic**：Actor 是被梯度推的 \(\pi\)，Critic 是打分的 \(V\)。贝尔曼方程还在，但只给打分员做平账，不解出最优策略。PPO 的「用一半」从这里接上。

## 结构（6 节 + 结尾，正文 ~3400 字）

- 开头（~280 字）：回到上篇停在原地的 agent。逐字回引 Q-learning 文末「还有一条路根本不经过 \(P\)，直接改策略 \(\pi\)」（链接 + 括号一句）。挂锅盖：上篇那个 \(\delta\)，今天会改职业——但先别乘。点题：直接改概率，行不行？
- 一、今天不问账本，问概率（符号卡 1，~350 字）：场景仍是「改完一处，跑测试还是再改」。开场习惯 \(0.70/0.30\)。新符号只给 \(\pi_\theta\)、\(\theta\)：策略现在带旋钮，拧旋钮就是改概率。\(V/Q/\delta\) 先不请回来。
- 二、乘回去为什么合法（符号卡 2，~700 字，核心推导）：目标 \(J(\theta)=\mathbb{E}[G]\)；轨迹概率里有 \(\pi_\theta\)；对数导数 \(\nabla\pi=\pi\nabla\log\pi\)；得到 REINFORCE。期望换到轨迹外：平均走很多条路，每条用自己的 \(G\) 打分。来源 Sutton Ch13。\(G\) 在这里当「走完之后手里的分数」，不当折扣回报定义重讲。
- 三、两条轨迹，\(G\) 推了两笔（~500 字）：红 \(G=0\)，\(0.70\) 不动；绿 \(G=1\)，\(0.70\to 0.73\)。softmax 一句：走了跑测试，它加、再改减。点题：只靠赢的那条学，输的那条沉默。这就是先别乘 \(\delta\) 的原因——还没轮到它。
- 四、揭盖：分数从 \(G\) 换成「比平均好多少」（符号卡 3 + 六格对照，~700 字）：三小步（基线 \(V\) → \(A=Q-V\) → \(\delta\) 估 \(A\)）。对照卡前回引贝尔曼招牌（链接 + 括号一句）。六格对照卡。Actor-Critic 这个名字跟在第 3 小步后。对照卡后回链 PPO（链接 + 括号一句）：请回的 critic 是这个打分员，策略改进那一半就是今天这条梯度。
- 五、同一红、同一绿，换成 \(\delta\)（~450 字）：\(V(s_0)=0.50\)。红 \(\delta=-0.50\)，\(0.70\to 0.68\)；绿 \(\delta=+0.50\)，\(0.70\to 0.72\)。两张表并排。绿还是往上，红终于会往下。管子接上：同一个 \(\delta\)，上篇改账，这篇改概率。
- 六、半句话（~200 字）：Actor / Critic 可以是表，也可以是网络，一句带过。GAE 是把很多步的 \(\delta\) 加起来，挂到后面。不写 clip，不写重要性采样。
- 结尾（~250 字）：回到 agent——现在它能直接拧概率，打分员只负责告诉它拧哪边。预告：\(\pi\) 一步能改多大，需要一把尺子。开放式问题（给 coding agent 改概率，你更信整段回报，还是「比平均好多少」？）。关注引导 + 近期热门 + 参考资料 + 话题标签。
