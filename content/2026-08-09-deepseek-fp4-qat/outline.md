# FP4量化：4位数字怎么做到无损

## 文章定位

- 本篇是 DeepSeek 技术解密系列的新一篇，主线是 **V4 后训练阶段的 FP4（MXFP4）量化感知训练（QAT）**（DeepSeek-V4 Technical Report §3.4 + §5.2.1）。
- 兑现 FP8 篇（08-08）文末预告：「下一篇，指数位再砍 2 个：FP4 量化感知训练，专家权重再省一半。FP4 怎么在 4 位精度下保持 99.7% 的检索召回？」——标题与预告同频，**99.7% recall 在正文独立成节兑现**。
- 与 FP8 篇形成对照：FP8 篇回答「残缺数字怎么练出顶级模型」（训练精度），本篇回答「4 位数字怎么做到无损」（部署压缩）——同一条精度谱系的两端。
- 主线冲突：**无损压缩的算术**——E2M1 只有 1 符号 + 2 指数 + 1 尾数、16 个可选值、12 倍动态范围、25% 相对精度，DeepSeek 却宣称 FP4→FP8 反量化**无损**。凭什么？数学边界在哪？
- 数学深度：双深潜。① **STE 直通梯度**——量化不可微，朴素反传梯度归零权重冻结，STE 恒等直通让训练继续；② **FP4→FP8 无损反量化**——FP4 子块 scale 差异被 FP8 块动态范围吸收，无损条件 = scale 比值阈值。
- 实验：双实验。① STE vs 梯度截断的收敛对比（toy MLP）；② FP4→FP8 反量化无损性数值验证（scale 比值阈值扫描），标注「机制演示，不是官方性能基准」。
- 下一篇预告：KV 磁盘（08-10，1M 上下文为什么能秒开）。

## 核心结论

1. FP4（E2M1）只有 16 个可选值：0、0.5、1、1.5、2、3、4、6（±）。1 位尾数 → 每 binade 2 个台阶 → 相对精度约 25%，比 E4M3（约 6%）糙 4 倍，比 BF16（约 0.4%）糙约 60 倍；动态范围仅 12 倍（0.5 到 6）。
2. **深潜①**：量化是阶梯函数，几乎处处导数 0。朴素反传把梯度截断为 0 → 权重永不更新。STE 在前向用量化权重、反传把梯度「原样直通」（等价于把量化器当恒等映射求导）——不精确但方向可用，QAT 能训练的数学根基。V4 的用法：梯度对前向 FP8 权重算，直接回传 FP32 master，附带红利是反传无需重新量化转置权重。
3. **深潜②**：FP4→FP8 反量化无损的数学：FP4 元素值（0.5/1/1.5/2/3/4/6）全是 E4M3（3 位尾数）能精确表示的数，scale 是 2 的幂（E8M0），乘 scale 只移指数——反量化回 FP8 不丢信息。无损条件：反量化值落进 E4M3 范围 → 子块 scale 最大/最小比值 ≤ 约千倍（量级）。V4 实测满足。「无损」指 FP4→FP8 回程；master→FP4 本身有损，靠 QAT 让模型适应。
4. 结构：FP4 子块 1×32（512 个 scale 挂在 128×128 FP8 块下），细粒度 scale 的差异被 FP8 块宽动态范围「吸收」——这就是官方「多 2 个指数位，scale 可被吸收」的数学本质。
5. **训练模拟、推理真量化**：训练时 FP32 master → FP4 → 反量化 FP8 计算（模拟量化，复用 V3 FP8 框架零修改）；推理/RL rollout 不走反传，直接用真 FP4 权重——采样行为与线上部署一致，省显存省带宽。teacher/reference 模型同样 FP4。
6. **indexer 量化（兑现 99.7%）**：QK path 全 FP4（缓存/加载/乘法），index 分数 FP32→BF16 → top-k 选择器 2× 加速、KV 条目召回率 99.7%。直觉：top-k 选的是排序不是绝对值，BF16 的 0.4% 扰动只影响骑在边界附近的块。
7. 后训练定位：预训练 33T tokens 全 FP8，后训练（SFT/RL/OPD）才引入 FP4 QAT（观察性表述）——模型先学会知识，再学会在 16 个台阶上表达；OPD 的 10+ teacher 全 FP4 跑蒸馏，student 学到的就是 FP4 环境下的最优分布。
8. 硬件注脚：现役硬件 FP4×FP8 峰值算力与 FP8×FP8 相同，未来硬件理论上可再省 1/3（报告 §1）。

## 标题与摘要

### 标题

**FP4量化：4位数字怎么做到无损**

（教程攻略型 ⭐⭐⭐⭐：术语「FP4量化」前置，搜一搜命中长尾词；「无损」承接主线，与 FP8 篇「残缺数字」「顶级模型」对仗；16 字 ≤ 22；单术语 FP4）

### 摘要

FP4 的每个数字只有 4 位——1 个符号位、2 个指数位、1 个尾数位，总共只有 16 个可选值，动态范围 12 倍，被戏称为「比残缺更残缺」。可 DeepSeek 却宣称 FP4→FP8 反量化**无损**。秘密藏在算术里：FP4 能表示的数全是 FP8 能精确表示的数，子块 scale 的差异被 FP8 块的宽动态范围整个吸收。量化不可微怎么训练？STE 直通梯度让权重继续更新。专家权重再省一半，indexer 打分还保住 99.7% 召回。（含 2 个搜索关键词：FP4 量化、量化感知训练）

## 正文结构

### 0. 开头：16 个数字的记账（约 250 字）

延续 FP8 篇的记账类比：上篇是「8.6 只能写成 9」，本篇更狠——账本上只能写 0.5、1、1.5、2、3、4、6 这几个数，其余数字一律就近取整。FP4（E2M1）就是这本账：1 个符号位、2 个指数位、1 个尾数位，总共 16 个可选组合。悬念：比残缺更残缺的数字，DeepSeek 却敢说反量化「无损」——4 位怎么做到无损？

### 1. 回应弧线：FP8 篇的预告，今天兑现（约 300 字）

- 引 FP8 篇结尾预告原文：「下一篇，指数位再砍 2 个：FP4 量化感知训练，专家权重再省一半。FP4 怎么在 4 位精度下保持 99.7% 的检索召回？」
- 归属校准（系列惯例，谁发明的记在谁头上）：QAT 是 Jacob et al. 2018（CVPR）的通用方法，STE 更早（Bengio et al. 2013），MXFP4 格式来自 OCP 标准（Rouhani et al. 2023）。V4 不发明方法，贡献在落地三件事：①万亿级 MoE 后训练里规模化 FP4 QAT；②FP4→FP8 无损反量化（让整个管线复用 FP8 框架不加修改）；③indexer 分数 BF16 化（top-k 选择器 2× 加速、99.7% recall）。
- 本篇回答：4 位数字有多糙？量化不可微怎么训练？「无损」的数学边界在哪？

### 2. FP4 的算术：16 个可选值（约 450 字）

- E2M1 定义：1+2+1，指数偏置 1。可表示值表：0、0.5、1、1.5、2、3、4、6（正数；± 共 16 个组合，0 计一次）。
- 对照表：| 格式 | 位数 | 动态范围 | 相对精度 | 台阶/区间 |（E2M1 12 倍 / 25% / 2 个；E4M3 2.9×10⁴ / 6% / 8 个；BF16 3.4×10³⁸ / 0.4% / 128 个）
- 直觉：尾数 1 位 = 每区间只有 2 个台阶（×1 或 ×1.5）；动态范围 6/0.5 = 12 倍——从半块蛋糕到 6 块蛋糕；相对精度约 25%，比 E4M3 糙 4 倍、比 BF16 糙约 60 倍。
- 关键认识：单看元素，E2M1 糙得没法用；MXFP4 靠「子块共享 scale」把动态范围外挂——**指数位不够，scale 来凑**。这是深潜②的伏笔（正文不用「伏笔」二字）。

### 3. 深潜①：量化不可微，STE 让梯度穿墙（约 550 字 + 实验 1）

- 问题：Q(W) 是阶梯函数，几乎处处导数为 0。朴素反传：∂Q/∂W = 0 → 梯度为 0 → 权重永不更新，训练直接死掉。
- STE（Straight-Through Estimator）：前向用 Q(W) 计算，反传把梯度「原样直通」：

$$\frac{\partial L}{\partial W} := \frac{\partial L}{\partial W_q}, \qquad W_q = Q(W)$$

数学上等于把量化器当恒等映射求导——不精确，但方向可用，低比特量化里经验上出奇有效。

- V4 的等价实现：FP32 master → FP4 → 反量化 FP8 → 前向计算；反传梯度对**前向的 FP8 权重**算，直接回传 FP32 master——就是 STE。附带红利：反传 GEMM 直接用同一份 FP8 权重，**无需重新量化转置权重**。
- 实验 1（支撑）：toy 2 层 MLP 三路对比——(a) STE 直通、(b) 朴素截断（梯度归零）、(c) 无量化基线。预期：截断路 loss 纹丝不动（权重冻结），STE 路收敛接近基线。
- 为什么 STE 行：量化误差近似零均值噪声（呼应 FP8 篇随机舍入的直觉），直通梯度不会被系统性带偏；训练过程中权重缓慢适应量化网格。

### 4. 深潜②：4 位怎么无损——动态范围算术（约 650 字 + 实验 2）

- 问题重述：E2M1 元素只有 12 倍动态范围、25% 精度，反量化怎么做到「无损」？
- 关键事实①：FP4 能表示的数全是「干净的数」——{0.5, 1, 1.5, 2, 3, 4, 6} 都是 1.m×2^e 且尾数 ≤ 1 位；E4M3 有 3 位尾数（m ∈ {0, 0.125, ..., 0.875}），**全部能精确表示**。
- 关键事实②：MXFP4 的 scale 是 E8M0——8 位纯指数、2 的幂。乘 scale 只移动指数位，不产生新尾数误差。
- 结论：FP4 元素 × scale 反量化后的值，在 E4M3 里**精确可表示**——反量化这一环零信息损失。量化损失发生在 master→FP4（那一步真的丢精度），但从 FP4 回 FP8 是精确的。
- 数学边界（无损条件）：反量化值必须落进 E4M3 范围——最大 6×s_max ≤ 448，最小 0.5×s_min 不低于次正规下限。换算：s_max/s_min ≤ 约千倍（量级，用正规范围口径约 2.4×10³）。V4 报告原文：实测当前权重满足此条件。
- 结构图景：FP4 子块 1×32（512 个 scale 挂在 128×128 的 FP8 块下）——细粒度 scale 的差异被 FP8 块宽动态范围「吸收」。这就是官方「FP8（E4M3）多 2 个指数位，scale 可被吸收」的数学本质。
- 实验 2（支撑）：数值验证——构造满足/不满足比值条件的权重块，扫描 s_max/s_min，低于阈值反量化误差精确为 0，超过阈值误差出现。
- 一句话记忆：压缩可以无损，前提是「格式之间的位宽差得刚刚好」。

### 5. 训练模拟、推理真量化（约 350 字）

- QAT 管线全貌：FP32 master → FP4 → 反量化 FP8 → 计算；反传 STE 回 master。整个管线复用 V3 的 FP8 训练框架，**零修改**（这就是深潜②的工程回报）。
- 推理/RL rollout：不走反传，直接用**真 FP4 权重**（不模拟）——采样行为与线上部署完全一致，且省显存省带宽。训练学的是「FP4 环境下的行为」，部署时就是 FP4，无训练/部署失配。
- teacher/reference 模型同样 FP4（§5.2.1）。
- 硬件注脚：现役硬件 FP4×FP8 峰值算力与 FP8×FP8 相同，未来硬件理论上可再省 1/3。
- 呼应：这是 SFT/RLHF 系列「让模型适应」母题在精度维度的回响。

### 6. indexer 量化：99.7% 召回怎么保住（约 400 字）

- 兑现 FP8 篇预告的「99.7% 检索召回」。
- QK path 全 FP4：indexer 的 query/key 缓存、加载、乘法全部 FP4——长上下文下注意力打分加速（呼应 CSA 篇：indexer 是「先筛后算」的看门人）。
- index 分数 FP32→BF16：top-k 选择器 2× 加速。
- 99.7% 的直觉：top-k 选的是「排序」不是「绝对值」。BF16 相对精度 0.4%，把分数扰动 0.4% 左右，绝大多数 KV 块的相对次序不变；只有恰好骑在 top-k 边界附近的块可能被换进换出——召回率掉 0.3%。
- 与专家权重 QAT 同一条线：QK path 同样走「训练模拟量化 + 推理真量化」。
- 呼应 K=V 篇（08-05）的 indexer FP4 预告。

### 7. 为什么是后训练？（约 300 字）

- V4 的选择：预训练 33T tokens 全 FP8，后训练（SFT/RL/OPD）才引入 FP4 QAT。
- 观察（非官方解释，正文标注）：预训练算力最贵、对精度最敏感，FP8 已验证可行；后训练模型已收敛，此时让权重适应 4 位是「临门一脚」——成本低、收益大（部署侧全链路受益）。
- OPD 衔接：V4 后训练用 On-Policy Distillation（10+ teacher 全 FP4 跑蒸馏）——蒸馏本身就是「学分布」，student 在 FP4 权重下训练，学到的就是 FP4 环境下的最优分布。

### 8. 回扣与结尾（约 350 字）

- 精度拼图汇总：FP8 管训练精度（残缺数字练出顶级模型），FP4 管部署压缩（16 个数字照样无损）——两条线在 V4 汇合。表：| 层 | 格式 | 干什么 |（预训练 FP8 / 后训练 FP4 QAT / 部署 FP4）
- 回扣开头：16 个数字凑不出 16 亿种权重——但当每个数字的误差是零均值噪声、当格式之间的位宽差得刚刚好，压缩可以无损。
- 下一篇预告（KV 磁盘，08-10）：FP4 让权重瘦身一半，KV 缓存呢？下一篇拆 1M 上下文为什么能秒开——KV 缓存直接存进 SSD。
- 开放式问题：如果把「无损」的边界再推一步——你觉得下一个能被无损压缩的组件是什么？评论区聊聊。
