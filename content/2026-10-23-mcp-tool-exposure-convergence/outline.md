## 结构（横切问题四节 + 开头 + 结尾）

### §0 开头（~150 字，钩子已锁定，逐字进稿）

> 2026 年 8 月，OpenAI 给 Codex 合了一个不多的 PR，改动就一句话：MCP 工具分三种方式暴露——直接声明、按需搜索、或者只许代码模式调用。
>
> 如果故事到这儿结束，这只是 OpenAI 的内部改动。但两个月后，另一家公司发布 agent 1.0，文档里是同样的三档。再往前大半年，Anthropic 已经把按需搜索做进了 Claude Code 的默认行为。
>
> 谁也没牵头，谁也没跟风。答案本来就应该长这样，才是唯一合理的选项。

禁系列导航（前两段规矩）；「素不相识」已否（夸张，三家同行业读过彼此，Cloudflare 2025-09 就是命名来源）。

### §1 工具声明怎么进上下文（~450 字，小标题悬念式）

1. **槽1（原声，沿用）**：Q7 后半句逐字——「Anthropic又是如何处理MCP带来的上下文严重膨胀的问题呢？codex如何应对这个挑战？」
2. Cloudflare 背景一段：2500+ 端点按「一端点一工具」= 1.17M tokens（超任何窗口）→ `search()`+`execute()` 两工具 ≈1000 token，降 99.9%；「Code Mode」这个名字 2025-09 它起的
3. Anthropic 四层药之定义层：工具定义不进上下文、按需搜索、**10% 阈值自动开**（auto:N 可调）；官方两理由：50 工具占 10-20K tokens；**超 30-50 个后选择准确率下降**（注意力问题，内链 Context Rot 篇）
4. Codex：PR #36781 原话（2026-08-03 merged）；**时序修正**：PR #29486（2026-06-22 merged）2026-06 就已默认把 MCP 工具走 tool search（原触发条件「feature flag 或 ≥100 工具」改无条件默认）；v0.119.0「200 工具不再注入 200 份 schema」
5. pi：四档压一句（direct/deferred/codemode/hidden）+ **deferred 不在描述里，连上 MCP server 时系统提示 mcp_servers 段都不变**（prompt cache 经济学）+ 回引第一篇微信链接
6. 收敛点一句：三家独立到达同一套三档（Anthropic 2026-01 → Codex 2026-06 → 2026-08 补三档 → pi 2026-10）

### §2 代码跑在哪一侧（~350 字）

- pi = harness 脑侧：沙箱无网络无 FS、权限管线全生效、可审计（`parentToolCallId`）
- Anthropic = 服务商侧：Code Execution 工具在服务商，中间结果不回客户端
- Codex = 本地 V8：`exec`/`wait` 两工具，用户可读脚本
- 落点（笔记 §7 判断）：**三种 placement = 三种信任模型**（可审计/不回传/可复现），不能简单说谁更强
- **槽（原声，新采集）**：对三种信任模型的判断/经历

### §3 大结果怎么管（~300 字）

- pi：bash 回传只给尾部 2000 行/50 KB，codemode 走最多 1 MiB（超长头尾各 512 KiB + `truncated` + `full_output_path`）
- Anthropic：脚本消费中间结果，模型只看最终输出
- Codex：per-tool `output_token_limit` + `on_mcp_tool_result` hook 先于截断（第三方档位表砍掉，非官方口径）
- **槽（原声，新采集）**：被大返回结果坑过的亲历

### §4 都不默认开（~400 字，落点节）

- pi：只在 MCP 启用时自动开 + 作者四理由压缩（benchmark 不够/编码层次/codemode 本身占 system prompt/小模型过度使用）+ 回引第一篇 vibes based 微信链接（升级角度：不是一家为什么关，是三家为什么都不开）
- Codex：官方配置参考页原文 "under development and off by default"（2026-10-21 现读确认）+ **issue #29122 故事**（open：稳定版 IDE 静默激活 under-dev code mode、模型签发 `terminate: true` 终止健康 MCP 调用、10 小时调用 ≈3600 个模型轮次——默认关不是保守，是事故还在现场）
- Anthropic：beta + 旧模型/代理回退全量
- **落点**：三家独立同一判断——方向对，但收益不确定、成本确定
- **槽（原声，新采集）×2**：对「都不默认开」的判断 + 态度/质疑

### §5 结尾（~100 字）

- 撞车没人治一句带过：溢出和涣散三家都治，撞车（上下文互相冲突）没人治（内链 Context Rot 篇——第一篇结尾已接「四方抢地皮」，本篇只一句不展开）
- 第三篇预告：信息守恒 vs 上下文卫生（「什么时候该宁可撑爆窗口也不删」）
- **槽（原声，新采集）**：文末互动问
