# 03-swiglu-gate — SwiGLU 门控 FFN

展示 FFN 的 SwiGLU 门控机制：gate_proj + up_proj → SiLU 激活 → 元素乘 → down_proj 压缩。

中文文字：
- 输入 [7,2048] → 分叉为上下两路
- 上路标注 **gate_proj**：2048→6144 → 经过 **SiLU** 激活（标注为平滑 S 曲线，非硬截断）→ 输出门控信号
- 下路标注 **up_proj**：2048→6144 → 信息通道（直线）
- 两路汇合：⊙ 元素乘（标注为"门控 × 信息"）
- 结果 [7,6144] → **down_proj**：6144→2048 → 输出 [7,2048]
- 底部小标题：**SwiGLU：用神经网络来控门，比 ReLU 更聪明**
- 右下角标注对比："ReLU：负数全扔掉" vs "SiLU：负数也能留一点（平滑激活）"

风格：现代信息图，扁平矢量，白色背景。gate_proj 路用蓝色系，up_proj 路用暖橙色，SiLU 曲线处用绿色高亮。禁止手写体、人物、品牌 logo。所有文字为中文。
