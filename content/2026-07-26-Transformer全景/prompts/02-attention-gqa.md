# 02-attention-gqa — 多头注意力 + 分组查询

展示 Qwen3-1.7B 的多头注意力和 GQA 分组机制。

中文文字：
- 上方：[7,2048] 输入矩阵 → 分叉为三路标注 **Q**、**K**、**V** → 再各自切分为 16 个头
- 中间：16 个 Q 头排成 16 个方块，8 个 K 头 + 8 个 V 头排成两组各 8 个方块（比 Q 头少一半）→ 用大括号标注"**每 2 个 Q 头共享 1 组 KV**"
- 下方：16 个头独立算完注意力后 → 拼接回 [7,2048]
- 右下角小标注：**GQA 2:1**、**16 个 Q 头，8 个 KV 头**
- 底部小标注："更小的 KV 缓存 → 推理更快"
