# 小红书信息图提示词模板

> 核心原则：信息图是小红书推流的核心杠杆。高收藏率 = 高推流。
> 三层逻辑在信息图中体现为：图1-2直觉→图3-5算法→图6-8实测→图9回扣总结

---

## 小红书轮播逻辑链

```
图1：封面（驱动问题）
图2-3：直觉 + 数学（为什么）
图4-5：算法核心（怎么做）
图6-8：实测对比（真的吗）
图9：回扣总结（闭环）
```

**9张图就是一条完整的逻辑链，不是9张独立卡片。**

## 小红书发布 SOP

### 1. 从深度稿提取关键信息
- 1个核心概念 = 1套信息图
- 每套 6-9 张图
- 图与图之间必须有逻辑递进，不是并列

### 2. 生成信息图
- 用上述提示词模板 + gpt-image-2 / xhs_card.py
- 先用 medium quality 测试构图，再 high quality 出终稿

### 3. 写文案（300字）
```
[驱动问题一句话] 🤔

[直觉解释2句话]

[实测关键发现1句话]

📌 收藏慢慢看，完整原理见公众号[账号名]

#数学 #AI科普 #人工智能 #[具体概念] #模型评测
```

### 4. 发布时间
- 原理篇/融合篇：周二/四/六 19:00-21:00
- 评测篇：热点当天尽快，不限时段

### 5. 发布后互动
- 30分钟内回复所有评论
- 评论区补充一个"实测小发现"（增加互动率 + 强化逻辑链印象）
- 置顶评论引导到原理篇/公众号
