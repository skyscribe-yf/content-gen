# 📐 数学×算法×评测 内容生产流水线

## 定位

**用数学讲懂AI，用算法实现AI，用实测验证AI**

三层闭环叙事，别人只做一层：
- 数学博主：讲"为什么"，不讲"怎么做"和"谁做得好"
- 评测博主：讲"谁做得好"，不讲"为什么"和"怎么做到的"
- **你**：为什么→怎么做→谁做得好→结果回扣为什么

## 核心逻辑链

每篇内容遵循同一条逻辑链，三层不是并列，是递进：

```
驱动问题（开头抛出）
    │
    ├→ 数学层：为什么会这样？（直觉+公式）
    │     过渡："这个公式告诉我们需要计算X，算法上怎么实现？"
    │
    ├→ 算法层：怎么实现这个"为什么"？（AI核心算法代码）
    │     过渡："这段代码有个关键决策点，模型能做对吗？"
    │
    ├→ 实测层：模型做到了吗？差异在哪？（多模型对比）
    │     过渡："这个差异不是随机的——"
    │
    └→ 回扣层：实测结果验证/推翻了前面的原理
           回答开头的驱动问题
```

**闭环约束**：
- 算法代码必须对应数学公式（公式每一步，代码有一行）
- 实测必须测试算法层面行为（不是随便跑题）
- 实测差异必须能用数学解释（否则评测和原理就割裂了）
- 开头的问题在结尾必须有回答

## 内容类型与比例

| 类型 | 占比 | 频率 | 定位 |
|------|------|------|------|
| 原理篇 | 50% | 2-3篇/月 | 长尾沉淀，搜索流量 |
| 融合篇 | 30% | 1-2篇/月 | 核心武器，三层完整闭环 |
| 评测篇 | 20% | 1篇/月（热点额外加） | 钩子引流，热点当天出 |

### 三种类型的侧重

| 部分 | 原理篇 | 融合篇 | 评测篇 |
|------|--------|--------|--------|
| 驱动问题 | ✅ | ✅ | ✅ |
| 直觉+数学 | ✅✅ 详细 | ✅ | 简述 |
| 算法实现 | ✅ | ✅✅ 详细 | ✅ |
| 模型实测 | 简述/跳过 | ✅✅ 详细 | ✅✅ 详细 |
| 回扣原理 | ✅ | ✅✅ 详细 | ✅✅ 详细 |

**即使跳过某层，逻辑链不能断。**

## 工作流概览

```
选题 → 深度稿(公众号) → 拆解为:
  ├→ 小红书信息图 (6-9张)
  ├→ B站 Manim 动画 (3-5min)
  └→ 知乎回答 (引流)

评测钩子（热点触发）:
  新模型发布 → 评测快报(6小时内) → 引导原理篇
```

## 一期内容的生产步骤

### Step 1: 选题（5分钟）
- 从 `topics/topic-tracker.md` 选一个选题
- 或热点驱动：新模型发布→评测快报→挂钩原理篇
- 确定类型：原理篇/融合篇/评测篇
- **状态更新**：选题定下后，在 `draft-status.yaml` 新增一条记录（status: planned）

### Step 2: 写深度稿（60-90分钟）
- 用 `templates/weixin-article.md` 模板
- 核心原则：**一条逻辑链贯穿，三层递进，闭环回扣**
- 融合篇需先跑 `eval_benchmark.py` 获取实测数据

### Step 3: 拆解为小红书信息图（30分钟）
- 用 `templates/xiaohongshu-info.md` 中的轮播设计
- 图1-2直觉→图3-5算法→图6-8实测→图9回扣
- 用 `xhs_card.py` 或 gpt-image-2 出图

### Step 4: 制作 B 站动画（60-120分钟）
- 用 `manim/` 下的模板
- 三层配色：蓝=数学，橙=算法，绿=实测
- 融合篇需加实测分屏段（2:15-3:45）

### Step 5: 知乎引流（15分钟）
- 找相关问题，用 `templates/zhihu-answer.md` 模板

### Step 6: 发布排期
- 公众号：周二/五早8点
- 小红书：周二/四/六晚7-9点
- B站：周六下午3点
- 知乎：发布后找问题回答
- 评测快报：热点当天，不限时段

### 热点日流程
```
Day 0  当天出评测快报（公众号800字+小红书6张图）
Day 1  B站2分钟评测短视频
Day 3  公众号发挂钩原理/融合篇
Day 5  B站原理/融合视频
```

## 流量闭环

```
评测篇（钩子）──→ 融合篇（核心）──→ 原理篇（沉淀）
    ↑                  │                   │
    │                  │                   │
    └── 新模型发布 ─────┘                   │
                                           │
  评测引流 ────────────────────────────────→原理留人
```

- **评测是钩子**：搜索意图强（"DeepSeek价格""Claude评测"），新用户入口
- **原理是鱼塘**：长尾搜索（"Transformer原理"），用户留下来的理由
- **融合是核心**：三层闭环完整展示你的独特价值，用户"哇"的时刻
